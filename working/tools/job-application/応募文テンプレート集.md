# 案件応募文テンプレート集 — コトハ用（汎用）

**対応プラットフォーム：クラウドワークス・ランサーズ・その他案件サイト**

提案ライター「コトハ」が案件ジャンル別に使えるテンプレート。
プラットフォーム問わず、応募文の構成・書き方は共通。
各テンプレートの [ ] 部分を案件に合わせて編集してください。

---

## 応募文の基本構成（共通ルール）

**必ず含める7要素：**
1. **冒頭の挨拶** — 本名フルネーム、元気でかつ丁寧に
2. **募集要項への具体的言及** — 「〇〇という部分について、以下が可能です」
3. **具体的な実績・数値** — 「過去〇件・平均評価★4.8」など
4. **作業プロセス・スケジュール** — 「1日目◇◇、2日目◇◇」と明確に
5. **付加価値の提案** — 基本要件にプラスアルファ
6. **稼働時間・連絡頻度** — 「◇時～◇時対応可」「24時間以内レス」
7. **最後の意欲表明** — 謙虚かつ前向きに

## 応募文作成時のチェックリスト（コトハ用）

**送信前に必ず確認：**

- [ ] 本名フルネームが記載されているか
- [ ] クライアント調査に基づいた記載があるか（「ターゲット層」など具体的な言及）
- [ ] 募集要項の全項目に触れているか
- [ ] 数値化された実績が入っているか（「件数」「評価★」「納期遵守率」など）
- [ ] 作業プロセスが日単位で明記されているか
- [ ] 付加価値（基本要件のプラスアルファ）が提示されているか
- [ ] 稼働時間帯が明記されているか
- [ ] レスポンス・修正対応の回数が明記されているか
- [ ] 誤字脱字がないか
- [ ] 敬語は正確か（「〇〇させていただきます」など）
- [ ] 最後に意欲表明があるか

**すべて✓ なら、秘書アイに「応募文完成」と報告。**
