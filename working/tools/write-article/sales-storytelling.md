# 感情を動かす文章の極意 ストーリーライティングの秘訣！

## なぜストーリーを使うのか？

- わかりやすくて、面白いから！
- 感情を強く揺さぶれる → 人は理論ではなく、感情の生き物
- 直接表現ではなく、間接表現

**人は本来、知識を「物語」で伝えてきた**
- 例：「諦めないのが大事」ではなく「俺は山にいき、クマと出会い仲間も死に、もうだめだと思ったが、最後まで諦めずに知恵を駆使したおかげで切り抜けられ、成長できた」というふうに
- 遺伝子に刻まれた本能「人は物語が大好き！」→ 人類最古の職業は語り部
- 文字ができるより前から、言葉と物語で知識を伝えてた

**物語の強さ**
- 物語には「興味をひく」力がある

**物語の力**
- 物語には「事実だと信じさせる」力がある
- 物語には「わかりやすくする」力がある
- 物語には「楽しませる」力がある
- 物語には「仮の体験をさせる」力がある
- **人は説教はきかないが、物語なら聞く**

セールスレターにもコンテンツにも超有効！

## 物語の作り方 基礎の基礎！

**基本は物語は「変身」のストーリーである（広い意味での変身）**
- Before → Afterの転換
- 人は変身願望の塊
- より正確には「覚醒願望の塊」
- △ 別人になった → ◎ 秘められた力が開放された

- 仮想敵：良い状態→イベント→悪い状態
- 自分：悪い状態→イベント→良い状態 or良い状態→イベント→さらに良い状態
- これを軸にするのが基本
- さっきのクマの話も、広い意味で変身の話
- 人は好感をもてる人物のサクセスストーリーは大好きだ
- 同様に、嫌いな人物の転落ストーリーも好きだ
- 例：進研ゼミ、チャレンジの漫画みたいなの
  - 平凡な自分→ゼミうける→超リア充に変身！
  - リア充なライバル→ゼミうけない→ひたすら落ち目に

## 気をつけること

- 長くなりやすい
- 無駄な情報が入りやすい
- 結論が遅い。引きが弱いと退屈
- 「嘘」がつきづらい
- （物語は連鎖してるので、1つの嘘が10の嘘に膨らむ）
- 「盛る」ぐらいならいいが「創る」嘘はほんとやめよう
- だからこそアラのない物語は信用されやすい

## 実践への簡略化（文章例）

**1：葛藤のある日常** → 解説

「私は会社員時代、お金がなくかつ忙しい日々を過ごしていた。転職も考えたが、うまくいく保証もない。」

- 読み手への共感シーン、自己投影箇所
- 同時に、変身への前フリ、落差があるほどよい
- 葛藤とは「板ばさみ」のこと
- 欲しい物があるが、壁があって越えられない状態
- 例：好きな人がいるが告白の勇気がない
- 単に悩みをだすより「欲しい物があるが失いたくないものもある」という両立がよい
- 表現すべき感情：苦悩、苦痛、葛藤、欲望、将来への悩み

**2：誘惑と拒否と再挑戦** → 解説

「その頃、転売というものを知った。うまくいけば月に100万円！？しかし、そんなうまい話があるはずがない。当然のように見送した。しかし、どうにも気になる。飲み会くらいは行ってみるかなと参加した。そこで、違う世界を知り、挑戦した」

- 読み手への共感、一度拒否することで、常識的な感覚をもっていることを示唆する、その上で再挑戦することで「自分も同じ判断をするかも」と読み手に思わせる
- 表現すべき感情：疑念、否定、世間体への意識、プライドとの葛藤、興味、驚き、挑戦、覚悟、理性、興奮

**3：挑戦の失敗と否定** → 解説

「しかしダメだった。週7日の労働、仕入れに出品、評価に価格調整。あまりにも大変。副業でもなんでもない、本業にも影響をきたしたし、単なる二重仕事だと気づいた。絶望した。仕事を2つもちたいわけじゃない」

- 読み手への共感と投影。一度失敗するから共感される
- あるいは、ライバルの手段や既存手段の末路を提示することでさりげなく否定、警告している
- 表現すべき感情：疑念、否定、苦しみ、辛さ、不安、悔しさ、情けなさ、後悔、失望、迷いなど

**4：真理への気付き（師匠との出会い）** → 解説

「そんなとき、投資型転売というものをやってる人に出会った。労働時間を一切かけずに、まるで投資のように長い目で転売することで資産を徐々に増やす転売手法があるらしい。これだ。これこそ私が探していた方法だ！私はこの方法をやってみようため、弟子になった」

- 読み手を賢くする。読み手の想像しない解決手段があることを示し、読み手の選択肢、世界を広げる。
- 間違ったルールにいたことに自覚させる
- 表現すべき感情：疑念、戸惑い、驚き、衝撃、興奮、情熱、気付き、確信、目からウロコ

**5：覚醒と成功** → 解説

「するとどうだろう！面白いようにお金が増えていった。労働時間は週7から1になったが、収入は逆に7倍になった。今までの苦労はなんだったんだ？これが成功者のみてる世界なのか？確かに現金化までは時間がかかる。だが、そんなの気にならないくらい。私は熱中し、それと比例して成果はどっとふえていった」

- 読み手の自慢シーン。いかに「困難だった壁」が「簡単な壁」にかわったか。自分や状況が変われたことを書く。解決法は「以前よりはるかに簡単」でなくてはいけない
- 読み手に憧れをいだかせる。手段に信用をもってもらう
- 表現すべき感情：驚き、衝撃、喜び、ワクワク、熱中、夢中、興奮

**6：報酬とその後** → 解説

「そして今では、年収1000万を超えている。会社もやめ、逆に社長になった。師匠には感謝してもしきれない。相変わらず、労働時間（仕入れ時間ではない）は週に1日ほど。考えるもかわって、本当の投資もしはじめ、周囲の目もガラッと変わった。冴えないサラリーマンだ、今では新進気鋭の社長だ。これは、誰にでも起こる物語だ。次はあなたの番だ」

- 達成した成功を示す。「壁を超える」事が、そこだけにとどまらず「連鎖」的に、幸福を呼び寄せることを示す
- 「選択は間違いなかった」事を決めてもらうよう
- 表現すべき感情：夢中、興奮、満足、幸福感、感謝、謙虚さ、前進、希望、博愛など

**※ 2：誘惑と拒否と再挑戦、6：報酬とその後 → はスペース次第では削れる**

## 最強の煽りストーリー ヒトラーストーリー術！

熱狂させたといえばこの人

**4つのポイント**

**1：現状をこきおろす**
- ドイツの現状は何だ！
- 失業率は低い、貧困率は高い、犯罪率もたかい
- 産業もない、軍も弱い、しかも身内で争うてるし
- よその国に金も土地もボロボロにされていたり

**2：ポテンシャルを褒める**
- だが、私は知っている
- 真のドイツ国民の力はこんなものではない。
- 誠実にして真面目、賢く力強く勤勉でその気になれば
- どんな敵にも負けはしない。世界一優れた民族だ

**3：敵が邪魔していると伝える**
- それを邪魔するものがいる。ユダヤであり諸外国だ
- 彼らが、我らの課題を、それしあ動機で背負っている。
- 勤勉な我々はただボヤいてし、戦い、そしてやがては
- 金を通して、世界を支配しようとしている。ドイツはその足がかりだ。
- 彼らはドイツ人を奴隷に思い、牟搾取し続けていたのだ

**4：バラ色の未来を伝える**
- 彼らがいなければ、ドイツは再び蘇ることができる。
- 我らドイツ人は世界一優秀な種族だ。
- 仕事を取り戻し、産業は活性化し、誇りと尊厳を取り戻すだろう！
- 私は約束する。強くて誇り高い、先祖の血を覚醒させた、あるべき姿のドイツを取り戻すぞ！

**さらなる補足**

- たたきと褒めの矛盾を解決した → 褒めるとそのままでいいとなる → しかし、それを指摘するだけだと説教と感じて離れる
- 現状は否定し、ポテンシャルを褒める → 問題点を解く
- 相手が努力する、投資する理由がみえなくなる
- いいも事実やいいことだから響きづらい
- 敵を排除すれば解決するとしかいわない
- 方法論は特にいわなかった → 自分に投票すれば解決するとしかいわない
- 言ったところで覚えてないと思われた
- 自分勢力が30、敵が40ぐらいだとしても、100ぐらいにみせた
- 敵を巨大にみせた
- 巨大な力があおれるし、正当性がある。
- 1000ぐらいだと膝がけりるが、頑張れないもいるなら頑張る

**3つの所属術を使う**
- 私と言わず、我々という
- 我ら→「自分らの集団」をさす
- 我、彼ら、あいつら → 彼ら→「憧れの集団」をさす
- あいつら→「見下す敵の集団」をさす

**「我ら」は「あいつら」みたいにはなるまい**
**「彼ら」みたいになろう**

- 全てを集団と捉える
- これをやると、強烈に方向性が定まる
- 結束も高まる

## ビジネスに応用

**文章例**

**1：現状をこきおろす**
- 例：ニートは世間から馬鹿にされてる。
- 親の世話になりっぱなしとか、根性ないとか、
- 社会に適応できないとか。

**2：ポテンシャルを褒める**
- 例：しかしまだろう、真面目すぎるからこそ、ブラック会社と向き合って心を病む上に、
- 根性がないのではなく、体を大切にした合理的選択。
- むしろ新しい時代への適応力がある旧社会の偏見だ。
- 人格的に正社員や社長より優れたニートはたくさんいる

**3：邪魔する敵を叩く**
- 例：
- 日本の労働が遅れてる、僕らニートはむしろ世界標準。
- こんな奴隷環境で働くのは日本人だけ。
- みんなブラック企業の社長をどこに渡淵してる。
- ここまで頑張ったらなくても、日本人はそもそも真面で優秀
- 海外にいけば、日本人の評価は超高い

**4：バラ色の未来をむかい**
- 例：
- 時間を守るだけでめっちゃ評価される。
- 普通の真面目、誠実さをもつだけで、ガンガン褒められるし
- 勝手に昇進するし、彼女もできるし、友達もできる。
- お金も稼げるし、消費も少ない、
- 笑顔さえ絶やさなければいいだけ！
- 自分の優秀さに気づけ、世界へでろ！
