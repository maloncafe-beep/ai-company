# セールス系ライティング チェックリスト

## 最上級のバカ売れを目指すセールスライティング（チェックリスト編）

## 4つの「レターの良し悪し」即興チェック！

**1. 他の商品のセールスにも、商品名だけかえれば転用可能か？**
- 可能なら、ダメなレター
- 優れたレターは「専用」である、パクることはできない
- 「そのまま何にでも使えるセールス文」はダメ

**2. 全く知らない他人が書いたとしても、読む気になるか？買いたいか？**
- 買う気にならないなら、客観的になれていない
- 思い入れや、損得勘定が絡んでいる
- 商品名と、販売者名をあなたの知らない名前に入れ替えてみよう
- できるだけドライに評価しよう
- お客はあなたの評価より一段下くらいだと思おう
- あなたの事情はお客には関係ない
- 思い入れは済そう
- 買う気になるなら、良いレター
- 販売者の事を信用できそうなら、良いレター
- お客が買わない第一の理由は「うさんくさい」これのみだ
- これと似た質問に「中身を知っていても、もう一度買いたくなるか？」というのがある
- 知っていても欲望が刺激される、それくらいを目指そう → 欲情
- 書いている自分が欲しくなるくらいがいい

**3. そのレターを知識なしで読んだとして、商品を買うことで得られる能力やベネフィットが、一言でいえるか？**
- 言えないなら、お客にも伝わってない
- 伝わってないなら、ほぼ売れない
- 要するにコンセプトがぼやっとしてる可能性大

**4. 自分より収入やブランディングなどが上の人がみても、欲しいか？**
- 欲しくなるなら良いレター
- オリジナリティが高い、特化できている
- 欲しくならない場合、ありきたりだったり
- コンセプト勝負できない
- 単なる実績とかだけで勝負しようとしてる

## 8つの超基礎チェック!!!

**1. 新規性はあるか？（好奇心）**
- 新しさ、面白さがあるか？
- 独自性、オリジナリティがあるか？
- 中身をみるまでやめない、と思われないか？ → 思われたら終わり

**2. ベネフィットはあるか？（欲望）**
- 買うとどうなる？
- 変身後の世界（環境と感情）の提示
- ビフォー・アフターの対比 → 実践者と非実践者の対比
- ローコスト（労力や資金）、ローリスク、ノータイム、ノーストレスのどれかあるいは複数あるか

**3. 簡単そうか？（簡易性）← 最重要**
- 相手が強敵だと思っているものを「ワンパンチ」で倒す

**4. 択を迫っているか？（恐怖）**
- 相手が現実的に選びうる → 相手が何かを捨てるか
- 全ての選択肢をだせてるか → 既に戻してると定着してるか
- 「その所属はイマイチである」と伝えてるか → 仮想敵との対比
- 例：ダイエット方法は3つあります → 運動をメインにするダイエット・運動をサブにするダイエット・運動しないダイエット → 必ずお客はどれかに属す
- 仮想敵の所属者の思考 → 所属者の恐怖の「未来」の提示
- 自分が提供する選択肢が、最上であると合意はとれてるか

**5. あおられているか？（緊急性）**
- 緊急性はあるか → 緊急性の正しい煽り方
- 「動かないリスクを刺激しているか」
- × 電車の発車まであと5分！3分！2分！集れないと終わりです！
- ○ 最後の電車の発車は12:00です。今、11:55です。

**6. 共感はあるか？（味方確認）**
- 苦悩・基盤への理解 → この人は「わかってくれる人だ」という認知
- 動機・理念の共有 → この人はうさんくさくなく、誠実な人だ、という認知
- 実績と他者証明

**7. 相手の疑いを晴らす証拠はあるか？**
- お客は常に疑っている
- 数字や事実は常に強い
- 反論を想定し、反論を先においているか
- **お客様の声は最強**

**8. これらが分かりやすく表現されているか？（伝達性）**
- 説明書や、車のカタログのようになってないか？
- 対比で表現されているか？ → 変化も差別化、全ては対比で理解する → 価値は相対的にしか理解できない
- ストーリー形式があるとよし → 語りかけているか
- 読みやすく、分かりやすいか？ → 話は「連続して」つながっているか？ → 単なる解説の羅列になっていないか？
- 主張、キャラに一貫性はあるか？

## これが基本！オファーレターテンプレ構成！

**前提** — レターを書く前に、設定は終わらせておく
- ターゲット、自分の実績/権威、ベネフィット（理想世界）
- 二色化（分かれ目）、仮想敵（厄介な壁）、ライバル（他の選択肢）
- 魔法の武器（ノウハウなど）、なぞるか（価値観や動機）

### 冒頭

**タイトル＆キャッチコピー**
- タイトルだけで欲しくなるようなタイトルをつける
- タイトルで賄いきれないものはサブタイトルをつけるのも可
- 数時間かける価値がある
- 欲情させる

**実績＆ベネフィット**
- 「私がなぜ○○のような成果を出せてるのか、その秘密をお届けします」
- ○○には、3〜7つくらいの他人が震えしがるか、凄いと思うような実績が入る
- 実績提示だが、ベネフィットを添えている
- 権威性を示し、こいつは凄いと思ってもらう

**ベネフィット連打**
- 「私は今や○○のような生活をしています」
- 「△△のようなことも珍しくありません。日常です」
- 理想の未来を提示し、こうなりたい手にしたいと思ってもらう → 欲情させる

**簡易性提示**
- 「これらは実は難しくない。別に難しくはありません」
- 「難しいことをするのは嫌ですが、ただ正しい方法が知られていないだけです」
- 軸の提示、答えの提示
- 簡易性を加速させる → 簡易性

**二色の提示**
- 「それは○○によるものです」
- 「自分の成功も、○○でもたらされました」
- 好奇の刺激、欲望の刺激

### ストーリーを持つ価値説明

**ストーリー開始**
- 「しかし、私も最初からこうだったわけではありません」→ 共感のスタート

**苦悩と葛藤**
- 「だいぶ○○をやっても、しかし○○はなかなか難しかった」→ 共感、仲間だ！
- 「どうしても成功できず苦悩しました」→ 仮想敵の提示

**既存の失敗**
- 「私は既に出たある、有名な○○を試し」→ 既知の方法で失敗
- 「しかし、結果は期待外れのものだった」
- 「私は諦めかけたしくじりを繰り返しました」
- メジャーな手段、ライバル、道徳的解決法の否定 → 恐怖の刺激
- 知識を与えるようで、選択肢を奪う

**出会い**
- 「そんな時、師匠と出会った or 新しい手法と出会った、あるいは気づいた」
- 「私が求めていたのはこれだったのかもしれない！」
- 「私は問題しつつそこに打ち込んだ、やっと…」
- 出会い →（順番に思いっきり打ち込んだ、やっと…）
- 新しい手法、**魔法の武器の登場**
- 読み手が置換し、新しい知識
- 賢くなるという感覚の付与
- 提示への感謝の心と、提供への認識の刺激 → **核** ベネフィットと結ぶ

**簡易性と威力の提示**
- 「○○は【簡単に】取り扱われ、そこから何もかもが変わった」
- 「これは一○しまいました（選択式とベルトなど）」
- 簡易性の提示
- 魔法の武器の威力の提示 → **核**

**解説**
- 「こんなことやあんなことを手に入れたい」→ 理想世界の提示
- 「その手法とは○○です」→ 説明、納得させるために説明
- 「○○で成功する理由は○○だ」→ 解説
- **ここの説明力はかなり成否をわける**

**失敗した未来との対比**
- 「…もし私が過去のままなら○○になっていたでしょう」
- 「or あの時、○○をしなかった人たちは失敗しました」
- 常識的手段、ライバルの手法の否定
- 仮想敵の弱点を受け入れない場合の結末 → 恐怖の刺激
- 今あなたが失敗ルートのさなかにいるという錯覚

**理念開示と提案**
- 「だが、私は●●と思っている」（理念、動機の提示）→ 人格の提示
- 「そこで、その理念にもとづき、xxをあなたに提供したい」→ 綺麗な主張による安心感

**希少性の提示**
- 「世の中にはまだこのことは広まっていない、だからこそ…」
- 「せっかくこれだけのことは広まっていない、チャンスしかない」
- 残りの限定、オンリーワン性の主張、今決断せねばならない
- 「あるいは、最も早く知れる人、最も早く取り組んだ人だけが…」→ 限定感の提示
- 発見と歓迎 → 応援したい → 人格の提示
- 読み手の飢民思想の刺激

### コンテンツ説明

- コンテンツ説明＆ベネフィットの連打
- 小見出し（ブレッド）＋ 2〜3行の説明やベネフィット
- 「私はこういうものを提供し」
- 未来の提示：「あなたはこれによりこうなるでしょう」
- これを3〜30くらい並べる
- リアルに受け取っている自分をイメージさせる

**価格とその妥当性の説明**
- 「この商品を作るために○○円や○○ヶ月を注ぎました。○○万円の価値はあるでしょう」
- 「あるいは、これを得れば○○○のリターンがあります。そのためなら…」
- でしょう
- 安いと目の前で感じてもらう → お金よりやっぱいいと思うから買う

### オファーと価格説明

**第三者の証明**（いわゆるお客様の声）
- 「この人のノウハウをやってみましたが素晴らしい成果が出ました！」
- 「or この商品を使いましたが、人生が変わりました！」
- 社会的証明、高い権威、高精度の承認

**煽りと緊急性の提示**
- 期間限定価格です / 限定○名 / or 期間限定販売です / 3日以内に決断してくだされば十分
- 集める

**オファー**
- 「ご注文はこちらから！」→ なけなしではなく十分

**疑問の解消**
- Q&A
- Q：サポートはどうなってますか？ A：サポートは○○です

### 追伸

- 最後のひと押し。現状や未来の再確認、主張のまとめ
- 「私がこの商品を作ったのは、○○という想いがあったから」
- 「全身全霊をこめました。今後世の中は○○になっていく」
- 「でしょう。そんな中で○○でいいですか？」
- 冒頭の欲情を思い出させる場所 → 習慣の欠如で売れる場所
