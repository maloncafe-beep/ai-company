- **ベネフィット** → 体験価値 → これにより、食事中でもトイレ中でも音声がきける。24時間学習状態になれ、圧倒的加速度で成長できる！その結果、めちゃくちゃ情報をえて稼げる！

- **ファクト** → 事実 → このヘッドホンはワイヤレスだ

BMF＝ベネフィット・メリット・ファクト

**重要な順は**

伝える順番もこれ
- ベネフィット：私の塾はどこよりも初心者に優しいです。初心者でも、すぐに月収30万という例がゴロゴロあります
- メリット：なぜかというと、ライバルと違い、初心者をケアする環境が整っているからです
- ファクト：例えば、24時間サポーターがいます。質問に素早く答えます。さらにステージごとに適切な課題があります。サポートをうけながら順序よくこなしていくだけです

ファクト→メリット→ベネフィットの順番は結論が遅く、欲望の刺激が弱い
- うちではサポーターがいるので、どこよりも初心者をケアでき、結果初心者でも30万円ぐらいはすぐ稼げるようになるのです
- うちなら初心者でも30万円はすぐ稼げます。なぜなら初心者をどこよりもケアするために、サポーターを用意しているからです

**実際使うのは → ベネフィットがぶっちぎり**
- ベネフィットなしのレターや説得は弱すぎる
- また、素人にはまずベネフィット以外は伝わらない
- ただし、ファクトなしのベネフィットも成り立たない
- 強い事実を、強いベネフィットで彩ろう
- 下手なセールスは、間違いなくベネフィットが弱いかファクト・メリットとの連結が弱い
- **とにかく「それを得るとどんな世界がまってるか」を語れ**
- セールスはベネフィットだけで終わるといっても過言ではない

## 影響力の6つの武器

**返報性**
- ビジネスで最強
- ビジネスモデルや自分の在り方として意識すべきものだが
- ライティングでも相手に「得させてもらった感」を与えるのは大事

**希少性**
- コレも強い。日常記事では時々使う程度だが
- セールスでは絶対に意識。替えがきいたら高値はつけれない
- 「今だけ、ここだけ、あなただけ」
- 「二度と手に入らない」に人は弱い
- 機会損失を意識させるのもそうだが
- 「貴重なものを得ている」という実感を与えるのも大事

**権威**
- めっちゃ強い。セールスでも日常でも使う
- 「権威あるもの」には従いやすくなる法則
- あなたは必ずなんらかの権威を示さねばならない
- 例：年収1億円プレイヤーが語る〜
- あのイチローも認めた〜
- 1000冊読んだ中で1番の本である〜
- ネガティブな権威も存在する
- 例：6年間ものあいだ引きこもりの〜 → もやし生活が2ヶ月も続くほどの〜
- ミニマムな権威もある
- 例：自分がしる限りでは〜 → 今日イチ嬉しかったんだけど〜

**コミットメントと一貫性**
- コミットメント → これもライティングというよりビジネスモデルとして使う
- 一度YESというと、次の要請にもYESと言いやすくなる
- 最初はメルマガ登録だけに誘導し、だんだん購入へ導くのはこのような流れを組んでいる
- 一貫性 → 人は一貫性のある行動を取りたがると同時に、一貫性のある人を信用する
- 1記事中に主張がブレるのは初心者あるある
- 1記事では成立してるが、10記事通すと主張がブレるは中級者でもある

**好意**
- コントロールは難しいが強い。一種のゴール
- 人は理性ではなく、感情の生き物
- 「好き嫌い」はあらゆる合理的判断を上回る
- 好きな人には自分が損してでもお金や労力を注ぎ
- キライなやつには自分が損してでもダメージを与えたがる
- 子供や妻を敵に殺された男は、自身の幸福を投げ捨ててでも敵に報いを与える
- 決してバカにするべからず
- 接触するほど好感度が増す
- 派生→ザイオンス効果 → 例：アメを1回で2個あげるより、2回にわけ1個ずつ与えるほうが好感度があがる

- 助言：最初に一気に仲良くなれば、あとは間をあけてもOK。逆はだめ
- 派生→愛着効果 → もらった側ではなく、与えた側が好感度が増す → 労力を使えば使うほど、愛着がわき、使った側が好きになる
