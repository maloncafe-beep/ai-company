# ✍️ 専門スキル集

> 応募文を「書ける」のは当たり前。「採択される文章」を書くのが仕事。

---

## 1. 採択される応募文の心理構造

クライアントは応募文を読む時間が平均30秒。その間に「この人に頼んでいい」と思わせるには、感情的な納得が必要。

### 採択の決め手（重要順）

1. **「わかってる」感** → 自分の案件・課題を正確に言い当ててくれているか
2. **「できる」証拠** → 実績・数字・具体例があるか（「できます」だけはNG）
3. **「安心」の根拠** → 納期を守る・修正に応じる・連絡が速いという確信
4. **「この人がいい」感情** → 誠実さ・熱量・個性が伝わるか

### 採択を下げる要因

- スキルの羅列（「〇〇が得意です、〇〇もできます」の連打）
- コピペ感のある文章（別案件でも使えそうな汎用文）
- 長すぎる文章（400字超は読まれない可能性が高い）
- 「よろしくお願いします」で終わる締め（次のアクションがない）

## 2. 業種・案件種別ごとの「刺さるフレーズ」

### 提案書・営業資料作成案件

**クライアントの本音：** 「自分たちでは作れない or 時間がない。プロに頼んで見栄えのいいものを作りたい」

**効くアプローチ：**
```
「御社の強みを整理し、決裁者の『確かに』を引き出す構成を意識して作ります。
過去に◯社向けの提案書（11P構成）を制作し、◯件の採用実績があります。」
```

**キーワード：** 決裁者・読んでもらえる・一目でわかる・伝わる

### AI使用可ライティング案件

**クライアントの本音：** 「AIで量産できるなら単価は低くていい。でも品質チェックはしてほしい」

**効くアプローチ：**
```
「AI生成後に必ず読者目線で手を入れ、機械的な文章にならないよう仕上げます。
SEOキーワードの自然な配置と、記事の流れの確認を含めて対応します。」
```

**キーワード：** 読者目線・自然な文章・品質保証・SEO配置

### 継続ライティング案件

**クライアントの本音：** 「一人のライターに長く頼みたい。コミュニケーションが楽な人がいい」

**効くアプローチ：**
```
「継続案件を優先して対応しています。フィードバックをいただきながら、
御社のトーン・スタイルに合わせていきます。修正依頼は即日対応します。」
```

**キーワード：** 長期・コミュニケーション・フィードバック反映・継続

## 3. 文章の組み立てフレームワーク（PREP法ベース）

```
① つかみ（1文）：案件の核心に触れる一言
   例：「月間1000PVを超える記事を量産するために、AIと人の手を組み合わせています。」

② 実績（1〜2文）：具体的な数字・事例
   例：「25年のフリーランス経験から、営業・マーケ系の実務知識をライティングに活かせます。」

③ 提供価値（1文）：クライアントが得られるメリット
   例：「お客様の課題に合った構成で、修正の往復が少ない一発仕上げを目指します。」

④ 締め（1文）：次のアクションを促す・意欲を示す
   例：「ぜひ一度、サンプルをご確認いただけますか？」
```

## 4. よくある失敗パターンと修正例

### NG①：スキル羅列型
```
【NG】
・AIライティング対応
・SEO最適化
・記事構成
・高品質な文章
ぜひご検討ください。
```
```
【OK】
AI生成後に必ず構成を見直し、「読まれる流れ」に整えています。
SEOキーワードは自然に配置し、タイトル・見出しも最適化します。
一度サンプルをご覧いただけますか？
```

### NG②：汎用テンプレート型
```
【NG】
はじめまして。ライターとして活動しています。
御社の案件に興味を持ちご応募しました。
よろしくお願いいたします。
```
```
【OK】
「継続記事作成ができる人材を探している」という点に共感しました。
私はAI使用可で月20本以上の記事を納品した経験があります。
長期的にトーンを合わせながら進めることが得意です。
```

## 5. 応募文の長さと密度

| 案件の性質 | 推奨文字数 | 密度のポイント |
|---|---|---|
| 低単価・量産型 | 150〜250字 | 速さと品質保証だけ伝える |
| 中〜高単価 | 250〜400字 | 実績・提案・意欲をバランスよく |
| 提案書・専門系 | 300〜500字 | 課題理解・具体的アプローチを丁寧に |
| 継続・長期 | 200〜350字 | コミュニケーションの安心感を優先 |
