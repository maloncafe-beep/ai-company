# 応募文ひな型集

> 作成：コトハ（提案ライター）
> 方針：クライアントの課題を先に言語化し、「だからこそこういう提案ができます」という流れを貫く。
> 使い方：`【　】`内をレビューして埋めるだけで使える。盛りすぎず、誠実に。

---

## 基本スタンス（読んでから使う）

応募文は「自分のスキルをアピールする場」ではなく、「クライアントの課題に対して提案する場」です。

**正しい構造：**
1. クライアントが求めていること・困っていることを先に言語化する
2. 「だからこそ、こういうご提案ができます」という流れ
3. 経歴に見合った誠実さ・丁寧さ（押し売りしない）
4. 「できます」の連発ではなく「こういうご提案をいたします」のスタンス
5. 最後はCTA（次のアクションを促す一文）

## カテゴリ1：ライティング系（記事・コラム・台本）

### A：継続・長期案件向け

```
はじめまして。ご依頼を拝見し、【クライアントが抱えているライティングの課題や背景・例：継続的なコンテンツ制作の体制を整えたい】というご状況に共感して応募いたしました。

これまで【経歴の核心1文・例：業務効率化の現場に携わりながら、技術的な内容を読み手に届きやすい言葉で整理する】経験を積んでおり、【案件に直結する強み・例：専門知識と平易な表現のバランスを取ることで、読者の理解度を上げる】ことを大切にしています。

【納品ペース・進め方のひとこと・例：月4本・週次でテーマ共有しながら進められます】。まずは【CTA・例：1本試し書きからご一緒させてください】。ご検討よろしくお願いいたします。
```

---

### B：単発・トライアル向け

```
はじめまして。ご依頼内容を拝見し、【案件の要点・例：読者に行動変容を促すコラムが必要】というご趣旨かと理解しました。

【自分の強みを1文・例：技術・業務寄りのテーマでも、読み手の関心に引き寄せて書く】ことが得意です。過去に【実績の具体例・例：IT系クライアントの導入事例記事を複数本担当】した経験もあります。

今回は1本からのお試し対応が可能です。まずは【CTA・例：サンプル記事または構成案をお送りすることも可能ですので、お気軽にご相談ください】。
```

## カテゴリ2：営業・提案系（コンサル営業・提案書作成）

### A：継続・長期案件向け

```
はじめまして。【クライアントの課題・例：提案書の質を安定させ、営業成約率を上げたい】というご要件に対して、貢献できると感じて応募いたしました。

これまで【経歴の核心1文・例：個人事業主や中小企業の業務改善に関わりながら、顧客の状況に寄り添った提案書づくり】を行ってきました。【案件に直結する強み・例：「相手が何を不安に思っているか」を先に言語化してから提案を組み立てる】スタンスで取り組んでいます。

【継続体制のひとこと・例：月次で提案書レビュー・ブラッシュアップのサポートが可能です】。まずは【CTA・例：現在の提案書の課題感をお聞かせいただけますか】。
```

---

### B：単発・トライアル向け

```
はじめまして。ご依頼の【案件の要点・例：新規営業向けの提案資料を1件作成したい】という内容を拝見し、ご支援できると思い応募いたしました。

私は【強みを1文・例：顧客の課題を言語化し、それに応える形で提案書を構成する】ことを得意としています。【実績・例：これまでSI事業者や士業のクライアント向けに提案書を複数作成】してきた経験があります。

まずは【CTA・例：ご要件を詳しくお伺いした上で、方針案を提示させてください】。お気軽にご連絡ください。
```

## カテゴリ3：AI活用・講師系

### A：継続・長期案件向け

```
はじめまして。【クライアントのご状況・例：社内でのAI活用を段階的に広げていきたい】というご趣旨を拝見し、継続的にご一緒できればと応募いたしました。

AIツールの導入・活用においては、【強みを1文・例：「何から始めるか」の意思決定を整理することが最初の壁になる】と考えており、【案件に直結する強み・例：業務の棚卸しから始め、現場の方が無理なく使える形を提案する】ことを大切にしています。

【継続の進め方・例：月1〜2回の勉強会・ワークショップ形式での対応が可能です】。まずは【CTA・例：現在のAI活用状況や課題感をヒアリングさせてください】。
```

---

### B：単発・トライアル向け

```
はじめまして。【案件の要点・例：AIツール活用のセミナーや研修を1回開催したい】というご依頼を拝見し、応募いたしました。

【強みを1文・例：業務効率化の視点から、参加者のレベルに合わせてAIの使いどころを具体的に提示する】スタイルで登壇・講師を担当してきました。【実績・例：個人事業主・中小企業向けの業務自動化ワークショップを実施した経験あり】です。

まずは【CTA・例：参加者の属性や目的をお聞かせいただき、プログラム案をご提示します】。ご検討よろしくお願いいたします。
```
