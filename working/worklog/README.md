# 作業フォルダ

## フォルダ構成

```
workslog/apply
├── README.md              （このファイル）
├── applylogs/                  （応募文ログ）
│   └── YYYYMMDD_案件ID_{CW/LC}.md    （タスクごとの作業履歴）
├── 応募文_案件ID.md

```

## ここに保存するもの
- **applylogs/** フォルダ：応募文ログ
- 応募文ドラフト（例：`20260824_応募文_案件ID.md`）
- 提案文・営業文のドラフト（例：`20260824_提案文_会社名.md`）

## 命名規則
- タスクログ：`applylogs/YYYYMDD_案件ID_{CW/LC}.md`
- 成果物：`YYYYMMDD_種類_対象.md`
