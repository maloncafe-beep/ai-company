# LINEスタンプ工場 制作手順（元シート1枚 → 40枚PNG → ZIP）

作成日：2026-10-09　範囲：元シートPNG → 40枚分割 → 検査 → ZIP

## 仕様（LINE）
| 種類 | 数 | サイズ |
|---|---:|---|
| スタンプ画像 | 8/16/24/32/40（基本40） | 最大 370×320（幅高さ偶数、1枚1MB以下） |
| メイン画像 | 1 | 240×240 |
| トークルームタブ画像 | 1 | 96×74 |

## 工程と担当（工程1は別AI。工場は工程2から）
| # | 工程 | 担当 |
|---|---|---|
| 1 | 40パターンの一覧を作る（[プロンプト追加仕様](LINEスタンプ_プロンプト追加仕様_20261009.md)を必ず付ける）→ `input/` に保存 | 別AI |
| 2 | 個別画像に分割（5列×8行の固定分割。はみ出し検査つき） | `split_sheet.py` |
| 3 | 透明背景・370×320・中央配置・余白（左右30/上下25px、最低20px）に統一、全数検査 | `split_sheet.py` |
| 4 | 01〜40.pngをZIP化（`--zip`。検査NGがあれば作らない） | `split_sheet.py` |
| - | 背景透過をCanva Proで行う場合のみ、工程2の前に透過済みシートを用意（任意） | 人 |

**固定分割が前提**：切り出し位置は調整しない。警告（区画端への接触）が出たら、
絵を直すのではなく**一覧を作り直す**（プロンプト追加仕様が守られていない）。

## 背景透過（任意：Canva Pro）
白背景のままでも `split_sheet.py` が外周とつながる背景色だけを透過にする（体の内側の白は残る）。
Canvaで透過する場合：シートをアップロード→背景リムーバ→背景透過ONでPNG書き出し→ `input/` に保存（RGBAなら自動でアルファを使用）。
透過後に毛並み・海/夕焼け背景のコマが欠けていないか確認する。

## 実行
```bash
cd ~/ai-company/line-stamps
python split_sheet.py input/<シート>.png --zip      # 40枚＋全数検査＋ZIP → output/<シート名>/ と .zip
python split_sheet.py input/<シート>.png --outline 4  # 白フチ付き（暗いトーク背景で黒文字が読める）
python split_sheet.py input/<シート>.png -n 16        # 16枚（8=2×4, 16=4×4, 24=4×6, 32=4×8, 40=5×8）
```
- 背景色は四隅から自動推定。許容差 `BG_TOLERANCE=8`（28だと明るい毛並みが抜けたため8に調整）
- 列×行がずれる場合は `GRIDS` を修正

## 検査（自動＋目視）
- [ ] 自動検査が全て合格（370×320・四隅透過・余白20px以上・1MB以下・区画端に接触なし）
- [ ] 暗背景に重ねて文字が読めるか（読みにくければ `--outline 4`）
- [ ] 毛並み・背景付きコマ（海/夕焼け）の欠けなし
