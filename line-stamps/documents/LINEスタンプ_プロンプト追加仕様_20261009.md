# LINEスタンプ制作プロンプト 共通仕様への追加文（一覧画像の作り方）

経緯：一覧シートを固定の5列×8行で切り出す方式は、絵が区画をはみ出すシート・デザイン変更で崩れた。
実地テスト（カワウソ）では、正方形の一覧だと1区画が約250×157px（横長1.6:1）になり、スタンプ（約1.16:1）が縦に収まらず、
胴体が隣の区画へ食い込んだ。区画の縦横比をスタンプに近づけるため、一覧は縦長3:4にする。
対策は切り出し位置を調整することではなく、**一覧を作る段階で区画内・余白つきに収めさせる**こと。
以下を、別AIに渡すLINEスタンプ制作プロンプトの共通仕様に追加する。

---

【余白・分割・個別ファイル化の厳守事項】

■ 一覧画像
* 40パターンを5列×8行で均等に配置する。
* 一覧画像全体は縦長（3:4〜2:3程度。例：1200×1600px）。1区画は横長になりすぎず、縦横比1.0〜1.3:1程度にする。
* 各スタンプを独立した区画の中央に配置し、隣のスタンプと十分な間隔を空ける。
* 各区画の境界に、文字・キャラクター・小物・装飾を絶対にはみ出させない。
* 各スタンプの外周には、区画サイズの最低10〜15％の安全余白を確保する。
* セリフの文字、キャラクターの耳・ひげ・前足・しっぽ、小物、ハート、花、効果線まで、すべて区画内に収める。
* セリフが長い場合は、文字を小さくするか改行して収める。余白を削って調整しない。
* 40個すべての絵柄・文字・装飾が隣接せず、個別に切り出せる配置にする。

■ 個別ファイル化
* 一覧画像を5列×8行の40区画に正確に分割する。
* 分割後の各画像は370×320px、PNG、背景透過とする。
* 各画像の中央にスタンプを配置し、上下左右に均等な透明余白を設ける。
* キャラクターや文字を画像端に接触させない。最も外側の要素から画像端まで、最低20px、推奨30〜40pxの透明余白を確保する。
* 余白が不足する場合は、スタンプ全体を縮小して中央に配置する。文字やキャラクターを切り取って調整しない。
* 白背景を透明化する場合は、白い部分がキャラクターや文字の内部にある箇所を誤って透明化しない。
* 01.png〜40.pngの連番で保存し、ZIPにまとめる。
* ZIP作成前に40ファイルすべてを検査し、文字切れ、隣接スタンプの混入、端への接触、背景透過の不具合がないことを確認する。

---

## 運用方針（優先順位）
- **最優先は納品する個別画像の品質**：370×320px・透過PNGで、文字切れなし・隣のスタンプの混入なし・端への接触なし。
- 一覧のピクセル数・比率は納品物ではないので固定しない。上記が満たせれば、1200×1600でなくてもよい。
- 目安は「1区画の縦横比が約1.0〜1.3:1」。使うAIが縦長を出せない場合の対応：

| 一覧のサイズ | 1区画の比 | 対応 |
|---|---|---|
| 3:4（1200×1600など） | 約1.2:1 | 理想。`--zip` まで通常どおり |
| 2:3（1024×1536など） | 約1.07:1 | 可 |
| 正方形のみ | 約1.6:1（5×8） | 不可。**2枚に分けて作る**（各20枚＝5列×4行、1区画は約250×313で余白が取れる） |

```bash
python split_sheet.py input/前半.png --grid 5x4 -o output/set            # 01〜20
python split_sheet.py input/後半.png --grid 5x4 -o output/set --start 21 --zip  # 21〜40 ＋ZIP（40枚）
```
- 合否の判定基準は一覧ではなく、`split_sheet.py` の全数検査（警告・NGなし）と目視。

## 余白の目安（370×320px）
| 項目 | 推奨設定 |
|---|---|
| 左右の透明余白 | 各30〜40px |
| 上下の透明余白 | 各25〜35px |
| 文字と画像端の最小距離 | 20px |
| 背景 / 配置 | 透過PNG / 中央寄せ |
