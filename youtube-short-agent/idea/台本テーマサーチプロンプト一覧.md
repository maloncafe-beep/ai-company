## プロンプト一覧

文字起こし内に出てきたプロンプトを、まとめて再掲します。

### 1. 悪い例: 丸投げ台本生成

```text
ダイエットのおすすめ動画の台本を書いて
```

### 2. 視聴者の本音を掘るプロンプト

```text
あなたはプロの心理カウンセラーです。
痩せたいと願っている30代女性が誰にも言えずに抱えている深夜の悩みや屈辱的なエピソードを10個具体的に列挙してください。
建前は不要です。
嫉妬、焦り、劣等感など負の感情にフォーカスしてください。
```

### 3. 競合の不満点を分析するプロンプト

```text
AIで〇〇について検索しているユーザーが、既存の動画では満足できていない不満点を分析してください。
Yahoo知恵袋やコメント欄の声をシミュレーションし、未解決の悩みを抽出してください。
```

### 4. 冒頭2秒のフックを作るプロンプト

```text
冒頭の挨拶は禁止です。
その代わり、視聴者が信じている常識を真っ向から否定し、このままだと危険だと警告する衝撃的な一言から始めてください。
```

### 5. ノウハウを失敗談に変えるプロンプト

```text
ノウハウを羅列するのではなく、そのノウハウを知らなかった時の失敗談や悲惨なエピソードを創作して語ってください。
視聴者が「分かるわ」と共感して痛みを感じるような、あるある話を盛り込んでください。
```

### 6. ジェットコースター構成のプロンプト

```text
1. 脅し。問題提起で不安を煽る。
2. 共感。読者の悩みを代弁して寄り添う。
3. 解決。独自の解決策を提示する。
4. 未来。それによって得られる理想の未来を見せる。
全体を通して感情の起伏が激しくなるようにドラマチックに演出してください。
```

## 使える型

この文字起こしから抽出できる、ショート動画用の基本型です。

```text
冒頭:
視聴者の常識を否定する、または危機感を与える。

共感:
視聴者が抱えている悩み、恥ずかしさ、焦り、劣等感を代弁する。

問題の正体:
なぜ今までうまくいかなかったのかを説明する。

解決策:
独自の視点や方法を提示する。

未来:
その方法を使うことで得られる変化を見せる。

行動:
次に何をすればいいかを明確に伝える。
```
