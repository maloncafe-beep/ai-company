# YouTubeショート分析指標基準

作成日: 2026-08-03

## 目的

YouTubeショート動画を収益化に向けて伸ばすために、投稿ごとの数値を同じ基準で記録・比較する。

この基準では、再生数だけで判断せず、以下の3点を中心に分析する。

- 最初の1〜3秒で見てもらえたか
- 最後まで見られたか
- 高評価・コメント・登録につながったか

特に心理学・雑学・健康・豆知識系のショートでは、最後まで見たくなる構成とリピート再生が重要になる。

## 最重要KPI

| 優先度 | 指標 | 目的 | 目標ライン |
| --- | --- | --- | --- |
| 1 | Viewed率 | スワイプされずに視聴された割合を見る | 70%以上 |
| 2 | 平均視聴率 | 最後まで見られたか、リピートされたかを見る | 80%以上 |
| 3 | 高評価率 | 視聴者の反応の強さを見る | 4%以上、理想6%以上 |
| 4 | 登録率 | チャンネル成長につながったかを見る | 0.3%以上 |
| 5 | コメント率 | 反応・共感・議論が起きたかを見る | 0.3%以上 |

## 指標の定義と計算式

### Viewed率

スワイプされずに「視聴を選択したユーザー」の割合。

YouTube Studioで確認できる場合は、以下を記録する。

- 視聴を選択したユーザー
- スワイプして離脱したユーザー

目安:

| 評価 | Viewed率 |
| --- | --- |
| 要改善 | 60%未満 |
| 合格 | 60%以上 |
| 良い | 70%以上 |
| バズ候補 | 80%以上 |

改善対象:

- タイトル
- 冒頭1秒
- 冒頭テロップ
- 最初に出す雑学・結論

### 平均視聴率

動画全体の長さに対して、平均でどれくらい視聴されたかを見る指標。

計算式:

```text
平均視聴率 = 平均視聴時間 ÷ 動画尺 × 100
```

YouTube Studio上の「平均視聴率」をそのまま記録する。

目安:

| 評価 | 平均視聴率 |
| --- | --- |
| 要改善 | 60%未満 |
| 合格 | 60%以上 |
| 良い | 75%以上 |
| 心理学・雑学系の目標 | 80%以上 |
| バズ候補 | 90%以上 |
| 強いリピートあり | 100%以上 |

100%を超える場合は、ループ再生や見直しが起きている可能性が高い。

改善対象:

- 台本のテンポ
- 雑学の順番
- 後半の失速
- オチや最後の一言
- 動画尺

### 高評価率

視聴回数に対して、高評価がどれくらい付いたかを見る指標。

計算式:

```text
高評価率 = 高評価数 ÷ 視聴回数 × 100
```

例:

```text
高評価 12 ÷ 視聴回数 1,908 × 100 = 0.63%
```

目安:

| 評価 | 高評価率 |
| --- | --- |
| 低め | 1%未満 |
| 普通 | 1〜3% |
| 良い | 4%以上 |
| とても良い | 6%以上 |
| 強い | 8%以上 |

注意:

高評価率は重要だが、Shortsでは平均視聴率の方が優先度は高い。

例:

- 高評価率15%でも平均視聴率50%なら伸びにくい
- 高評価率4%でも平均視聴率95%なら大きく伸びる可能性がある

改善対象:

- 視聴後に押したくなる納得感
- 保存したくなる実用性
- コメントしたくなる問いかけ
- 最後のCTA

### コメント率

視聴回数に対して、コメントがどれくらい付いたかを見る指標。

計算式:

```text
コメント率 = コメント数 ÷ 視聴回数 × 100
```

目安:

| 評価 | コメント率 |
| --- | --- |
| 合格 | 0.3%以上 |
| 良い | 0.5%以上 |
| とても良い | 0.8%以上 |

改善対象:

- 「あなたはいくつ当てはまりましたか？」
- 「どれが一番意外でしたか？」
- 「保存して後で見返してください」

### 登録率

視聴回数に対して、チャンネル登録者がどれくらい増えたかを見る指標。

計算式:

```text
登録率 = 登録者増加数 ÷ 視聴回数 × 100
```

目安:

| 評価 | 登録率 |
| --- | --- |
| 合格 | 0.3%以上 |
| 良い | 0.5%以上 |
| とても良い | 0.8%以上 |
| 強い | 1%以上 |

改善対象:

- チャンネルの専門性
- シリーズ感
- 次も見たくなるテーマ設計
- プロフィール・固定コメント・概要欄

## 再生数の目安

| 再生数 | 評価 |
| --- | --- |
| 300〜500回 | テスト配信で終了 |
| 1,000〜3,000回 | 普通 |
| 5,000〜10,000回 | 良作 |
| 30,000〜100,000回 | ヒット |
| 100,000〜1,000,000回 | バズ |
| 1,000,000回以上 | 大当たり |

公開直後の再生数だけで判断しない。Shortsは数日後、1〜2週間後に再評価されて伸びることがある。

## 現在のチャンネル初期方針

公開済み動画が少ない段階では、改善よりも検証を優先する。

まずは10本を目安に、以下の条件をなるべく固定する。

- 公開時間: 19:00
- 動画尺: 25〜35秒
- 雑学数: 同程度
- イラストの世界観: 同じ
- キャラクター・色調・背景: 同じ
- テロップ位置・フォント: 同じ
- ナレーション速度: 同じ
- 冒頭の型: 「99%が知らない ○○」を継続

実験する要素は、以下に絞る。

- テーマ
- タイトル
- 冒頭1つ目の雑学
- 最後のCTA

## 投稿後に記録するタイミング

| タイミング | 見る数字 | 目的 |
| --- | --- | --- |
| 公開1時間後 | 再生数、Viewed率、平均視聴率 | 初動の反応を見る |
| 公開24時間後 | 再生数、高評価、コメント、登録者増加 | 初期評価を見る |

## 判定ルール

### 伸びる可能性が高い動画

以下のうち2つ以上を満たす動画は、勝ちパターン候補として扱う。

- Viewed率70%以上
- 平均視聴率80%以上
- 平均視聴率100%以上
- 24時間で1,000再生以上
- 48時間で3,000再生以上
- 高評価率4%以上
- 登録率0.3%以上

### 冒頭に課題がある動画

以下の場合は、タイトル・冒頭1秒・冒頭テロップを改善対象にする。

- Viewed率60%未満
- 平均視聴率は高いのに再生数が伸びない
- 最初の3秒で大きく離脱している

### 台本に課題がある動画

以下の場合は、雑学の順番・テンポ・動画尺を改善対象にする。

- Viewed率は高いのに平均視聴率が60%未満
- 中盤以降で大きく離脱している
- 最後まで見られていない

### 反応に課題がある動画

以下の場合は、CTAや視聴後の満足感を改善対象にする。

- 平均視聴率80%以上なのに高評価率1%未満
- コメントがほぼ付かない
- 登録者増加がない

## 10本投稿後の分析方法

10本投稿したら、上位3本と下位3本を比較する。

比較する項目:

- テーマ
- タイトルの言い回し
- 冒頭1秒
- 1つ目の雑学
- 動画尺
- 平均視聴率
- Viewed率
- 高評価率
- 登録率
- 公開後24時間の伸び方

見るべきポイント:

- 伸びた動画に共通するテーマは何か
- 伸びなかった動画に共通する弱点は何か
- 平均視聴率が高いのに伸びない動画は、Viewed率が低くないか
- Viewed率が高いのに伸びない動画は、後半で離脱していないか
- 高評価率・登録率が高い動画は、シリーズ化できるか

## 収益化に向けた目標

Shorts中心で収益化を狙う場合は、安定して再生される型を作ることを優先する。

中期目標:

- 10本中1〜2本が1万再生を超える
- 平均視聴率80%以上の動画を増やす
- Viewed率70%以上の動画を増やす
- 毎月100万〜300万回再生を狙える投稿本数と型を作る

広告収益化の目安:

- 登録者1,000人
- 直近90日でShorts 1,000万回再生

## 運用メモ

初期段階では、2〜3本だけで方向転換しない。

まずは同じフォーマットで10本投稿し、数値を比較する。特に現在は、動画尺・イラスト・テロップ・ナレーション速度を固定し、テーマと冒頭だけを検証する。

現時点の仮説:

- 19:00投稿は相性が良い可能性がある
- 悩み解決系タイトルは相性が良い可能性がある
- 平均視聴率が高い動画は、追加配信で後から伸びる可能性がある
- 高評価率が低い場合は、最後に保存・コメント・共感を促す一言を入れる
