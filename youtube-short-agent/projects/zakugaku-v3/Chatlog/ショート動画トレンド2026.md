## 伸びる動画企画10選

### 型1: 結論先出し型（ハウツー・TIPS系）

**構成テンプレート:**

```
0〜3秒: 「○○する方法、これです」と結論を先に言う
3〜15秒: 具体的な3つのステップ
15〜45秒: 各ステップの詳細
45〜60秒: まとめ＋CTA「詳しくは長尺動画へ」
```

**向いている業種:** 士業・コンサル・教育・IT

**成功事例の特徴:**

-   タイトルに数字を入れる（「3分で分かる」「5つのコツ」）
-   冒頭で「保存推奨」と明示する（保存率が上がる）
-   テロップで重要情報を視覚化する

* * *

### 型2: 意外な事実型（雑学・知識系）

**構成テンプレート:**

```
0〜3秒: 「実は○○って知ってました？」と意外性を強調
3〜10秒: 簡単な事実の提示
10〜45秒: 詳しい背景と根拠
45〜60秒: まとめ＋問いかけ「あなたはどう思う？」
```

**向いている業種:** 教育・メディア・専門職

**成功事例の特徴:**

-   コメント欄で議論を誘発する
-   視聴者が「他人に教えたくなる」情報を提供する
-   出典・根拠を明記して信頼性を高める

* * *

### 型3: ビフォーアフター型（変化・成果系）

**構成テンプレート:**

```
0〜3秒: ビフォー映像「こんな状態でした」
3〜20秒: 問題の深刻さを説明
20〜45秒: 改善プロセス
45〜60秒: アフター映像＋まとめ
```

**向いている業種:** 整体・美容・リフォーム・フィットネス

**成功事例の特徴:**

-   ビフォー・アフターを同じアングルで撮影する
-   数値で変化を示す（「5kg減」「腰痛が8→2」）
-   お客様インタビューを30秒追加する

* * *

### 型4: 裏側・制作過程型（ドキュメント系）

**構成テンプレート:**

```
0〜3秒: 完成品の映像「これがどうやってできるか」
3〜15秒: 材料・準備の紹介
15〜45秒: 作業工程のタイムラプス
45〜60秒: 完成＋CTA
```

**向いている業種:** 飲食・ものづくり・工芸・製造業

**成功事例の特徴:**

-   タイムラプス・早回しで退屈さを回避
-   環境音を活かす（包丁の音・機械音など）
-   職人の表情を映す

* * *

### 型5: Q&A型（質問・回答系）

**構成テンプレート:**

```
0〜3秒: 質問を表示「○○って本当？」
3〜15秒: 結論を先に提示
15〜45秒: 詳細な説明と根拠
45〜60秒: まとめ＋「次の質問募集」
```

**向いている業種:** 士業・医療・教育・コンサル

**成功事例の特徴:**

-   コメント欄の質問から次のShortsを作る循環を作る
-   専門家の権威性を示す（資格・経歴・実績）
-   シリーズ化する（Q1、Q2、Q3...）

* * *

### 型6: ストーリー型（感情移入系）

**構成テンプレート:**

```
0〜3秒: 衝撃の一言「5年前、私は倒産寸前でした」
3〜15秒: 当時の状況の詳細
15〜40秒: 転機となった出来事
40〜60秒: 現在＋教訓
```

**向いている業種:** 経営者・起業家・教育

**成功事例の特徴:**

-   具体的な数字を入れる（「借金1,000万円」）
-   感情の起伏を作る（絶望→希望）
-   視聴者の共感を誘発する

* * *

### 型7: ランキング型（リスト系）

**構成テンプレート:**

```
0〜3秒: 「○○ランキング5位から発表」
3〜10秒: 5位と4位の紹介
10〜20秒: 3位と2位の紹介
20〜45秒: 1位の紹介と理由
45〜60秒: まとめ＋「あなたのお気に入りは？」
```

**向いている業種:** 小売・飲食・レビュー系

**成功事例の特徴:**

-   1位を最後まで引っ張ることで視聴完了率を上げる
-   コメント欄で議論を誘発する
-   シリーズ化する

* * *

### 型8: トレンド便乗型（時事ネタ系）

**構成テンプレート:**

```
0〜3秒: 最新ニュース・トレンドの紹介
3〜15秒: なぜ話題になっているかの説明
15〜45秒: 自社の見解・関連する情報
45〜60秒: まとめ＋「詳しくは長尺動画へ」
```

**向いている業種:** 幅広い業種で活用可能

**成功事例の特徴:**

-   トレンド発生から24時間以内に投稿する
-   自社の専門性と結びつける
-   独自の視点を加える

* * *

### 型9: デモンストレーション型（実演系）

**構成テンプレート:**

```
0〜3秒: 「これ使ったら驚くよ」と結果を予告
3〜15秒: 製品の紹介
15〜45秒: 実際に使っている様子
45〜60秒: 結果＋CTA
```

**向いている業種:** 小売・製造業・IT製品

**成功事例の特徴:**

-   音声を活かす（ASMR的要素）
-   結果を数値化する
-   視聴者のコメントに動画で返信する

* * *

### 型10: 日常ヴログ型（親近感系）

**構成テンプレート:**

```
0〜3秒: 「今日の仕事密着」
3〜15秒: 朝のルーティン
15〜45秒: 一日の仕事風景
45〜60秒: 退勤＋CTA
```

**向いている業種:** 医療・サービス業・起業家

**成功事例の特徴:**

-   過度な演出をしない（リアリティ重視）
-   ファン化を目的とする
-   定期的に投稿する

## 視聴完了率を高める3つの技術

### 技術1: 最初の1秒に「動き」を入れる

静止画・ロゴから始まる動画は3秒以内に90%のユーザーがスワイプします。最初の1秒で「動き」を入れることで離脱を防げます。

### 技術2: 3秒ごとにビジュアルを変える

同じカットが5秒以上続く動画は視聴完了率が下がります。カメラアングル・テロップ・BGMのいずれかを3秒ごとに変化させるのが鉄則です。

### 技術3: 最後の5秒に「次の誘導」を入れる

Shortsの最後に「長尺動画では更に詳しく解説しています」などの誘導を入れることで、チャンネル登録・長尺動画視聴につながります。

より詳しい冒頭の技術については[会社紹介動画の構成テンプレート](https://0120.co.jp/blog/video-41/)でも解説しています。
