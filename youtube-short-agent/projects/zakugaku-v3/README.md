# 雑学ショート Rev3.0

## 目的

収益化を狙う雑学ショートの新構成を管理するプロジェクト。

従来の「1本7〜10雑学、1〜2分」の羅列型から、今後は「1雑学・1テーマを1〜2分で深掘りする」形式へ移行する。

## 背景

- 1行1雑学の羅列型は、古い動画を除くと類似動画が減ってきているように見える
- 羅列型は台本だけで作りやすい反面、量産型・低独自性・AI生成的に見えやすい
- いらすとや系の素材を毎回同じように使うと、動画ごとの差分が弱くなる
- YouTube側から「広告を載せる価値がある独自コンテンツ」と見られるには、台本だけでなく映像面の独自性も必要
- 直近で1000〜2000再生付近で止まる、またはショートフィード初回露出が極端に小さい傾向が出ている

## Rev3.0 の定義

Rev3.0 は、3分以内の縦型Shortsとして成立する「1本完結型の雑学ストーリー」。

従来のように、1画面ごとに独立した雑学を並べない。1本の動画全体で、1つの疑問・誤解・行動・心理を深掘りする。

## 基本構成

1. 意外な結論
2. 視聴者の悩み・違和感
3. 具体的な日常場面
4. なぜそうなるのか
5. 多くの人がしている誤解
6. 本当の原因
7. 今日からできる行動
8. 最後に残る一文
9. コメント・保存誘導

## 制作方針

- 1本につき中心テーマは1つ
- 雑学を増やして尺を作らない
- 視聴者の考え方が1つ変わる動画にする
- 30〜50代にも自然に刺さる言葉にする
- 説教感ではなく、代弁と気づきで進める
- サムネ、タイトル、冒頭1秒、本文、コメント誘導を同じ本音に向ける

## 映像方針

AI生成画像を多用するとクレジットコストが重いため、毎回AI生成には頼らない。

既存素材を使う場合も、量産感を減らすために以下を変数として扱う。

- 背景色
- 構図
- 切り抜き
- ズーム
- 図解要素
- テキスト配置
- 表情差分
- 比較表
- 冒頭1秒の見え方

## 評価指標

評価は以下の順番で切り分ける。

1. インプレッション
2. 視聴回数
3. EngView
4. 視聴を継続
5. 平均視聴率
6. 平均視聴時間
7. 登録者増加
8. コメント
9. 保存されそうな内容か

インプレッションが極端に低い場合は、台本本文以前に、サムネ、タイトル、配信対象、公開予約運用、YouTube側のシステム要因を疑う。
