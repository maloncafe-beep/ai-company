---

## 1. 入力ファイル（毎回渡すもの）

| ファイル | 形式 | 説明 |
|---------|------|------|
| 音声ファイル | `.wav` | VOICEVOXで生成したナレーション音声 |
| 台本テキスト | `script.txt` | UTF-8、下記フォーマット必須 |
| 背景画像 | `bg.png` | AI生成推奨（9:16縦型） |
| タイムスタンプ | `whisper_segments.json` | Whisper（medium）で生成したJSON |

### 台本テキストのフォーマット

```
【タイトル】
動画のタイトル（YouTube用）

【ハッシュタグ】
#タグ1 #タグ2

【台本】
1行目の文章。

2行目の文章。
3行目の文章（同じページに並べる場合は空行なしで続ける）。

次のページの文章。
```

- `【台本】` 以下のセクションのみ動画テキストに使用
- **空行 = ページ区切り**（1画面分のテキストブロック）
- 同じ段落内の行は1画面に同時表示
- ページあたり1〜3行が目安

## 2. 動画構成

```
[ カウントダウン 3秒 ] → [ 本編（WAV長さ） ]
```

| セクション | 時間 | 内容 |
|-----------|------|------|
| カウントダウン | 3秒固定 | 3→2→1のカウント。音声なし |
| 本編 | WAVの長さ | テキストページ切り替え＋Ken Burns |
| **合計** | **WAV長さ＋3秒** | |

> エンディングカードは台本の最後の行（「チャンネル登録と高評価をお願いします」）で代替。

## 6. テキスト表示

### 6-1. フォント

| 箇所 | フォント | サイズ |
|------|---------|--------|
| タイトル（常時表示） | HG隷書体 `HGRSGU.TTC` | 52px |
| 本文 | HG明朝E超太字 `HGRME.TTC` | 76px |
| カウントダウン数字 | HG明朝E超太字 `HGRME.TTC` | 280px |

### 6-2. テキストカラー

| 要素 | 色（RGBA） |
|------|-----------|
| タイトル | `(255, 245, 200)` クリーム＋ドロップシャドウ |
| 本文 | `(255, 255, 255)` 純白 |
| 本文シャドウ | なし（背景ボックスで代替） |

### 6-3. テキスト背景ボックス

段落（ページ）のテキストブロック全体の背後に半透明ボックスを配置。

| 設定名 | 値 |
|-------|----|
| 色 | 黒 `(0, 0, 0)` |
| 透明度 | テキスト alpha の65%（ライズと連動） |
| 角丸 | 16px |
| 余白 | 左右20px、上下12px |

### 6-4. ページ切り替え方式

- 台本の**空行でページを切り替え**（前ページは完全消去）
- Whisper タイムスタンプで各行の開始時刻を特定
- ページが切り替わった瞬間に**そのページの全行を一括表示**

### 6-5. ライズエフェクト（テキスト出現アニメーション）

| 設定名 | 値 |
|-------|----|
| `RISE_DURATION` | 0.5秒 |
| ライズ距離 | 70px（下から上へ） |
| イージング | ease-out cubic |
| 対象 | テキストブロック全体（ボックスも同時） |
| トリガー | ページ開始時点（`page_start`） |

### 6-6. 折り返し処理

- 長い行は自動折り返し（最大幅 = WIDTH - TEXT_PAD_X × 2 = 960px）
- **折り返し後の実表示行数**を事前計算してY座標を割り当て（重なり防止）
- テキストブロックは表示エリアの中央に縦方向センタリング

## 7. カウントダウン

| 項目 | 設定 |
|------|------|
| 秒数 | 3→2→1 |
| 背景色 | `(28, 18, 8)` 暗いセピア |
| 数字色 | `(210, 175, 110)` ゴールドセピア |
| 円・ライン色 | `(160, 120, 70)` セピア |
| フィルムノイズ強度 | 30 |
| フィルム穿孔 | 両サイドに9個ずつ |
| スクラッチライン | 8%の確率 |

## 8. タイムスタンプ（Whisper）

| 項目 | 設定 |
|------|------|
| モデル | `medium` |
| 言語 | 日本語 `language='ja'` |
| 出力 | `work/whisper_segments.json` |
| セグメント分割 | 台本の行数に合わせて手動調整 |

### Whisper セグメントの手動調整手順

Whisperが長い塊でセグメントを返した場合、台本の行数に合わせて時間を比例配分して分割する。

```json
[
  {"start": 0.0, "end": 7.6, "text": "..."},
  {"start": 7.6, "end": 9.83, "text": "..."}
]
```
