# 西国三十三所・海外向け巡礼VLOG

## 目的

過去のブログ記事ソースと写真資産を活用し、海外向けに西国三十三所を紹介する巡礼VLOGチャンネルを立ち上げる。

勝海舟の言葉ショートのような名言・静止画・教訓型から、実際の訪問記録、写真、場所の空気感、巡礼ルートを軸にした独自性のある動画へ移行する。

## 背景

- 名言系ショートは、AI量産型に見えやすい構成になりやすい
- お寺系コンテンツは、過去ブログ記事と写真が大量にあり、素材不足になりにくい
- 国内向けの寺社情報はブログ、旅行メディア、寺社巡り動画が多く競合しやすい
- 西国三十三所は英語圏では四国遍路ほど認知が高くなく、海外向けに「日本最古の巡礼」として打ち出せる
- 現地写真、訪問体験、ブログ本文を使うことで、AIだけで作った動画との差分を出しやすい
- 旅行VLOG形式にすることで、ショート動画から札所別ナレッジページ、写真アルバム、観光案内、商品ページへの展開もしやすい
- 将来的には、日本の観光地以外の写真アルバムを海外向けに販売する導線へ広げられる

## チャンネル方針

- テーマは、西国三十三所を海外向けに紹介する巡礼VLOG
- 英語圏向けには `Japan's Oldest Pilgrimage: Saikoku 33 Kannon Temples` を中心キーワードにする
- 観光ガイドだけでなく、行った気になる、心が整う、少し学べる動画にする
- 派手な煽りより、写真、空気感、短い発見を重視する
- 生成AI素材を主役にせず、実写真と実体験を主役にする
- AIナレーションを使う場合も、元記事と写真に基づいた編集として見せる
- Shortsは完結コンテンツではなく、ブログ、ナレッジページ、写真アルバム、観光案内ページへの入口として設計する
- 初期フェーズでは、ShortsをYouTube単体収益ではなく海外向け知識入口として扱う
- 初期導線は `Shorts → 海外版ブログ → 地域観光サイト` を基本にする
- 最初は `Shorts → 地域観光サイト` のショートカット導線も許容する
- 正しい紹介方法を最優先し、必要な情報は市町村観光課・観光協会・公式サイトへリンクする
- 全情報を自分のブログに抱え込まず、公式・地域観光情報への橋渡しをする
- 実際に行っている強みを活かし、行ってがっかりしないよう期待値を調整する
- 平均的に全部を褒める観光案内ではなく、何を目的に行くと満足しやすいかを正直に示す
- AI的なスピリチュアル演出に寄せすぎず、御朱印、国宝仏像、庭園、周辺体験など実際の訪問目的を1本ごとに仮設定する
- 西国33は場所ごとにフォーカス対象を変え、札所単体で弱い場合は周辺散策や近くの国宝仏像などへ展開する
- 高野山・奥の院のような墓所・霊場・聖域は、神秘的な観光素材として消費しすぎず、敬意と正確性を優先する
- 西国33再訪で写真・動画素材を強化し、海外版ブログと写真アルバムの品質を上げる
- 現状素材では写真をつないだShortsを基本形にし、再訪後は短い動画素材を足して現地感を補強する
- 情報として足りない部分は、Shorts内ではなく海外版ブログの文章で補う
- 映像美ではなく、既に行った有名地から近くの見落とし場所へ展開するストーリーを優先する
- 上位コンセプトは `Quiet Japan` や `Hidden Japan` に広げられる余地を残す
- 映像美だけで勝負せず、行きたいが行きにくい札所を写真と情報で知れる導線にする
- 既存ブログ資産を海外向けに再編集し、アフィリエイトや自社商品への導線は後段で検証する
- ブログ資産は、世界遺産を入口、西国33を中心シリーズ、新西国33を深掘り・差別化領域として扱う
- 御朱印は、動画や海外版ブログの締め、巡礼記録、スタンプシート的な理解補助として扱う。ただし印影そのものは販売対象にしない。ディープな日本好きには、御朱印帳を旅の記録やお土産として紹介できる
- 京都観光では御朱印帳が一気に埋まりやすく、御朱印は写真よりレアな手書きの漢字アートとして海外向けに見せられる
- 御朱印は約600円で受けられる手書きの寺社記録として価格感を伝えやすい。ただし金額は寺社や形式により異なるため目安にする

## 基本動画フォーマット

### Shorts

- 尺: 35〜45秒を初期基準にする
- 構成: 冒頭3秒、札所番号、見どころ写真3〜5枚、必要に応じた短い動画、行きにくいが知る価値がある理由、海外版ブログへの導線
- 目的: 西国三十三所を知ってもらい、海外版ブログまたは地域観光サイトへ進む入口を作る

### 長尺候補

- 尺: 3〜8分から検証する
- 構成: 巡礼全体の位置づけ、札所の見どころ、歴史背景、現地写真、訪問メモ、アクセス、周辺情報
- 目的: ブログ記事を動画資産に変換する

## 制作順

1. 過去ブログ記事と写真を確認する
2. 西国三十三所の札所番号、英語表記、地域、写真枚数を整理する
3. 1札所1テーマで企画メモを作る
4. Shorts台本を作る
5. 写真リストを作る
6. ナレーションと画面構成を作る
7. 投稿後に分析ログへ記録する
8. 伸びたテーマを長尺化、ナレッジページ強化、再訪撮影、写真アルバム、観光案内ページ、アフィリエイト、商品ページ候補にする
