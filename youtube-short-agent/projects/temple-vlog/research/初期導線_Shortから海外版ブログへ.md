# 初期導線: Shortsから海外版ブログへ

## 結論

初期フェーズでは、YouTube単体の収益化を狙わない。

Shortsは収益媒体ではなく、海外視聴者が西国三十三所、世界遺産、新西国三十三所を知るための入口として使う。

この導線は維持したまま、西国33再訪でより良い写真・動画素材を撮り、海外版ブログや写真アルバムの素材品質を上げる。

## 初期導線

```text
1. YouTube Shorts
   ↓
2. 自分のブログの海外向け版
   ↓
3. 地域の観光サイト
```

最初は、`1. YouTube Shorts` から `3. 地域の観光サイト` へ直接送るショートカット導線でもよい。

## なぜ長尺YouTube動画を最初に作らないか

- 制作負荷が高い
- AIを使った動画は、YouTube単体での収益化が現状かなり厳しい
- 勝海舟の言葉ショートから方向転換した理由も、AI量産型に見えやすくなったため
- まず必要なのは動画収益ではなく、海外視聴者の知識入口を作ること

## Shortsの役割

Shortsは、以下だけを担う。

- 知られていない場所を見つけてもらう
- 行きたいが行きにくい場所への興味を作る
- 西国三十三所や新西国三十三所の存在を知ってもらう
- 詳しい情報は海外版ブログへ送る

Shorts内で、歴史、アクセス、観光情報、商品案内をすべて説明しない。

現状素材では、写真をつないだShortsが基本形になる。写真スライド型でも入口としては成立するが、情報収集の入口として使う場合は、文章や補足情報が必要になる。

その補足は、Shorts内に詰め込まず、海外版ブログ側で受け止める。

## 海外版ブログの役割

海外版ブログは、Shortsで生まれた興味を受け止める場所。

役割:

- 寺社の基本情報を英語で整理する
- 写真を見せる
- なぜ知る価値があるかを説明する
- 行きやすさ、行きにくさを説明する
- 公式・地域観光サイトへ送る
- 写真だけでは分かりにくい背景やアクセスを文章で補う
- 写真スライド型Shortsの不足分を補完する

日本語ブログの翻訳ではなく、海外旅行者が知りたい順番に再編集する。

## 地域観光サイトの役割

地域観光サイトは、実際の訪問行動に近い情報を補完する場所。

役割:

- 公式性のある情報を補う
- アクセス、営業時間、イベント、交通などの最新情報へ送る
- 自分のブログで断定しすぎない情報を補完する
- 市町村観光課や観光協会にとっても、送客につながる導線にする

全部を自分のブログで説明しきらなくてよい。必要な情報があれば、地域観光サイトや公式情報へ送る。

## 初期CTA

ShortsのCTAは、販売ではなく知識導線にする。

例:

- Read the short guide in English.
- Learn more in the photo guide.
- See the temple details and official travel info.
- If you cannot visit yet, start with the guide.
- Check the local travel information from the link.

## 初期フェーズでやらないこと

- YouTube単体の広告収益を主目的にしない
- 長尺動画を量産しない
- Shortsからいきなり商品販売へ強く誘導しない
- アフィリエイトを前面に出しすぎない
- 映像美だけで勝負しない

## 初期フェーズで見る数字

- Shortsからブログへのクリック
- ブログ内の滞在
- 地域観光サイトへのクリック
- どのカテゴリが反応されるか
- 世界遺産、西国33、新西国33の比較

## 段階的な発展

### Phase 1

Shortsから海外版ブログ、または地域観光サイトへ送る。

### Phase 2

反応がある記事に、写真アルバム、関連記事、観光案内を足す。

西国33再訪で不足素材を撮影し、英語ページと写真アルバムの質を高める。

写真だけで構成したShortsに、短い動画素材を足して現地感を強める。

### Phase 3

アフィリエイトや自社商品を自然に追加する。
