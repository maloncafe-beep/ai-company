# 実訪問ベースの期待値調整

## 基本方針

この企画の強みは、実際に現地へ行っていること。

そのため、見栄えだけで期待値を上げすぎる案内ではなく、実際に行ったときにがっかりしにくい案内を作れる。

## なぜ重要か

海外向けの寺社・観光動画は、映像や言葉で期待値を上げすぎることがある。

しかし、実際に訪れる観光客にとって重要なのは、映像の美しさだけではない。

- どれくらい行きやすいか
- 何を目的に行くべきか
- 何を期待しすぎない方がよいか
- 周辺と組み合わせると満足度が上がるか
- 写真で見た印象と現地の印象がズレないか

一般的な観光案内は、平均的に紹介し、特段強い魅力がない場所も盛って書きがちである。

その結果、実際に行った観光客が「思ったほどではなかった」と感じることがある。

海外観光客が口コミを重視するのは、公式案内や観光記事よりも、実際に行った人の期待値調整を知りたいからでもある。

## 実訪問ベースでできること

- 写真では分かりにくい距離感を伝える
- 現地で迷いやすい点を補足する
- 観光客が見落としやすい場所を伝える
- 札所単体で弱い場合は周辺と組み合わせる
- 「ここだけを目的にすると弱いが、周辺と合わせると良い」と言える
- 「期待しすぎると違うが、この目的なら行く価値がある」と整理できる

## 案内の考え方

悪い案内:

- とにかく神秘的
- 絶対に行くべき
- 人生が変わる場所
- 写真映えだけで推す
- 平均的に全部を褒める
- 特段強い魅力がないのに盛る

良い案内:

- 御朱印目的なら行く価値がある
- 国宝仏像を見るなら強い
- 奈良まち散策と組み合わせると良い
- 行きにくいが、静かな場所を見たい人には合う
- ここだけでなく、近くの公式観光情報も確認するとよい
- この目的の人には合うが、別の目的なら優先度は下がる

## 海外版ブログでの表現

- This place may not be for everyone, but it is worth knowing if you like...
- Do not visit only for a dramatic view. Visit for...
- It is better as part of a short walking route.
- The temple is quiet, but the main reason to visit is...
- Check the official site before visiting.

## 判断ルール

- 自分が実際に行った印象を残す
- 盛りすぎない
- 平均的に全部を褒めない
- 目的を明確にする
- がっかりしそうな点も、必要なら柔らかく書く
- 公式情報へのリンクで最新情報を補う
