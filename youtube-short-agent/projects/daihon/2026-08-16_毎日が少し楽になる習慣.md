# 今日からできる 毎日が少し楽になる習慣

【台本】

毎日を楽にする人ほど全部を頑張ろうとしない

朝一番に今日やらないことを1つ決めておく

面倒な用事は2分だけ手をつけて勢いを作る

予定は詰め込まず30分の空白を残しておく

返信はすぐ返さず自分の都合に合わせて決める

物を減らすだけでも毎日の小さな判断が減る

嫌なことは後回しにせず最初の5分だけ進める

一日の終わりに明日の予定を3つだけ決めておく

疲れた日は完璧を目指さず60点で終わらせる

悩みは頭の中だけで考えず紙に全部書き出す

スマホの通知を減らすだけでも気が散りにくくなる

今から2分だけ面倒なことを始めてみる

## セルフチェック

・冒頭3秒で興味を引けるか
→ ○ 「楽にする人ほど全部を頑張らない」という逆説で開始。

・最後まで見たくなる構成か
→ ○ 努力→予定→行動→時間→返信→物→先延ばし→計画→完璧主義→悩み→スマホ→実践と切り口を分散。

・新規性は十分か
→ ○ 「今日やらないことを決める」「返信を急がない」「60点で終える」など、頑張ることを前提にしない内容を配置。

・数字は適切に使われているか
→ ○ 1つ、2分、30分、5分、3つ、60点など具体的な数字を使用。

・すぐ実践できる内容が含まれているか
→ ○ 12個中ほぼすべてが今日から実践可能。

・情報の種類が偏っていないか
→ ○ 時間管理、予定、片付け、返信、行動、睡眠前の計画、悩み、スマホなど幅広く構成。

今回は「毎日を楽にする＝何か新しいことを頑張る」という方向ではなく、**やることを減らし、判断を減らし、余白を作る**という切り口にしています。

最後は「2分だけ始める」という極端にハードルの低い行動にして、視聴後すぐ試せる形で締めています。
