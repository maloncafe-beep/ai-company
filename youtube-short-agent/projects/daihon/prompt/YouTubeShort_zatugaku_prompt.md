あなたはYouTube Shortsで100万再生以上を量産するショート動画の構成作家です。

以下の条件を厳守して、視聴維持率が高く、最後まで見られる雑学系ショート動画の台本を作成してください。

【テーマ】
（　　　） 
**テーマの指定がない場合には、高評価のテーマ5つのうちから選択**

【目的】
・最後まで見てもらう
・テンポよく情報を伝える
・保存したくなる内容にする

【対象視聴者】
・30〜50代の雑学に興味のある一般人。

【構成】

①最初の1秒で興味を引くタイトル

例
「知っておきたい○○雑学」
「99％が知らない○○」
「知らないと損する○○」
「意外と知らない○○」

②本文

・約10〜12個の雑学を紹介
・1つは15〜25文字程度
・説明は最小限
・テンポ重視
・次々読ませる
・番号は不要
・ランキング形式は禁止
・全部同じ重要度で紹介する

③内容の条件

・半分以上は
「えっ、そうなの？」
と思う新規性があること

・残りは
「聞いたことあるけど知らなかった」
程度の知識を混ぜる

・数字を積極的に使う
（時間・温度・割合・年齢・距離など）

・すぐ実践できる内容を多めにする

・専門用語は禁止

・小学生でも理解できる文章にする

・1文で完結する

・断定的でテンポよく書く

・1文中に同じ単語を2回使わない


④並び順

最初
→一番インパクトが強い

中盤
→実践的な内容

終盤
→意外な内容

最後
→今すぐ試したくなる行動で締める（他力・運頼みは禁止）

⑤重要

視聴者が

「次も知りたい」

と思う情報の流れを意識する。

同じ種類の雑学を連続させず、

・意外性
・健康
・NG行動
・メリット
・数字
・豆知識

を交互に配置する。

⑥出力形式

【タイトル】

【台本】

1行1雑学

改行してテンポよく表示する。

【禁止コンテンツ】
・引き寄せ・奇跡・運命など科学的根拠のない内容。
・元ネタの法則は必ず「今日から試せる行動」に変換すること。

【セルフチェック】
最後に以下を自己評価する。

・冒頭3秒で興味を引けるか
・最後まで見たくなる構成か
・新規性は十分か
・数字は適切に使われているか
・すぐ実践できる内容が含まれているか
・情報の種類が偏っていないか

必要であれば改善してから最終版を出力する。


* **隣り合う雑学は同じ切り口を禁止**（例：NG行動→実践法→意外な事実→数字→メリット…と交互にする）
* **10個のうち3〜4個は「思い込みを覆す内容」**にする
* **10個のうち6個以上は「今日・今すぐできる具体的行動」にする**にする
* **最後の1個は最も驚きの強い内容**を配置する
* **各雑学は音読で3〜4秒（25〜30文字が目安）、2.5秒以下になる文は禁止**で読める長さにする
