# LP-GPT for Codex

商品・サービス・セミナー・イベントの情報から、スマホ向けLPの構成、コピー、画像、機能するHTMLを制作するCodexプラグインです。

この配布版には、実案件、顧客データ、生成済みLP、個人用パス、APIキー、LINE/R2/社内Webhook連携を含めていません。

## 必要なもの

- Codexを利用できる環境
- ローカルファイルを書き込める作業フォルダ
- 画像生成を行う場合は、利用中のCodex環境で画像生成機能が使えること

外部公開、フォーム接続、デプロイは必須ではありません。ローカルHTMLまでで利用できます。

## インストール

### ダウンロードしたフォルダから追加する

1. ZIPを展開する。
2. ターミナルで次を実行する。`/path/to/lp-gpt-public` は展開したフォルダの絶対パスに置き換える。

```bash
codex plugin marketplace add /path/to/lp-gpt-public
codex plugin add lp-gpt@lp-gpt-public
```

3. Codexデスクトップアプリを再起動する。
4. 新しいタスクを開始し、LP-GPTを使う。

### GitHubから追加する

このフォルダをGitHubリポジトリとして公開した場合は、次の形で追加できます。

```bash
codex plugin marketplace add OWNER/REPOSITORY
codex plugin add lp-gpt@lp-gpt-public
```

## 使い方

新しいタスクで、商品情報と希望をそのまま伝えます。

```text
$lp-gpt を使って、このオンライン講座のスマホLPを作ってください。
商品情報は添付資料にあります。申込みURLはまだないので仮モーダルにしてください。
```

参考画像がある場合は一緒に添付します。

```text
$lp-gpt を使って、添付した参考画像の雰囲気でこの商品のLPを作ってください。
日本語の文章は画像に焼き込まず、あとから編集できるHTMLテキストにしてください。
```

標準では、現在の作業フォルダに次の成果物を作ります。

```text
lp-gpt-output/<project>-<timestamp>/
├── brief.md
├── copy.md
├── index.html
├── assets/
├── screenshots/
└── build-log.md
```

## 同梱スキル

- `lp-gpt`: ヒアリング、構成、コピー、制作方式の選択、納品管理
- `image2-mobile-lp-builder`: 縦長画像スライス、HTML機能化、スマホQA

## プライバシーと安全性

- プラグイン自体に外部通知や外部ストレージ連携はありません。
- APIキーやパスワードを成果物へ保存しません。
- デプロイや外部アップロードは、利用者が明示的に依頼した場合だけ行います。
- 生成物は、利用者が指定したローカル作業フォルダへ保存します。
- 入力する商品情報、画像、ロゴ、文章について、利用者自身が使用権限を確認してください。

## 配布前の確認

このフォルダ以外の実案件データを追加しないでください。特に次の名前のフォルダやファイルは配布物へ入れないでください。

- `inbox/`
- `outputs/`
- `.env`、秘密鍵、認証ファイル
- 顧客名を含むフォルダ
- ライセンス不明のフォント、写真、ロゴ

この配布物にはライセンスを設定していません。一般公開する前に、配布条件に合うライセンスを決めてください。
