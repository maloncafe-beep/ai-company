# 架空案件の入力例

以下は使い方を示すための完全な架空案件。実在する人物、会社、商品、実績ではない。

## ユーザーからの依頼例

```text
朝の時間を整えるオンライン講座のLPを作ってください。

対象は、仕事と家事で一日が終わってしまい、自分の時間を作れない30〜40代です。
90分のオンライン講座で、参加費は3,000円。開催日は9月12日 10:00〜11:30です。
講座では、前夜の準備、朝15分の使い方、無理なく続ける一週間の計画を扱います。
CTAは「オンライン講座に申し込む」。URLはまだありません。
白と淡いオレンジを基調に、落ち着いて親しみやすいスマホLPにしてください。
実績やお客様の声はまだないので入れないでください。
```

## brief.md の要点例

- LPの目的: オンライン講座の申込み
- 主CTA: オンライン講座に申し込む
- 主CTA URL: 未設定。仮モーダルを使用
- ターゲット: 自分の時間を作りにくい30〜40代
- 提供内容: 90分のオンライン講座
- 価格: 3,000円
- 日時: 9月12日 10:00〜11:30
- トーン: 白、淡いオレンジ、落ち着き、親しみ
- 実績・推薦: 使用しない
- 制作方式: 日本語の正確さを優先するHTMLテキスト方式

## 構成例

1. 講座名、日時、価格、主CTA
2. 忙しい朝に関する共感
3. 90分で扱う3つの内容
4. 受講後に持ち帰れる一週間の計画
5. こんな人におすすめ
6. 開催概要
7. FAQ
8. 最終CTA

実在しない実績や講師プロフィールを補完しない。
