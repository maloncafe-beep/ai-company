# みかみスタイル note記事執筆

## ワークフロー

### Step 1: コンテキスト読み込み（必須）
以下を**すべて**読む:
1. `config/author-profile.md` — みかみの文体・トーン
2. `config/addness-philosophy.md` — アドネス哲学
3. `config/writing-style-guide.md` — ライティングスタイルガイド
4. `research/` 配下の関連リサーチメモ（あれば）

### Step 2: テンプレート選択
テーマに最適なテンプレートを選ぶ:

| テンプレート | いつ使う |
|------------|---------|
| `experience-review.md` | 何かを試した体験を語るとき |
| `philosophy.md` | 根源的な問いに答えるとき |
| `company-story.md` | アドネスの軌跡やビジョンを語るとき |
| `vision-product.md` | 新概念の提唱やプロダクト紹介のとき |

### Step 3: 構成案をユーザーに確認
テンプレートをベースに見出し案を作り、確認を取る。

### Step 4: 執筆
以下のルールに従って執筆する。

### Step 5: 保存
`articles/drafts/YYYYMMDD-タイトル.md` で保存。

## 執筆ルール（みかみスタイル）

### 冒頭（最重要）
- 「どうも！（アドネス株式会社の）みかみです。」で始める
- AI使用の開示を入れる
- 最初の3行で「え、何それ？」と思わせるフックを入れる
- 「この記事では〜」的な退屈な始め方は**絶対禁止**

### 本文の文体
- 一人称は「僕」
- カジュアル口語体ベース
- **太字を超多用**（各段落に最低1つ）
- 一文は短く（60文字以内）
- 改行を多めに（1〜3文で改行）
- 「笑」を適度に使う
- 問いかけ → 即答え のパターンを多用
- 体験談・エピソードを必ず入れる

### 語尾の注意
- 同じ語尾が3回連続しないようにする
- 「〜です。」「〜ます。」だけでなく、「〜なんよね。」「〜でしょ？」「〜なわけです。」を混ぜる
- 断言するときは「〜です。断言します。」

### 太字の使い方
- 核心メッセージ: **その段落で一番言いたいこと**
- 転換点: **「でもね、ここに重要な前提がある。」**
- 独立した強調: 2〜3行を太字にして独立させる

### noteエディタのフォーマット制約（重要）
noteのエディタで使えるのは以下のみ:
- `#` 見出し / `##` 小見出し（`###`以下は**使えない**）
- `- ` `+ ` `* ` 箇条書きリスト
- `1. ` `2) ` 番号付きリスト
- `> ` `>> ` 引用ブロック
- 太字（エディタ上でテキスト選択 → B）
- `---` 区切り線

**使えないもの**: `###`以下の見出し、テーブル、コードブロック、Markdownの太字記法 `**text**`

下書きファイルでは `**太字**` や `###` を使ってOK（可読性のため）。
ただし**noteに貼り付ける際の変換**を意識して、テーブルは使わず箇条書きで代替する。

### アドネス哲学への着地（必須）
- 記事の後半で必ずアドネス哲学に接続する
- Well-being / LTR / Giver・Taker / 価値提供 / アドる のいずれか
- 押しつけがましくなく、ストーリーの自然な帰結として

### 締め方
1. 熱いメッセージ
2. 「一緒にやろう」の呼びかけ
3. CTA: DMリンク (https://x.com/mikami_01)
4. P.S. / P.P.S. / P.P.P.S.（必須）
5. 署名: アドネス株式会社 代表取締役 三上 功太 + 日付

## 品質チェック

記事が書けたら以下を確認:
- [ ] 冒頭3行にフックがあるか
- [ ] 太字が十分に使われているか（各セクション最低1つ）
- [ ] 「笑」が適度に入っているか
- [ ] 体験談・エピソードが含まれているか
- [ ] アドネス哲学への着地があるか
- [ ] P.S.がついているか
- [ ] 4000文字以上あるか
