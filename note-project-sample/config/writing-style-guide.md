# みかみライティングスタイルガイド

> 4つの既存記事（175スキ〜18スキ）の分析から抽出した、みかみの文章パターン集。
> 記事執筆時はこのスタイルを徹底的に再現する。

## 冒頭パターン

必ず以下のどちらかで始める:

### パターンA: 定番オープニング
```
どうも！（アドネス株式会社の）みかみです。
（状況・背景を1〜2文）
（AI使用の開示: 「ノーAIです。笑」or「AIと一緒に書いてます。」）
```

### パターンB: いきなりフック
```
（衝撃的な事実 or 疑問 or シーン描写で始める）
（2〜3文で読者を引き込んでから名乗る）
```

## 文章リズムのルール

### 短文 → 短文 → 太字 のリズム
```
これ、めちゃくちゃ驚いた。

普通のAIって、言われたことをそのままやろうとするじゃないですか。
でもCoworkは「まず認識を揃えさせてください」から入ってきた。

**優秀なコンサルタントとか、できる部下がやる仕事と同じなんですよね。**
```

### 問いかけ → 即答え パターン
```
なぜ特定の人に恋をする？

顔？→もっと美人/イケメンはいる
性格？→もっと優しい人はいる
スペック？→もっと高収入はいる

でも「この人じゃなきゃダメ」になる。

なぜか？

**共有した時間と経験が代替不可能性をもたらすから。**
```

### 箇条書きの畳み掛け
```
* 「もっといいものを逃してるかも」
* この恐怖が、現代人を支配してる。
* 恋人といても、他のカップルが気になる。
* 仕事してても、他の会社が気になる。
* 何を選んでも、不安。
```

### 一文独立の強調
```
**これ、本気で推してる人だいたい3パターン：**

1. 実践してない人（口だけ）
2. 搾取されて病んでる人（共依存）
3. 搾取してる側（「もっと愛して！」）
```

## 太字（**bold**）の使い方

みかみ記事の最大の特徴。以下の場面で使う:
- **核心メッセージ**: その段落で一番言いたいこと
- **転換点**: 「でもね、ここに一つ、重要な前提がある。」
- **結論**: 「**代替不可能だと信じること。それこそが、愛の本質だ。**」
- **独立した強調文**: 2〜3行を太字にして独立させる

## 改行・空白の使い方

- 一文ごとに改行する（スマホ最適化）
- セクション間は空行2つ
- 重要な文の前後に空行を多めに入れる
- 短い段落（1〜3文）を積み重ねる構成

## 語尾パターン集

| 場面 | 語尾例 |
|------|--------|
| カジュアル | 〜なんよね。/ 〜なわけです。/ 〜でしょ？ |
| ツッコミ | 〜では？/ 〜なんだよな。/ 〜ですよね。笑 |
| 断言 | 〜です。断言します。/ 〜なんです。 |
| 問いかけ | 〜じゃない？/ 〜だと思いませんか？ |
| 自虐 | 〜でした。(その節はごめん。笑) |
| 感嘆 | 〜やばい。/ 〜最高じゃない？ |

## 「笑」の使い方

- 自虐の後: 「我ながら雑魚です。笑」
- ツッコミの後: 「目的がない。笑」
- 照れ隠し: 「ちょっと恥ずかしい。笑」
- テンションの表現: 「マジでヤバい。笑」
- 頻度: 1セクションに1〜2回程度

## 構成パターン（記事タイプ別）

### TYPE A: 体験レビュー型（ClaudeCowork記事 = 55スキ）
1. 「実はいまこういう実験してます」で始める
2. 時系列で体験を語る（臨場感重視）
3. 使い方をステップ化してまとめる
4. 「なぜこれがすごいのか」を技術的に解説
5. アドネスの事業・哲学に接続する
6. CTA + P.S.

### TYPE B: 哲学・思想型（愛の証明記事 = 94スキ）
1. 根源的な問いを投げる（「愛って何？」）
2. 既存の答えを片っ端からぶった切る（歴史的レビュー）
3. 「で、全部使えない」と結論
4. 「僕の答えはこれ」と独自の定義を提示
5. その定義であらゆる事例を説明してみせる
6. アドネス哲学・事業に着地
7. 「一緒にやろう」で締め + P.S.

### TYPE C: 会社ストーリー型（2031年3兆円記事 = 18スキ）
1. 「久しぶりに書いてます」的な距離感で始める
2. 自分の人生ストーリーを時系列で語る
3. ストーリーの中で哲学が形成される過程を見せる
4. 哲学 → 事業 → ビジョンの順で展開
5. 「力を貸してください」で締め + P.S.

### TYPE D: ビジョン・プロダクト型（アドる記事 = 175スキ）
1. 「最近こんなことがあった」で始める（ラスベガス等）
2. 業界の現状を分析して「全部死ぬ」と断言
3. 自社の独自ポジションを明確化
4. 「アドる」のような新概念を定義・説明
5. 具体的なユースケースで読者に想像させる
6. 哲学的な意味づけ → 壮大なビジョン
7. CTA + P.S.

## 締めのパターン

### 必ず含める要素
1. 熱いメッセージ（「世界を変えよう」系）
2. 読者への呼びかけ（「一緒に」のスタンス）
3. CTA: DMリンク（https://x.com/mikami_01）

## noteエディタのフォーマット制約

noteのテキストエディタで使える記法は以下のみ。記事を書くときはこの制約内で書くこと。

| 記法 | ショートカット | 備考 |
|------|--------------|------|
| 見出し | `# ` + スペース | 大見出し。noteでは `##` 以降の見出しレベルはない |
| 小見出し | `## ` + スペース | 小見出し。`###` は使えない（noteでは反映されない） |
| 箇条書きリスト | `- ` or `+ ` or `* ` + スペース | |
| 番号付きリスト | `1. ` or `2) ` + スペース | |
| 引用ブロック | `> ` or `>> ` + スペース | |
| 太字 | テキスト選択 → B | `**太字**` のMarkdown記法は使えない |
| 区切り線 | `---` | |

### 重要な制約

- **`###` 以下の見出しは使えない**: noteでは `#`（見出し）と `##`（小見出し）の2段階のみ
- **太字のMarkdown記法 `**text**` は使えない**: noteエディタ上ではテキスト選択 → Bで太字にする
- **テーブル（表）は使えない**: noteのエディタにはテーブル機能がない。代わりに箇条書きや本文で表現する
- **コードブロックは使えない**: `` ``` `` 記法はnoteに存在しない
- **画像はエディタ上で挿入**: Markdownの `![alt](url)` は使えない

### 下書きファイルの書き方ルール

下書きMarkdownファイルでは `**太字**` や `###` を使ってOK（読みやすさのため）。
ただし、**noteに貼り付けるときに以下の変換が必要**であることを意識する:

- `###` → `##` に変換（noteには2段階しかない）
- `**太字**` → noteエディタ上で手動で太字にする
- テーブル → 箇条書きに変換
- コードブロック → 引用ブロック or 本文に変換

## NGパターン（これをやったらみかみっぽくない）

- 「〜させていただきます」的な丁寧すぎる敬語
- 一文が80文字を超える長文
- 見出しが「1. はじめに」「2. 本論」みたいな教科書スタイル
- 太字が全く使われていない
- 改行が少なくて段落が5行以上続く
- 体験談やエピソードが一切ない
- 「笑」が一度も出てこない
- P.S.がない
- アドネス哲学への接続がない
