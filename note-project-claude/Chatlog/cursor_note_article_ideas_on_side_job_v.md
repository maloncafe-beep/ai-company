## 「副業」論の核心（今回の主題）

### 世間の「副業」4種類
1. **会社員副業**（本業＋別労働）← 国・企業が想定する正規定義
2. **投資副業**（株・FX・不動産）
3. **自営業者の複業**（ライター＋講師＋コンサル等、全部本業）
4. **個人事業の入口**（note界隈：アフィ・コンテンツ販売＝実態は小規模事業）

### 言葉の変遷（実態は30年ほぼ同じ）
```
内職 → SOHO → フリーランス → 副業
```
- 実態：**業務委託・個人事業・小規模事業**（月数万〜数十万が大多数）
- 「副業」は**働き方の名称ではなくマーケティング用語**の可能性
- 起業は怖い／個人事業主は責任が重い → **心理的ハードルを下げるラベル**
- フリーランス ≒ SOHOの言い換え（業務委託の本質は変わらない）
- フリーター（労働者）と混同する人もいる

### 二重構造
- **国の副業**＝会社員＋追加労働
- **市場の副業**＝小規模事業
- 三者が同じ言葉で別物を指す：国「推進」／市場「小規模事業」／企業「他社労働」
- 個人事業が「副業」と呼ばれる背景：**会社員が正で、個人事業が評価されていない序列**
- 国は個人事業の方が税金取りやすいが、本気の支援にはなりにくい（利害・制度設計の複雑さ）

### 業務委託 vs 事業（重要な切り口）
- ランサーズ等＝**業務委託**（依頼者が先にいる）
- note販売等＝**事業**（商品→市場→顧客）
- 境界はグラデーション。分類軸は「働き方」より**収益構造**（雇用／業務委託／事業／資産収入）
- note界隈「AI副業で月○万」＝業務委託を教えているのか事業を教えているのか混同
- MALOさんの関心：**AI副業効率化界隈より、note有料記事の「何を売っているか」**

## note有料記事：何が売れているか

**売っているものの分類**
- ノウハウ販売 / 体験販売 / 解釈販売 / 共感販売 / 世界観販売

**市場の比喩**
- 業務委託＝**労働市場**
- note有料記事＝**意味市場**（「知的旅ブラ」「知的フィールドワーク」）
- TV比喩：ガチ解説番組ではなく**ドキュメンタリー／旅ブラ**
- 読者が買うのは情報ではなく**観察者の視点・思考過程**

**価値の3世代**
1. 有料メルマガ・レポート時代：**情報→課金**（情報格差）
2. ブログ・SNS時代：**情報の無料化**
3. note有料記事時代：**視点・解釈・経験→課金**（有料ブログ的）

**AI以降の価値シフト**
```
知らないこと → 価値　（昔）
どう考えるか → 価値　（今）
誰が考えるか → 価値　（AI以後）
```
- 投入労働時間 ≠ 市場価値（等価価値＝労働力＝お金ではない、という根っこ）
- 第1段階：労働時間→報酬
- 第2段階（今の主流）：AI→効率化→同じ時間で多く稼ぐ
- 第3段階（これから）：**自分が思う価値 ≠ 買う人が思う価値** →「こんなものが売れるなんて」が増える

**さらに先の仮説（断言不可）**
- 情報の希少性崩壊 → 体験の希少性崩壊（AI動画・GoogleMap飛行映像等）
- 旅ブラも終わる可能性。残るものはまだ不明
- 価値：**情報→体験→解釈→探索過程** へ移動しつつある？

**自己実現とお金**
- 旧：労働→賃金→消費→生活（自己実現は副次）
- 新：好きなこと→発信→共感→価値化→収益（**自己実現がお金に直結し始めた**）
- 芸術家モデルが一般化：評価者が出版社等→**市場全体**へ
- 権威→価値 から 共感→価値 へ
- 未確定：**自己実現がお金になる時代** vs **お金になりそうな自己実現だけが見える時代**
