# phase5-thumbnail スキル

## 発動トリガー
「サムネ作って」「バナー作って」「表紙画像作って」

## 目的
確定したタイトル・記事内容から、note用バナー（表紙画像）を生成する。
**AI画像生成は使わない。** `note-project-zodiacm`の既存バナーで確立済みのフラットデザイン
（ベージュ〜セージのグラデーション、黒太字見出し、カード型UI図解）を、Pillowスクリプトで
コードから直接再現する。コストゼロ・即時生成・ブランド一貫性が理由。

note記事は生成AIで作った派手な画像を使うクリエイターが多いため、逆にこの地味でテキスト
中心なデザインの方が目立つ、という判断（経営者コメント・2026-10-01）。この方向性を崩さない。

## 使用ツール
`scripts/make_note_banner.py`（Python/Pillow、ローカル・無料）

## 前提条件
- `products/YYYYMMDD-案件スラッグ/04-content/article-body.md` または `sales-page.md` でタイトル・内容が確定していること
- その記事が**有料か無料か**が分かっていること（バナーの見た目を分ける）

## 実行手順

### Step 1: 構成要素を決める
- タイトル・サブタイトル（記事の見出しから。対象読者か具体的な悩みを必ず含める）
- タグ（例：`CAREER GUIDE / AI ACTIVATION`）
- 有料なら `--paid` を付ける（右上にPREMIUMバッジ、金アクセントになる）。無料記事には付けない
- 右側の図解は以下から記事内容に合うものを選ぶ（複数可）
  - `--checklist-header` + `--checklist-items`：チェックリスト型（やること等）
  - `--steps`：番号付きステップ（例：`1:強みを言語化,2:書類を磨く`）
  - `--flow-before` + `--flow-after`：Before→After型（例：`手作業` → `AI`）
  - `--avatars N`：人数分の丸アイコン（迷ったらこれをデフォルトにしてよい）
- 背景を既存のグラデーションではなく任意の画像（写真・AI生成画像など）にしたい場合は `--bg <画像パス>` を指定する
  - 指定すると自動で左側に暗いスクリム（グラデーション）がかかり、見出し文字が白文字に切り替わるため、どんな背景でも視認性は確保される
  - **背景画像には文字を焼き込まない**（タイトルは常にこのスクリプトでローカル合成するため、背景側に文字が入っていると二重に重なる）

### Step 2: 生成
```powershell
python scripts/make_note_banner.py `
  --title "確定タイトル" `
  --subtitle "サブタイトル（任意）" `
  --tag "カテゴリタグ" `
  --paid `
  --checklist-header "やること" `
  --checklist-items "項目1,項目2,項目3" `
  --out products/YYYYMMDD-案件スラッグ/05-thumbnail/banner-01.png
```
文言違いでA/B案を複数出す場合も、このスクリプトを複数回呼ぶだけでよい（追加コストなし）。

### Step 3: 保存
生成した画像は `products/YYYYMMDD-案件スラッグ/05-thumbnail/` に保存する（Step 2で出力先指定済みならそのまま）。

### Step 4: 開いて確認
CLAUDE.mdの全社ルールに従い、生成した画像は自動的に開いてユーザーに見せる。

### Step 5: LOG更新
`products/YYYYMMDD-案件スラッグ/LOG.md` に、有料/無料どちらのバナー構成にしたか、使った図解パターンを追記する。
