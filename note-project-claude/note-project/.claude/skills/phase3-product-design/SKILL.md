# phase3-product-design スキル

## 発動トリガー
「商品設計して」「この切り口で設計図作って」

## 目的
フェーズ2で確定した切り口・価格帯から、本編構成・特典・購入後導線を含む商品設計図を作る。1商品で終わらない収益構造にすることが必須条件。

## 前提条件
- `products/YYYYMMDD-案件スラッグ/02-market-research.md` の結論（切り口・推奨価格帯）が確定していること
- 一次資料 `D:\Users\yyasu\Documents\MyDocuments_Mirror\AI-Business\02_コンテンツ販売_note\03_実施中_マネタイズ企画\マネタイズ\note売れる記事_方法論詳細.md` のジャンル選定5条件・骨組テンプレートを踏まえる

## 実行手順

### Step 1: 設計項目を埋める
1. **本編note**：見出し構成、想定文字数
2. **特典**：購入者限定コンテンツの内容（本編に統合する前提で設計する）
3. **購入後導線**：次に案内する商品・サービス（低価格note → まとめ商品 → 上位サービスの流れ）
4. **価格**：フェーズ2の推奨価格帯から決定
5. **ゴール（1文）**：「この記事を読み終えたら、読者はこれができるようになる」を1文で決める

### Step 2: 出力形式
```markdown
# 商品設計図（フェーズ3）

## 本編構成（見出しごとに1文で要約）
## 特典内容
## 購入後導線
## 価格
## ゴール
```

### Step 3: 保存
`products/YYYYMMDD-案件スラッグ/03-product-design.md` に保存する。

### Step 4: LOG更新
`products/YYYYMMDD-案件スラッグ/LOG.md` に設計方針と価格の決定理由を追記する。

立ち止まらず `phase4-content-generation` スキルに進む（2026-09-30更新：一気通貫がデフォルト）。
