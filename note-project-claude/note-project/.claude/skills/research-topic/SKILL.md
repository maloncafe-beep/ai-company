# research-topic スキル

## 発動トリガー
「○○について調べて」「リサーチして」「題材を探して」「正論と異論を出して」

## 方法
`research/METHOD.md` に従う（需要確認 → 正論 → 異論 → 異論への反論 → 未解決 → 暫定の見立て）。

## 守ること
- 結論（Go/No-Go）は出さない。決めるのは経営者。
- 事実は一次資料まで確認したものだけ。未確認は ★、データのない異論は「仮説」と書く。
- メモの冒頭に、検索語・調べた範囲の偏りを書く。
- 題材の候補は2〜3個出し、1つに絞らない。

## 保存
- `research/YYYYMMDD-theme-題材名.md`
- LOG.md に1行追記する。
