# research-topic スキル

## 発動トリガー
「○○について調べて」「リサーチして」「データ集めて」

## 実行手順

### Step 1: リサーチ範囲の確定
- テーマのキーワードを3〜5個抽出
- 記事タイプ（A/B/C/D）を仮決め

### Step 2: 情報収集
以下の順で収集:
1. **統計・数字**: 信頼できる公的データ（政府・研究機関・大手調査会社）
2. **事例・具体例**: 読者がイメージできる具体的なケース
3. **逆説・意外性**: 「常識と違う事実」を探す（記事のフックになる）
4. **哲学との接続点**: このテーマがWell-being/LTR/Giver・Takerとどうつながるか

### Step 3: リサーチメモの作成

保存先: `research/YYYYMMDD-テーマ名.md`

```markdown
# リサーチメモ: [テーマ名]

## 収集日
YYYY-MM-DD

## キーファクト（数字・データ）
- 

## 事例・具体例
- 

## 逆説・意外な事実
- 

## 哲学との接続ポイント
- 

## 参考URL・出典
- 

## 記事アイデアメモ
タイプ: A/B/C/D
推奨タイトル候補:
- 
```

### Step 4: 執筆への橋渡し
リサーチ完了後、「記事書く？」と確認する。
