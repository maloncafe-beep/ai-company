# generate-article-idea スキル

## 発動トリガー
「ネタ考えて」「アイデア出して」「何書こう」

## 実行手順

### Step 1: 設定確認
`config/author-profile.md` の得意ジャンルとターゲット読者を確認。

### Step 2: 6フレームワークでアイデア生成

各フレームワークで1〜2案、計6〜12案を生成する。

**① 哲学バズーカ法**
「〜とは何か？」という根源的な問いを立てる。
例: 「努力とは何か」「お金とは何か」「自由とは何か」

**② 体験ファースト法**
最近の具体的な体験・失敗・発見から発想する。
例: 「○○を試してみたら○○だった」「○○で気づいたこと」

**③ 業界ぶった切り法**
「○○業界は全部死ぬ」「○○の常識は嘘だ」という断言から入る。
例: 「マーケティングという概念はAIに殺される」

**④ 会社の裏側法**
普段見せない舞台裏・失敗・葛藤を語る。
例: 「失注した案件から学んだこと」「こう思ってた時期がありました」

**⑤ 人生ストーリー法**
自分の人生の転換点・決断・後悔から学びを引き出す。
例: 「サラリーマンを辞めた本当の理由」

**⑥ AI×哲学法**
AIとテクノロジーを哲学・人生論に接続する。
例: 「AIに仕事を奪われる前に、仕事とは何かを考えた」

### Step 3: アイデアの評価

各案を以下で評価して提示:
- **バズ度**: スキ数が伸びやすいか（TYPE B・Dが高い傾向）
- **書きやすさ**: 体験談・具体例があるか
- **哲学接続**: Maloncafe哲学に着地できるか
- **推奨タイプ**: A/B/C/D

### Step 4: idea-pool.mdへの追記
採用・不採用に関わらず、アイデアを`ideas/idea-pool.md`にストックする。
