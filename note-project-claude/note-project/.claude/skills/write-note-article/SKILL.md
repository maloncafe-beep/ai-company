# write-note-article スキル

## 発動トリガー
「記事書いて」「〜について書いて」「下書き作って」

## 実行手順

### Step 1: 設定ファイルの確認
必ず以下を参照してから執筆開始:
1. `config/author-profile.md`
2. `config/writing-style-guide.md`
3. `config/company-philosophy.md`
4. テーマに対応するテンプレート（`templates/`）

### Step 2: 記事タイプを確定
| タイプ | 判断基準 |
|--------|---------|
| TYPE A 体験レビュー型 | 実際の体験・ツール・サービスの話 |
| TYPE B 哲学・思想型 | 根源的な問いを立てる話 |
| TYPE C 会社ストーリー型 | 自分・会社の軌跡・ビジョン |
| TYPE D ビジョン・プロダクト型 | 業界を斬る・新概念を提唱 |

### Step 3: 執筆チェックリスト
執筆中・執筆後に必ず確認:

**文体**
- [ ] 一人称は「わたし」
- [ ] 冒頭は「こんにちは！ご機嫌いかがですか。」系
- [ ] AI使用の開示が冒頭付近にある
- [ ] 太字を超多用している
- [ ] 一文60文字以内
- [ ] 「笑」が1セクション1〜2回使われている
- [ ] P.S. / P.P.S. / P.P.P.S. がある
- [ ] 「ありがとうございました。」で締めている

**構成**
- [ ] 冒頭3行でフックがある
- [ ] 読者への問いかけが複数ある
- [ ] 体験談・具体例がある
- [ ] 哲学（Well-being/LTR/Giver・Taker/価値提供）に着地している
- [ ] 4000文字以上

**noteフォーマット**
- [ ] 見出しは`#`と`##`のみ（`###`不使用）
- [ ] テーブル不使用（箇条書きで代替）
- [ ] `**太字**`はnote貼り付け時に手動変換が必要と認識

### Step 4: ファイル保存
```
articles/drafts/YYYYMMDD-タイトル.md
```

フロントマター（YAMLヘッダー）を必ず記述:
```yaml
---
title: 記事タイトル
status: draft
created: YYYY-MM-DD
tags: [タグ1, タグ2]
article_type: A/B/C/D
estimated_read_time: ○分
ai_disclosure: "AIと一緒に執筆・推敲。体験と論旨は著者のもの。"
---
```

## NGパターン（絶対に避ける）
- 「させていただきます」
- 一文80文字超
- 「1. はじめに」スタイルの見出し
- 太字ゼロ
- P.S.なし
- 「わたし」以外の一人称
