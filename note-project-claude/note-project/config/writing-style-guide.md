# 執筆スタイルガイド（フェーズ4共通）

旧`note-project`の個人ブランド向けスタイルガイド（一人称「わたし」、P.S.文化など）は当工場では使わない。
本工場は市場起点・匿名寄りの有料note販売が目的のため、以下を基準にする。

## 文体

- 「です・ます」調で統一
- 修辞的表現より実証性を優先（データ・事例・具体的な数字を根拠にする）
- 一文は60〜80文字程度に収め、長文は分割する
- 読者の悩みへの共感から始め、押しつけがましい断定は避ける

## 構成（本編note）

導入 → 問題提起 → 解決策 → 具体例 → 特典 → CTA の流れを崩さない。

- 導入：読者の悩み・検索意図に一致する一文で始める
- 問題提起：なぜその悩みが解決しにくいのか、構造的な理由を示す
- 解決策：商品設計図（`03-product-design.md`）の切り口に沿って提示する
- 具体例：データ・事例・再現手順など、実証性のある裏付けを入れる
- 特典：購入者限定コンテンツへの導線を明確にする
- CTA：次に取ってほしい行動（購入・特典受け取り・次の商品への導線）を1つに絞る

## noteフォーマット上の注意

- 見出しは`#`と`##`を基本とする
- 表はnote上でも崩れにくいが、多用しすぎない（箇条書きと併用する）
- 本文中の強調は`**太字**`。note貼り付け時に反映を確認する

## AI利用の開示

- 商品として販売するため、AI生成であることを過度に強調しない
- 必要な場合のみ、販売ページまたは記事末尾に一言添える程度に留める
