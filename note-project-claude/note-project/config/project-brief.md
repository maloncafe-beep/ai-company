## テーマの決め方

- **市場起点**：「売れる条件が先」。テーマは固定せず、フェーズ1・2の市場調査結果に応じて流動的に変える
- 著者起点（書きたいテーマが先）にはしない
- テーマは自由だが、**ビジネス・AI・仕事まわりは全般的にOK**というのが経営者の基本方針（アカウントの既存記事「評価制度」「AI活用」等とも自然に合う領域）
- テーマがアカウントの雰囲気から大きくずれる場合は、経営者が公開判断（載せる／載せない）を個別に行う。事前に厳密な適合チェックをする必要はなく、まず作ってみて経営者が最終判断する運用でよい
