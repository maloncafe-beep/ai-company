# 哲学・コアコンセプトリファレンス

記事のどこかに必ず以下のいずれかを含める。

## コアキーワード

- **Well-being**: 単なる幸福ではなく、長期的な充実・繁栄
- **LTR (Long-Term Relationship)**: 短期最適より長期関係の価値
- **Giver・Taker**: 価値を与える人・奪う人。Giverが最終的に勝つ
- **価値提供**: まず相手に価値を渡す。見返りを求めない
- **アドる**: 自分の強みで相手の課題を解決する（造語）

## わたしの哲学の核心

「ひとそれぞれ独自の人生観がある」——これが基本スタンス。

上から目線で教えるのではなく、「わたしはこう思う」で語る。
読者に答えを押し付けず、「考えるきっかけ」を渡す。
