## この記事は、こんな人に向けて書いています

- 毎月（毎週）、社員ごと・部署ごとに別々のExcelが届き、1つずつ開いて、コピーして、貼り付けている人
- 勤務簿・日報・売上報告など、書式はそろっているのに、ファイルの数だけが多い作業を担当している人
- Pythonやマクロは使ったことがない人（使えなくて大丈夫です）

「社内の困りごと解決シリーズ」の第1回です。社内で毎月やっている手作業を、1つずつ取り上げていきます。

## 月末の作業

月末です。社員ごとの勤務簿が、メールやフォルダに届いています。

1つ目のファイルを開く。「集計」シートを探す。必要な行をコピーする。まとめ用の表に貼る。ファイルを閉じる。2つ目を開く。

8人分ならまだ我慢できます。ところが、貼り終えて合計を見たら、1人分が足りません。どのファイルを貼り忘れたのか、もう一度、全部開いて確かめることになります。

それに、毎回どこかで引っかかります。

- 1人だけ、「集計」シートの名前が違う（末尾に空白が入っている、など）
- 1人だけ、シートが入っていない。本人に連絡して、送り直してもらう
- フォルダに、Excelを開いている間にできた一時ファイル（`~$`で始まるもの）が残っている

来月、上司に「次からは部署全体で」と言われたら、8人が80人になります。

マクロを組める人は、社内にいません。情報システム部門に頼むほどの話でもありません。結局、今月も自分で1つずつ開くことになります。

Yahoo!知恵袋にも、同じ状況の相談が出ています。「各社員の勤務簿（書式は統一、ファイル名は各社員名）から、『集計』シートだけを集めて1つのブックにしたい」という質問です（2020年）。2025年にも、毎月500件ほどのデータを手作業で集計し、システムにも手入力している、という書き込みがあります。

## 実は、解決は簡単です

この作業は、3通りのやり方で片づきます。どれも、自分でプログラムを書く必要はありません。職場の環境に合うものを選んでください。

### 方法① Excelの標準機能だけで済ませる（Power Query）

Excelに最初から入っている「フォルダーから取得」という機能を使います。フォルダの中の全ファイルから「集計」シートだけを集めて、1つの表にしてくれます。コードは書きません。会社のPCにソフトを入れられない人や、Excelの外に出たくない人に向いています。

ただし、シートが無いファイルは、何も言わずに外されます。取り込めなかったことがログに残らないので、ファイルの数と取り込んだ件数を、自分で見比べる必要があります。

### 方法② チャットAIにスクリプトを書かせる（ChatGPT／Gemini／Claudeなど）

やりたいことをAIに伝えて、Pythonのスクリプトを書いてもらいます。Pythonを1回入れておけば、あとはコマンド1つで動きます。取り込めなかったファイルと、その理由が記録に残るので、毎月同じ作業をする人に向いています。会社のPCにPythonを入れられない場合は、使えません。

### 方法③ AIエージェントに作業ごと任せる（Claude Code／Codexなど）

作業フォルダをAIに渡して、「このファイルをまとめて」と頼みます。AIがファイルを読み、スクリプトを作って実行し、結果まで残します。条件が多くて試行錯誤が要る作業や、コードを読めない人に向いています。

AIにPC内のファイルを触らせることになります。個人情報を含むファイルは、会社のルールを確認したうえで、コピーしたフォルダで作業してください。

## 3つとも、同じ結果になることを確かめました

勤務簿のサンプルを8つ作り、わざと、うまくいかないファイルを3つ混ぜました。

- 「集計」シートが無いファイル（1件）
- シート名の末尾に空白があるファイル（1件）
- `~$`で始まる一時ファイル（1件）

3つの方法で、それぞれ実行しました。数字は、どの方法でも一致しました。

| 方法 | 取り込めた件数 | シートが無い1件 | 一時ファイル | 結果の残し方 |
|---|---|---|---|---|
| ① Power Query | 7件 | 除外（ログなし） | 除外 | 取り込んだ表だけ |
| ② チャットAI＋Python | 7件 | 失敗として記録 | 対象外として記録 | 取込ログ |
| ③ AIエージェント | 7件 | 失敗として記録 | スキップとして記録 | 取込ログ |

②と③は、1件ごとの結果がログに残ります。毎月「何が取り込めなかったか」を確かめたいなら、②か③を使います。

## 方法①　Power Queryで、Excelだけで済ませる

メニューの名前は、Excelのバージョンで少し違います。ここでは「データの取得」を使います。

1. 新しいExcelブックを開く
2. 「データ」タブ → 「データの取得」 → 「その他のデータソースから」 → 「空のクエリ」を選ぶ
3. 開いた画面（Power Queryエディター）の「ホーム」タブで、「詳細エディター」を開く
4. 中身をすべて消して、次のクエリを貼り付ける。**`C:\ここに\フォルダの\パス`** の部分を、対象フォルダのパスに書き換える
5. 「完了」を押し、「閉じて読み込む」で、ブックに読み込む

```
let
    Source = Folder.Files("C:\ここに\フォルダの\パス"),
    Target = Table.SelectRows(Source, each [Extension] = ".xlsx" and not Text.StartsWith([Name], "~$")),
    Pick = Table.AddColumn(Target, "Data", each
        let
            sheets = Excel.Workbook([Content], true, true),
            hit = Table.SelectRows(sheets, (r) => r[Kind] = "Sheet" and Text.Trim(r[Name]) = "集計")
        in
            if Table.RowCount(hit) = 0 then null else hit{0}[Data]),
    Keep = Table.SelectRows(Pick, each [Data] <> null),
    Slim = Table.SelectColumns(Keep, {"Name", "Data"}),
    AllColumns = List.Union(List.Transform(Slim[Data], each Table.ColumnNames(_))),
    Expanded = Table.ExpandTableColumn(Slim, "Data", AllColumns),
    Renamed = Table.RenameColumns(Expanded, {{"Name", "元ファイル"}})
in
    Renamed
```

書き換える場所は、2か所です。

- `"C:\ここに\フォルダの\パス"`：対象フォルダ
- `"集計"`：取り込みたいシートの名前

このクエリは、列名を固定していません。ファイルの中で見出しが同じなら、そのまま通ります。

**確認方法**：フォルダ内の.xlsxの数（`~$`を除く）と、読み込まれた「元ファイル」の種類の数を比べてください。差が、取り込まれなかったファイルです。

私の環境（Office 16）では、このクエリで、サンプルの7件が取り込まれました。「データの取得」の画面の名前は、お使いのバージョンの表示を優先してください。

### AIに頼む依頼文（全文）

ChatGPT、Gemini、Claudeなど、どれでも構いません。【前提】の部分は、5つの質問の答えに合わせて書き換えてください。

```
あなたはExcel業務の自動化を手伝う担当です。
Pythonを使ったことがない事務担当者が、そのまま実行できるスクリプトを作ってください。

【やりたいこと】
フォルダ内にある複数のExcelファイル（.xlsx）から、「集計」というシートだけを取り出して、
1つのブックに縦に並べてまとめたい。

【前提】
・対象フォルダ：実行時に指定する（指定がなければ「kintai」）
・取り込むシート名：「集計」（シート名の前後に空白があっても同じシートとして扱う）
・各シートは、1行目が見出し、2行目以降がデータ
・まとめたブックの先頭の列に「元ファイル」（ファイル名）を付ける

【条件】
・ファイルが1つ壊れていても、シートが無くても、止まらずに最後まで処理すること
・Excelを開いている間にできる一時ファイル（~$ で始まるもの）は対象外にすること
・まとめたブックとは別に「取込ログ」シートを作り、ファイル名・結果（成功／失敗／対象外）・メモを残すこと
・使うのは openpyxl のみ。Excel本体は使わない
・コメントは日本語で、何をしているかが分かるように書くこと
・最後に、成功と失敗の件数を表示すること

【出力】
・そのまま保存して実行できる、1つのファイル分のスクリプト
・実行方法（コマンドの例）と、書き換える場所の説明
```

この中で、特に外せないのは次の3つです。

- 「止まらずに最後まで処理」
- 「一時ファイルは対象外」
- 「取込ログを残す」

この3つが無いと、うまくいかないファイルが1つ出るたびに全体が止まります。何が取り込まれていないのかも分かりません。

この依頼文は、別のAI（Claude）に渡して出てきたスクリプトを実行し、動作を確認しています。ChatGPTやGeminiでの確認はしていません。AIが書くコードは毎回違いますが、結果は同じでした。

### 動いたスクリプト

```python
import glob
import os
import sys
import openpyxl

SRC_DIR = sys.argv[1] if len(sys.argv) > 1 else "kintai"
OUT = sys.argv[2] if len(sys.argv) > 2 else "集計まとめ.xlsx"
SHEET = "集計"

out_wb = openpyxl.Workbook()
out = out_wb.active
out.title = "集計まとめ"
log = out_wb.create_sheet("取込ログ")
log.append(["ファイル", "結果", "メモ"])

header_written = False
ok = ng = 0

for path in sorted(glob.glob(os.path.join(SRC_DIR, "*.xlsx"))):
    name = os.path.basename(path)
    if name.startswith("~$"):
        log.append([name, "対象外", "Excelの一時ファイル"])
        continue
    try:
        wb = openpyxl.load_workbook(path, data_only=True, read_only=True)
        target = next((s for s in wb.sheetnames if s.strip() == SHEET), None)
        if target is None:
            log.append([name, "失敗", f"「{SHEET}」シートが見つからない（あるシート: {', '.join(wb.sheetnames)}）"])
            ng += 1
            continue
        rows = list(wb[target].iter_rows(values_only=True))
        if len(rows) < 2:
            log.append([name, "失敗", "データ行がない"])
            ng += 1
            continue
        if not header_written:
            out.append(["元ファイル"] + list(rows[0]))
            header_written = True
        for r in rows[1:]:
            out.append([name] + list(r))
        log.append([name, "成功", f"{len(rows) - 1}行を取り込み" + ("（シート名の末尾の空白を補正）" if target != SHEET else "")])
        ok += 1
    except Exception as e:
        log.append([name, "失敗", f"{type(e).__name__}: {e}"])
        ng += 1

out_wb.save(OUT)
print(f"成功 {ok} / 失敗 {ng} → {OUT}")
```

書き換える場所は、`SHEET = "集計"` の1か所だけです。フォルダと出力名は、実行時に指定できます。

### 実行して、ログを見る

コードを `merge_kintai.py` という名前で保存し（文字コードはUTF-8）、対象フォルダと同じ場所に置いて、コマンドプロンプトで実行します。

```
python merge_kintai.py kintai 集計まとめ.xlsx
```

成功すると、次のように表示されます。

```
成功 7 / 失敗 1 → 集計まとめ.xlsx
```

`集計まとめ.xlsx` には、2つのシートがあります。

- 「集計まとめ」：全員の行が縦に並んだシート（先頭に元ファイル名）
- 「取込ログ」：どのファイルが成功し、どれが失敗したかの一覧

**必ず「取込ログ」を見てください。** 失敗した行のファイルは、「集計まとめ」に入っていません。

処理時間は、サンプル8件で1秒未満、同じ形のファイル200件で約4秒でした（私の環境での実測値です）。

## 方法③　AIエージェントに、作業ごと任せる

Claude CodeやCodexのような、PCのフォルダを読み書きできるAIに、次の依頼文を渡します。1行目のフォルダのパスだけ、自分のものに書き換えてください。

```
作業フォルダは 【ここに、コピーしたフォルダのパス】 です。このフォルダの外のファイルは読み書きしないでください。
Pythonとopenpyxlは使えます。

【依頼】
作業フォルダの kintai フォルダには、社員ごとの勤務簿（.xlsx）が入っています。
各ファイルの「集計」シートだけを取り出し、1つのExcelファイルにまとめてください。

【条件】
・シートが無い／開けないファイル、Excelの一時ファイル（~$で始まるもの）は、止まらずに飛ばし、
  別シート「取込ログ」に、ファイル名・結果・理由を残す
・シート名の前後に空白があっても、同じシートとして扱う
・まとめたファイルは、作業フォルダに result.xlsx として保存する
・使ったスクリプトは merge.py として作業フォルダに残す（次回、自分で実行できるように）
・元のファイル（kintaiフォルダの中身）は変更しない

【完了したら報告すること】
・成功件数と失敗件数
・失敗したファイルと、その理由
・次回、自分で実行するときのコマンド
```

この依頼文は、別のAI（Claude）に渡して、実際に実行させました。結果のファイル（`result.xlsx`）とスクリプト（`merge.py`）が作られ、取り込み件数は、方法①②と一致しました。元のフォルダは変わっていませんでした。

### ③のコツと注意点

- **「スクリプトを残して」と頼む**：次回から、AIを使わずに自分で実行できます。方法②と同じ形になります。
- **コピーしたフォルダで作業させる**：元のファイルを触らせないためです。
- **報告文だけを信じない**：このテストでは、AIの報告文に、どのファイルのシート名に空白があったかの取り違えがありました。成果物の取込ログは正しく、報告文だけが違っていました。**件数とログは、自分の目でも確認してください。**

## つまづきポイント（3つの方法に共通）

### 数字が空欄になる

取り込み元のセルが数式のままで、Excelで一度も保存されていないと、結果が空欄になります。方法②・③は、「Excelが保存した計算結果」を読むためです。私の環境でも、openpyxlだけで作ったファイルの数式が空（None）になることを確認しています。そのExcelをいったん開いて、保存し直してください。

### 結果のファイルが保存できない（PermissionError）

出力先の `集計まとめ.xlsx` を、Excelで開いたままにしています。閉じてから、もう一度実行してください。

### 見出しが2行ある／結合セルがある

「1行目が見出し、2行目以降がデータ」という前提が崩れます。シートの構造を文字で説明して、AIに直してもらいます。

```
取り込み元のシートの構造は次の通りです。
・1行目：タイトル（結合セル）
・2〜3行目：見出し（2段）
・4行目以降：データ
この構造に合わせて、見出しを2段分まとめて1行にして取り込むように、直してください。
現在のスクリプト（またはクエリ）は以下です。
（貼り付ける。個人情報は入れない）
```

### 古い形式（.xls）が混ざっている

3つの方法とも、`.xlsx` が対象です。`.xls` は、Excelで開いて `.xlsx` で保存し直してください。

## 詰まったときの、AIへの聞き方

エラーが出たときに「エラーが出ました」とだけ書くと、的外れな答えが返ります。次の4つを、毎回そろえて貼ります。

```
【やろうとしたこと】
フォルダ内のExcelの「集計」シートを1つにまとめる

【実行したもの】
（コマンド、または、どのクエリ・操作か）

【出たエラー（全文）】
（出た文を、そのままコピーして貼る）

【環境】
Windows 11 / Excelのバージョン / Python 3.14（使っている場合）
```

- エラーは、**全文**を貼ってください。最後の1行だけでは、原因が分かりません
- 実際のデータ（氏名・金額など）は貼らないでください

## 3つの方法の、選び方

| あなたの状況 | おすすめ |
|---|---|
| 会社のPCに何も入れられない | ① |
| 毎月同じ作業。失敗したファイルを、毎回ログで確認したい | ② |
| 条件が複雑で、試行錯誤したい。コードは読めない | ③（最後に、スクリプトを残してもらう） |

迷ったら、まず①を試してください。動くかどうかは、すぐに分かります。ログが欲しくなったら、②に移ります。

## まとめ

社員ごとのExcelを毎月コピペする作業は、Excelの標準機能、チャットAI、AIエージェントのどれでも片づきます。3つとも、サンプルで同じ結果になることを確かめました。シートが無いファイルや一時ファイルが混ざっても、止まりません。

まずは、手元のファイルを3つだけコピーして、テスト用のフォルダを作り、方法①か②を動かしてみてください。本番のフォルダに触るのは、ログの見方が分かってからで構いません。
