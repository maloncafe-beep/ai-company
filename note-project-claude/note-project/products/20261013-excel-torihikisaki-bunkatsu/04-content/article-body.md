## この記事は、こんな人に向けて書いています

- 毎月、システムから出した売上一覧や請求一覧を、取引先ごと（担当者ごと、支店ごと）に分けて配っている人
- 「フィルターで絞って、コピーして、新しいブックに貼って、名前を付けて保存」を、取引先の数だけ繰り返している人
- Pythonやマクロは使ったことがない人（使えなくて大丈夫です）

「社内の困りごと解決シリーズ」の第2回です。

## 月初の作業

月初です。システムから、先月分の売上一覧をダウンロードします。1つのExcelに、全取引先の行がまとまっています。

取引先でフィルターをかける。見えている行をコピーする。新しいブックを作って貼る。「取引先名.xlsx」で保存する。次の取引先に切り替える。

12社なら、1時間もかからないかもしれません。取引先が何十社もあれば、午前中が終わります。

そして、この作業でいちばん怖いのは、時間ではありません。フィルターを外し忘れたまま保存して、**他社の金額が入った表を、そのまま送ってしまう**ことです。

それに、途中で手が止まる場面もあります。

- 取引先名に「/」や「?」が入っていて、ファイル名に使えない
- 「青山商事」と「青山商事 」（末尾に空白）が、別の取引先として並んでいる
- 取引先の欄が空のまま、行が混ざっている

Yahoo!知恵袋にも、同じ状況の相談があります。毎月の売上金額のデータを、数百の取引先ごとに別のExcelへ振り分けている。マクロや関数を使わずに、効率化できないか、という質問です（2025年）。

## 実は、解決は簡単です

この作業は、3通りのやり方で片づきます。どれも、自分でプログラムを書く必要はありません。

### 方法① ピボットテーブルの機能で、取引先ごとのシートを作る

Excelの「ピボットテーブル」に、「レポートフィルターページの表示」という機能があります。フィルターに取引先を置いて実行すると、取引先ごとのシートが一度に作られます。コードは書きません。

ただし、できあがるのは「シート」です。ファイルではありません。取引先に送るなら、シートごとにブックを分ける作業が、もう一度必要です。社内で、取引先別の数字を確認する用途に向いています。

もう1つ注意があります。末尾に空白がある取引先は、別のシートになります。記号が入った取引先名のシートは、「Sheet4」のような名前になります。

### 方法② チャットAIにスクリプトを書かせる（ChatGPT／Gemini／Claudeなど）

「取引先ごとに、別々のExcelファイルに分けて」とAIに頼み、Pythonのスクリプトを書いてもらいます。Pythonを1回入れておけば、あとはコマンド1つです。

ファイルとして分かれるので、そのまま送れます。空白の違いも統合され、ファイル名に使えない文字も置き換わります。分けたあとに、元の行数・金額と合っているかの検算もできます。毎月同じ作業をする人に向いています。会社のPCにPythonを入れられない場合は、使えません。

### 方法③ AIエージェントに作業ごと任せる（Claude Code／Codexなど）

作業フォルダと売上一覧をAIに渡して、「取引先ごとに分けて」と頼みます。AIがファイルを読み、スクリプトを作って実行し、結果と検算まで報告します。条件が多い作業や、コードを読めない人に向いています。

AIにPC内のファイルを触らせることになります。取引先の金額が入ったファイルは、会社のルールを確認したうえで、コピーしたフォルダで作業してください。

## 方法①　ピボットテーブルで、取引先ごとのシートを作る

メニューの名前は、Excelのバージョンで少し違います。

1. 売上一覧の表の中をクリックし、「挿入」タブ → 「ピボットテーブル」で、新しいシートに作る
2. 右側の画面で、「取引先」を「フィルター」のエリアに、「金額」を「値」のエリアにドラッグする
3. 「ピボットテーブル分析」タブ → 「オプション」の右の「▼」 → 「レポート フィルター ページの表示」を選ぶ（画面の名前は、バージョンで少し違います）
4. 「取引先」を選んで「OK」を押す

取引先ごとのシートが、一度に作られます。

**確認のしかた**：できたシートの名前を、取引先の一覧と見比べてください。「Sheet4」のような名前のシートは、記号を含む取引先です。シートの中身を開いて、どの取引先か確かめます。末尾に空白がある取引先は、同じ名前のシートが2枚並びます。

私の環境（Office 16）では、サンプルで14枚のシートができました。メニューの画面名は、お使いのバージョンの表示を優先してください。

### ①の限界

- ファイルには分かれません。送るなら、シートを右クリックして「移動またはコピー」で新しいブックへ出す作業が、取引先の数だけ残ります
- 元の行数・金額と合っているかの検算は、自分でする必要があります

### AIに頼む依頼文（全文）

ChatGPT、Gemini、Claudeなど、どれでも構いません。【前提】の部分は、5つの質問の答えに合わせて書き換えてください。

```
あなたはExcel業務の自動化を手伝う担当です。
Pythonを使ったことがない事務担当者が、そのまま実行できるスクリプトを作ってください。

【やりたいこと】
売上一覧のExcelファイル（.xlsx）を、取引先ごとに別々のExcelファイルに分けて保存したい。

【前提】
・入力：1つのxlsxファイル（実行時に指定する）。1つ目のシートの1行目が見出し、2行目以降がデータ
・見出しの中に「取引先」と「金額」の列がある
・出力：指定したフォルダ（指定がなければ「取引先別」）に、「取引先名.xlsx」で保存する
・見出しは、そのまま各ファイルの1行目に付ける

【条件】
・取引先名の前後の空白は取り除いて、同じ取引先として扱うこと
・取引先が空欄の行は、「取引先未設定.xlsx」にまとめ、ログで知らせること
・ファイル名に使えない文字（\ / : * ? " < > |）は「_」に置き換え、ログに残すこと
・置き換えた結果、ファイル名が重なったら、連番を付けて別ファイルにすること（上書きしない）
・最後に検算すること：書き出したファイルを読み直して、元の行数と金額の合計が一致するかを表示し、ログにも残すこと
・「分割ログ」を別のxlsxで保存すること（取引先・ファイル名・件数・金額合計・メモ）
・使うのは openpyxl のみ
・コメントは日本語で、何をしているかが分かるように書くこと

【出力】
・そのまま保存して実行できる、1つのファイル分のスクリプト
・実行方法（コマンドの例）と、書き換える場所の説明
```

この中で、特に外せないのは次の3つです。

- 「取引先名の前後の空白は取り除く」
- 「ファイル名が重なったら、連番を付ける（上書きしない）」
- 「書き出したファイルを読み直して、検算する」

最後の2つが無いと、別々の取引先のファイルが上書きされても、検算が合っているように見えてしまいます。

### 動いたスクリプト

```python
import os
import re
import sys
import openpyxl

SRC = sys.argv[1] if len(sys.argv) > 1 else "売上一覧_2026-09.xlsx"
OUT_DIR = sys.argv[2] if len(sys.argv) > 2 else "取引先別"
KEY_COL = "取引先"      # 分けたい列の見出し
AMOUNT_COL = "金額"     # 検算に使う列の見出し

os.makedirs(OUT_DIR, exist_ok=True)

ws = openpyxl.load_workbook(SRC, data_only=True).worksheets[0]
rows = list(ws.iter_rows(values_only=True))
header, data = list(rows[0]), [r for r in rows[1:] if any(v is not None for v in r)]
key_idx, amt_idx = header.index(KEY_COL), header.index(AMOUNT_COL)

# 取引先ごとにまとめる（前後の空白は取り除く。空欄は「取引先未設定」）
groups = {}
for r in data:
    key = str(r[key_idx]).strip() if r[key_idx] is not None else ""
    groups.setdefault(key or "取引先未設定", []).append(list(r))

log = openpyxl.Workbook()
lg = log.active
lg.title = "分割ログ"
lg.append(["取引先", "ファイル名", "件数", "金額合計", "メモ"])

used = set()
written = []
for key, items in sorted(groups.items()):
    memo = []
    base = re.sub(r'[\\/:*?"<>|]', "_", key)
    if base != key:
        memo.append("ファイル名に使えない文字を「_」に置換")
    fname, n = base, 2
    while fname.lower() in used:          # 置換後に名前が重なったら連番を付ける
        fname = f"{base}_{n}"
        n += 1
    if fname != base:
        memo.append("同じ名前のファイルがあるため連番を付けた")
    used.add(fname.lower())
    if key == "取引先未設定":
        memo.append("取引先が空欄の行。要確認")

    out = openpyxl.Workbook()
    o = out.active
    o.title = "売上"
    o.append(header)
    for r in items:
        o.append(r)
    out.save(os.path.join(OUT_DIR, fname + ".xlsx"))
    written.append(fname + ".xlsx")
    lg.append([key, fname + ".xlsx", len(items), sum(r[amt_idx] or 0 for r in items), " / ".join(memo)])

# 検算：書き出したファイルを読み直して、元の行数・金額と比べる
out_rows = out_amount = 0
for f in written:
    w = openpyxl.load_workbook(os.path.join(OUT_DIR, f)).worksheets[0]
    for r in w.iter_rows(min_row=2, values_only=True):
        out_rows += 1
        out_amount += r[amt_idx] or 0
src_rows = len(data)
src_amount = sum(r[amt_idx] or 0 for r in data)
ok = (src_rows == out_rows) and (src_amount == out_amount)

lg.append([])
lg.append(["検算", "", f"元 {src_rows} / 分割後 {out_rows}", f"元 {src_amount} / 分割後 {out_amount}", "一致" if ok else "不一致。要確認"])
log.save(os.path.join(OUT_DIR, "_分割ログ.xlsx"))

print(f"{len(groups)} 社に分割 / 元 {src_rows} 行 → 分割後 {out_rows} 行 / 検算 {'OK' if ok else 'NG（要確認）'}")
```

書き換える場所は、冒頭の2か所です。

- `KEY_COL = "取引先"`：分けたい列の見出し（担当者ごとに分けるなら「担当者」）
- `AMOUNT_COL = "金額"`：検算に使う列の見出し

元のファイル名と出力フォルダは、実行時に指定できます。

### 実行して、ログを見る

コードを `split_by_customer.py` という名前で保存し（文字コードはUTF-8）、売上一覧と同じ場所に置いて、コマンドプロンプトで実行します。

```

```

`取引先別` フォルダには、取引先ごとのファイルと、`_分割ログ.xlsx` ができます。

**必ず「_分割ログ.xlsx」を見てください。** 「取引先未設定」が出ていれば、元の売上一覧に、取引先が空の行があります。送る前に、元データを直すか、その行の取引先を確認します。

## 方法③　AIエージェントに、作業ごと任せる

Claude CodeやCodexのような、PCのフォルダを読み書きできるAIに、次の依頼文を渡します。1行目のフォルダのパスだけ、自分のものに書き換えてください。

```
作業フォルダは 【ここに、コピーしたフォルダのパス】 です。このフォルダの外のファイルは読み書きしないでください。
Pythonとopenpyxlは使えます。

【依頼】
作業フォルダの「売上一覧_2026-09.xlsx」を、取引先ごとに別々のExcelファイルに分けてください。

【条件】
・出力先は、作業フォルダの「取引先別」フォルダ。ファイル名は「取引先名.xlsx」
・取引先名の前後の空白は取り除き、同じ取引先として扱う
・取引先が空欄の行は「取引先未設定.xlsx」にまとめる
・ファイル名に使えない文字は「_」に置き換え、その旨を記録する
・各ファイルの1行目には、元と同じ見出しを付ける
・分割した結果の一覧（取引先・ファイル名・件数・金額合計・メモ）を、別のExcelファイル「分割ログ.xlsx」に残す
・元のファイルは変更しない
・使ったスクリプトを split.py として作業フォルダに残す（次回、自分で実行できるように）

【完了したら報告すること】
・何社に分けたか
・元の行数・金額の合計と、分割後の行数・金額の合計が一致するか（検算）
・注意が必要な取引先（空欄、記号の置換など）
・次回、自分で実行するときのコマンド
```

この依頼文は、別のAI（Claude）に渡して、実際に実行させました。13個のファイルと、分割ログ、スクリプトが作られ、行数と金額の合計は、元の売上一覧と一致しました。元の売上一覧は変わっていませんでした。

### ③のコツと注意点

- **検算を、報告に含めさせる**：行数と金額の合計を、元と分割後で比べさせます。報告文だけでなく、できたファイルを自分でも開いて確かめてください
- **「スクリプトを残して」と頼む**：次回から、AIを使わずに自分で実行できます
- **コピーしたフォルダで作業させる**：元の売上一覧を触らせないためです

## つまづきポイント（②③に共通）

### 数字が空欄になる

元のセルが数式のままで、Excelで一度も保存されていないと、結果が空欄になります。Excelで一度開いて、保存し直してください。

### 結果のファイルが保存できない（PermissionError）

同じ名前のファイルを、Excelで開いたままにしています。閉じてから、もう一度実行してください。

### 見出しの名前が違う（ValueError）

`KEY_COL` と `AMOUNT_COL` の名前が、売上一覧の見出しと、1文字でも違うと止まります。全角と半角、末尾の空白も区別されます。見出しを確かめて、書き換えてください。

### 金額の列が、数値ではなく文字になっている

「1,000」のように、文字として入っていると、金額の合計がおかしくなります。シートの構造を文字で説明して、AIに直してもらいます。

```
売上一覧の「金額」列に、数値と、文字として入った数字（「1,000」や「¥1,000」）が混ざっています。
どちらも数値として扱って、合計と検算ができるように、スクリプトを直してください。
現在のスクリプトは以下です。
（貼り付ける。個人情報や取引先名は入れない）
```

## 詰まったときの、AIへの聞き方

エラーが出たときに「エラーが出ました」とだけ書くと、的外れな答えが返ります。次の4つを、毎回そろえて貼ります。

```
【やろうとしたこと】
売上一覧のExcelを、取引先ごとのファイルに分ける

【実行したもの】
（コマンド、または、どの操作か）

【出たエラー（全文）】
（出た文を、そのままコピーして貼る）

【環境】
Windows 11 / Excelのバージョン / Python 3.14（使っている場合）
```

- エラーは、**全文**を貼ってください。最後の1行だけでは、原因が分かりません
- 実際のデータ（取引先名・金額など）は貼らないでください

## まとめ

売上一覧を取引先ごとに分ける作業は、ピボットテーブルの機能、チャットAI、AIエージェントのどれでも片づきます。ファイルとして送るなら、②か③です。3つとも、同じサンプルで確かめました。②③は、末尾に空白がある取引先も、記号を含む取引先も、取引先が空欄の行も、止まらずに処理し、行数と金額の合計が元と合うことまで確かめられます。
