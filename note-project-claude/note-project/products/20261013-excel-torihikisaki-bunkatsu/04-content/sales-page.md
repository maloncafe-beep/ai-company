# note「概要」欄・SNS告知の元ネタ

## 概要欄（案）
毎月、システムから出した売上一覧を、取引先ごとに分けて送っている方へ。解決は3通りあります。①ピボットテーブルの機能で取引先ごとのシートを作る、②チャットAIにPythonスクリプトを書かせて取引先ごとのファイルに分ける、③AIエージェントに作業ごと任せる。それぞれの概要と、同じデータで試した結果は無料部分に、手順・依頼文・動いたスクリプトの全文は有料部分に載せています。末尾に空白がある取引先、ファイル名に使えない記号、取引先が空欄の行が混ざっても止まらず、行数と金額の検算までする作り方です。（サンプル284行・12社で確認）

## シリーズ
社内の困りごと解決シリーズ #2。#1は、社員ごとのExcelを1つにまとめる作業。
