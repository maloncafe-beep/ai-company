# 低評価を伝える面談台本テンプレート

1. 事実の確認（「今期は〇〇という結果でした」）
2. 評価の伝達（「今回の評価は〇〇です」）
3. 期待の提示（「次は〇〇を一緒に目指したい」）
4. 相手の言葉を聞く（ここで止める。畳みかけない）

```
あなたは経験豊富な人事コンサルタントです。
私はこれから部下に低い評価を伝える面談をします。
以下の情報をもとに、「事実」「評価」「次への期待」の3つに分けて
話す内容を整理してください。
```

# 目標設定面談「曖昧→具体的」変換プロンプト

```
あなたはキャリアコンサルタントです。
以下は部下が期初に立てた目標です。曖昧な表現を、
「何を」「どのレベルまで」「いつまでに」の3点が分かる形に
書き直す案を3つ提案してください。
```

# 反発・沈黙への切り返しシミュレーションプロンプト

```
あなたは評価に納得していない部下役を演じてください。
私（評価者）が話しかけたら、以下のどちらかの反応をランダムに
返してください。
1. 黙り込む、短い返事しかしない
2. 「納得できません」と反論する
```
