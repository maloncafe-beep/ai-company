## 横断的な気づき

1. **1on1記事は、同じ経過日数（約2日）でインプレッションが評価面談記事と同じ（26）、PVとスキは上回った**（PV 8 vs 5、スキ 2 vs 0）。ただし母数が数件で、差があるとは言えない。方向がよさそう、という段階。
2. **1on1記事のPV/インプレッション30.8%は、他記事（2〜13%）より高い**。ただしX告知経由のPVが入っているため、タイトル・サムネの効果とは切り分けられない。
3. **古い記事の数字は、集計期間の違い（10/6まで＝過去28日間、10/8＝全期間）で大きく見えているだけ**。バックオフィス47→695などの増加は、期間を変えたことによるもので、実際の増加ではない（経営者の指摘で訂正）。参考表の括弧内の数字とは比較しない。今後は全期間で統一する。なお、Claude工場の3本は公開から28日未満のため、期間による差はない。
4. **古い記事の全期間の数字は、ほぼ最終値として、基準に使える**（経営者の見解：古くなるとPV等はほとんど伸びない）。基準は、インプレッション157〜695、PV 8〜28、スキ1〜9（6本）。1on1記事は公開2日でPV 8、スキ2で、PVは基準の下限（8）に並び、スキも範囲内。インプレッション（26）はまだ基準の下限（157）に届いていない。ただし、古い記事は公開から2か月以上かけて積み上げた数字で、経路（X告知の有無・アカウント等）も違うため、厳密な比較にはならない。今後、1on1記事が基準の範囲にどの時点で届くかを見る。
5. **スキ2件のうち1件は社労士（専門家）のアカウント**（経営者の確認）。もう1件はAI関連のアカウント。公開直後のスキは自動いいねの可能性もあるため、反応の質（コメント・フォロー）で判断する。コメントは0。
6. **売上は全記事で0**（有料は2本のみ）。新規開拓 vs アップセルの比較は、1本目92インプレッション、2本目62で、優劣を言える母数ではない。
