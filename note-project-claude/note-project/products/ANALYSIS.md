## 横断的な気づき

1. **3本のClaude工場記事は、PVが6〜12、スキが0〜4で、大きな差がない**。1on1記事は7日目でインプレッション45・PV9・スキ2で、40代転職の7日目（69／8／4）と同水準かやや下。10/8時点の「方向がよさそう」は、7日目の数字では支持されない（母数が小さく、差は誤差の範囲）。
2. **古い記事は、5日間でほぼ動かない**（インプレッション+0〜+14）。経営者の見解「古くなるとほとんど伸びない」と整合する。基準として使える。
3. **評価面談記事のインプレッションが10/8の62から10/13の199に増えた**一方、PVは5→6とほぼ増えていない。表示は増えたがクリックは増えていない。原因は不明★（note内のおすすめ・検索への露出が増えた可能性はあるが、データからは言えない）。
4. **PV/インプレッション（20.0%）は1on1記事が最も高い**が、インプレッション自体が少ない（45）。PVの多くはX告知など直接の訪問の可能性がある。
5. **スキ2件のうち1件は社労士（専門家）のアカウント**（経営者の確認）。コメントは0、スキは10/8から増えていない。
6. **売上は全記事で0**。
