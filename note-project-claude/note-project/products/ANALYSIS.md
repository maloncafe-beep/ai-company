## 横断的な気づき

1. **表示されてもクリックされない問題が全アカウント共通**：クリック率は2〜10%台で、特別高くない。タイトル・バナーのインパクトがボトルネックになっている可能性
2. **Claude工場の2本はまだ比較に足る母数がない**：インプレッションが60・15と、他記事（46〜279）より少ない。到達経路（SNS告知頼み）の差が出ている可能性が高い
3. **新規開拓 vs アップセルの比較はまだ判断材料不足**：2本目（アップセル狙い）は公開1日のため、1本目との優劣はまだ言えない。3〜5日後に再比較する
