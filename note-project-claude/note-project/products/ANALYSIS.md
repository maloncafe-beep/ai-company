## 横断的な気づき

1. **表示されてもクリックされない問題が全アカウント共通**：クリック率は0〜19%と幅があるが母数が小さく、特別高くない。タイトル・バナーのインパクトがボトルネックになっている可能性
2. **Claude工場の2本はまだ比較に足る母数がない**：インプレッションが69・26と、他記事（25〜293）と同水準かやや少ない。ただしクリック率はClaude工場の2本（11.6%・19.2%）が他記事（0〜8%）より高く、タイトル・導入は悪くない可能性。到達経路（SNS告知頼み）の差が出ている可能性が高い
3. **新規開拓 vs アップセルの比較はまだ判断材料不足**：2本目（アップセル狙い）は公開1日のため、1本目との優劣はまだ言えない。3〜5日後に再比較する
