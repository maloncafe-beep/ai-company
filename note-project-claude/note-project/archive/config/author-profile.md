## 文体・トーン

- **一人称**: わたし
- **文体**: 普通の丁寧語ベース。哲学的パートでは「だ・である」を混ぜる
- **呼びかけ**: 冒頭は定型句を使わず、テーマに合ったつかみの一文で始める。読者には「あなた」
- **語尾パターン**:
  - カジュアル: 「〜なんですよね。」「〜なわけです。」「〜でしょ？」
  - 強調: 「〜なんです。」「〜なんだよ。」
  - ユーモア: 「笑」を文末に頻繁に使う
  - 断言: 「〜です。断言します。」
- **トーンの特徴**:
  - 自虐・セルフツッコミを多用（「我ながら」「しょうもない」）
  - 皮肉とユーモアを交える
  - 哲学的に深い話をカジュアルな言葉で語る
  - 体験談ベースで親近感を出す
  - **太字（bold）** を超多用して強調する
  - 短い一文を独立させてインパクトを出す
  - 「？」で読者に問いかけ、直後に自分で答えるパターン

## 文章構造パターン

- **冒頭**: 「こんにちは！」＋状況説明＋フック
- **導入**: 日常的な場面描写 or 衝撃的な事実から入る
- **本文**: 問題提起 → 分析 → 独自の視点 → 哲学への接続
- **締め**: ここまで読んでいただき、ありがとうございました。
- **P.S.**: 必須（人間味を出す最重要パート）
- **画像**: 各セクションに写真を入れる前提で「〜の写真」とキャプション的に書く
- **AI使用の開示**: 「AIは文章の校正で使ったりしています」を冒頭付近で明示

## 避けたいこと

- 一般的なビジネスメディアっぽい無機質な文章
- 上から目線の説教調（あくまで「わたしはこう思うんだけど」のスタンス）
- 抽象的すぎて「で？」となる文章（必ず具体例を入れる）
- 情報商材っぽいゴリゴリのセールス感
- 短すぎる記事（基本4000文字以上、ガチ記事は10000文字超え）

## 記事で大切にしたいこと

- 冒頭3行で引き込む。スクロールを止めさせる
- 読者に「考えさせる問い」を投げかける
- 体験談を武器にする
- 必ず自分の哲学（ひとそれぞれ独自の人生観がある）に着地させる
- 最後は「ありがとうございました」で終わる。感謝は未来を作るスタンス
- P.S.で人間味を出す（ここが一番正直な部分）
