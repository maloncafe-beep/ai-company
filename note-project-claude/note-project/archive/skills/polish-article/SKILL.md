# polish-article スキル

## 発動トリガー
「推敲して」「チェックして」「ブラッシュアップして」

## 実行手順

### Step 1: 設定ファイルの確認
`config/writing-style-guide.md` のNGパターンと照合。

### Step 2: 5軸チェック

**① スタイル再現度（Maloncafe度）**
- 一人称が「わたし」か
- 太字が核心メッセージに使われているか
- 「笑」の頻度と場所が自然か
- 一文60文字以内か
- P.S.があるか
- 「ありがとうございました。」で締めているか

**② 冒頭フック力**
- 冒頭3行でスクロールを止めるフックがあるか
- 「こんにちは！ご機嫌いかがですか。」系で始まっているか

**③ 哲学接続度**
- Well-being/LTR/Giver・Taker/価値提供のいずれかに着地しているか
- 「上から目線」になっていないか（「わたしはこう思う」スタンスか）

**④ バズ度**
- 逆説・意外性・断言があるか
- 読者が「RT・シェアしたくなる」文章があるか
- タイトルに数字・問い・断言が入っているか

**⑤ noteフォーマット適合度**
- `###`以下の見出しが使われていないか
- テーブルが使われていないか（箇条書きで代替されているか）
- コードブロックが使われていないか

### Step 3: フィードバック形式

```
## 推敲レポート

### ✅ 良い点
- 

### ⚠️ 要修正
- 

### 💡 改善案
- 

### Maloncafe度スコア: ○/10
```

### Step 4: 修正版の提案
要修正箇所が3つ以上ある場合、修正版を提示するか確認する。
