# 婚活・結婚・子育て支援——結局何が問題なのか（リサーチメモ）

## 概要

日本は**「結婚したい人は多いのに、結婚しない人が増えている」**というパラドックスの中にいる。同時に**婚活産業は拡大**し、マッチングアプリ経由の結婚も過去最高水準。一方で出生数は1899年以降初の70万人割れ（2024年）、婚姻数も半世紀で半減している。

子育て支援は**量的には過去最大級に拡大**しているが、出生率は下がり続けている。**「支援が失敗した」のか「支援のターゲットがズレている」のか**を切り分ける必要がある。

本リサーチの結論（先に）：**本質的な問題は「個人の意志不足」でも「国家の予算不足」だけでもない。**  
**「結婚・子育てという人生イベントに到達するための社会的インフラ（出会い・収入・時間・ケア）」が、個人の幸福と国家の持続可能性の両方を同時に蝕んでいる構造問題**である。

---

## 問題の整理：3層構造

| 層 | 何が起きているか | 主な問題の性質 |
|----|------------------|----------------|
| **① 個人（ミクロ）** | 結婚願望と行動のギャップ、婚活疲れ、将来不安、未婚者の幸福度格差 | 心理・関係性・経済不安 |
| **② 市場・文化（メゾ）** | 婚活の産業化、アプリのスワイプ文化、結婚の「格差装置化」 | インセンティブの歪み・代替可能性の増大 |
| **③ 国家・制度（マクロ）** | 社会保障の持続性、労働力不足、単身世帯急増、政策の費用対効果 | 財政・人口・インフラ |

**重要：①②③は独立ではない。**  
個人が「結婚しない」と決めたのではなく、②の市場が①を消耗させ、③の制度が①②の成果を十分に支えられていない——という連鎖がデータと整合する。

## ① 婚活の「流行」——成功しているのに、結婚は減っている

### 何が起きているか（ファクト）

- 婚活・マッチングは**産業として成長**している（売上342億円、参入企業5.6倍）。
- それでも**婚姻数・出生数は減少**し続けている。
- 婚活サービス利用者の恋人満足度（71.5%）は非利用者（65.5%）より高い——**「出会いの質」は一定改善している可能性**がある。
- 2023年の婚姻の15.3%が婚活サービス経由＝**「婚活は無駄」ではない**。ただし**残り85%は別ルートまたは未達**。

### 構造的問題（意見・分析）

| 論点 | 内容 |
|------|------|
| **パラドックスの正体** | 婚活は「結婚の**手段**」の市場化。結婚そのものの需要が減れば、市場は拡大しても**分母（婚姻数）は縮む**。 |
| **インセンティブの逆行** | 利用者のゴール＝良い相手を見つけてアプリをやめる。運営のゴール＝継続課金。**構造的に「成功＝収益減」**。 |
| **商品化・スペック化** | 相談所の「OK/NG項目」教育、容姿・年齢による市場価値の可視化。**本音よりパッケージ**が評価される。 |
| **代替可能性の増大** | 数百万人の候補＝「次のスワイプでいい人がいるかも」という心理。**長期的な親密関係の形成を阻害**しうる。 |
| **自然な出会いの消滅** | 30〜34歳未婚率：男性21.5%→49.5%、女性9.1%→38.5%（数十年で）。**「皆婚社会」の崩壊**により、意図的婚活が必須化→疲弊コスト増。 |

### 個人の問題か？国家の問題か？

| 視点 | 判定 |
|------|------|
| **個人** | 婚活疲れ・自信喪失は**個人が抱える苦痛**だが、原因は「努力不足」ではない。 |
| **国家** | 出会いインフラの民営化に依存し、**労働時間・非正規・地域格差**を放置した結果、**結婚到達コストが社会全体で上昇**している。 |

## ② 結婚願望の「低下」——本当に減っているのか？

### データが示す「二層構造」

**層A：願望はまだ高い（が、弱まっている）**
- 若年未婚の約80%は「いずれ結婚したい」
- ただし新成人の「結婚したい」は73.2%で過去最低

**層B：行動・到達が追いつかない**
- 「交際を積極的にしたい」は51.7%で過去最高
- → **「したい」と「結婚したい」が乖離**している
- IPSS分析：**「離脱型」（結婚意欲そのものが薄い層）の増加**
- 障壁として多いのは「適切な相手に出会えない」「異性とうまく付き合えない」

### 「結婚願望低下」の正確な言い方

| 言い方 | 妥当性 |
|--------|--------|
| 「日本人はもう結婚したくない」 | **過剰**。願望は残るが、**到達率・タイミング・意欲の強度**が低下。 |
| 「結婚から離脱する人が増えた」 | **妥当**（IPSS・日経の表現）。 |
| 「晩婚化だけの問題」 | **不十分**。50歳未婚率の急増は**生涯非婚**の問題。 |

### 個人の問題か？国家の問題か？

| 視点 | 判定 |
|------|------|
| **個人** | 未婚でもソロ活で満足する人はいる（56.7%が満足）。**全員にとって「結婚＝幸福」ではない**。ただし男性40〜50代未婚は不幸度が高まる傾向（独身研究・各種調査）。 |
| **国家** | 「結婚したいのにできない」層が増えると、**出生・税基盤・介護の家族内共助**が同時に毀損。**未達の願望が外部性を生む**。 |

## ③ 子育て支援の「失敗」——全部失敗ではない

### 何が「成功」しているか（ファクト）

| 施策 | 効果のエビデンス |
|------|------------------|
| **保育所・認可保育の拡充** | 定員100%増でTFR約+0.139（RIETI推計）。1990〜2020年の実績で約+0.097の押し上げ。**効果あり**。 |
| **待機児童の削減** | 2025年4月時点2,254人。ピーク2.6万人から大幅減。**量的目標は達成に近い**。 |

### 何が「失敗」または「不十分」か（ファクト＋分析）

| 論点 | 内容 |
|------|------|
| **ターゲットのズレ** | 2017年以降の出生率低下の約4割は**有配偶出生率の低下**（第一生命経済研究所）。＝**「結婚した夫婦が子を持たない」問題が増えている**。保育・児童手当だけでは届かない。 |
| **現金給付の限界** | 一律児童手当拡充は費用対効果が小さいとの指摘（第一生命経済研究所）。**被扶養者・所得制約世帯**には効くが、全体には弱い。 |
| **隠れ待機・地域偏在** | 公式待機児童は減ったが、希望施設に入れない保留児童は**6万人超**が高止まり。過疎地は逆に**定員割れ（74.6%）**。 |
| **人材不足** | 待機解消できない自治体の46.1%が「保育人材確保困難」を挙げる。 |
| **支出は増えているが出生は減る** | こども未来戦略でGDP比11%→16%目標など**規模はOECDトップ級に**。だがTFRは1.2まで低下。**「金をかけた＝子が生まれる」ではない**。 |
| **時間・ジェンダー・所得** | 女性の出産年齢上昇（29.6歳→32.2歳）、男性低所得層の非婚化。**働き方・賃金・役割分担**が先に来る。 |

### 「失敗」の正確な定義

| 定義 | 内容 |
|------|------|
| **完全失敗説** | 過剰。保育拡充など**部分的成功**はある。 |
| **構造失敗説** | **妥当**。支援は「既婚・既に子を持つ／持とうとする層」に届きやすく、**未婚化・晩婚化（出生の8割）**には届きにくい。 |
| **設計失敗説** | 現金中心・後追い給付より、**出会い・初婚・第二子のタイミング（スピード・プレミアム型）**へのシフトが研究上も推奨される。 |

## 結局、何が「問題」なのか——統合フレーム

### 問題①：到達ギャップ（Marriage Attainment Gap）

```
結婚願望（高）  ×  結婚到達率（低）  ＝  社会の歪み
交際意欲（上昇） ×  婚姻数（半減）    ＝  同じく
```

**これは個人の問題というより、「社会OS」の問題。**  
出会い・収入・住居・時間・役割期待が同時に必要で、どれかが欠けると**全てが止まる**。

### 問題②：婚活産業と本質的ニーズのズレ（Market Misalignment）

婚活市場は**「出会いの効率化」**には成功しうるが、**長期的・相互に支え合う関係の構築**には最適化されていない。  
スワイプ・スペック・課金モデルは**代替可能性を最大化**し、深い親密関係の形成を阻害しうる。

### 問題③：政策のフェーズミスマッチ（Policy Phase Error）

| フェーズ | 日本の状況 | 有効な政策例 |
|----------|------------|--------------|
| **結婚前** | 未婚化が主因（8割） | 出会い支援、賃金、労働時間、男性非婚化対策 |
| **結婚後・子育て前** | 有配偶出生率も低下 | 第二子の早期化（スピード・プレミアム）、家事・育児分担 |
| **子育て中** | 保育は改善、隠れ待機残存 | 保育士確保、地域偏在、柔軟な保育 |

**現状：子育て中フェーズへの投資は増えたが、結婚前フェーズの構造改革が遅い。**

### 問題④：格差の再生産（Inequality Feedback）

結婚がかつては**所得平等化装置**だったが、今は**格差拡大装置**になりつつある（内閣府経済社会総合研究所等）。  
低所得男性の非婚化→単身高齢化→社会保障負担増、という**悪循環**。

## 個人の問題か、国家の問題か——答えの整理

| 問い | 答え |
|------|------|
| **個人だけの問題？** | **No。** 婚活疲れ・将来不安は実在するが、**社会構造・市場・制度**が先に存在する。 |
| **国家だけの問題？** | **No。** 全員が結婚すべきではない。ソロ選択も幸福の一形態。**強制はできないしすべきでない**。 |
| **両方の問題？** | **Yes。** ただし**同じ問題の表裏**ではない。 |
| **個人にとっての「問題」** | ①将来不安（8割）②経済不安③孤立（相談しない未婚者40%）④男性中高年の幸福度低下リスク |
| **国家にとっての「問題」** | ①税基盤・社会保障②労働力③GDP成長④医療介護人材⑤単身高齢貧困⑥家族前提制度の破綻 |
| **両者が交わる点** | **「結婚・子育てに到達できない」こと自体**が、個人の幸福（関係性・生活の意義）と国家の持続可能性（家族・地域を支える関係網の基盤）を同時に損なう |

### よくある誤解の整理（ぶった切り候補）

| 常識 | ぶった切り |
|------|------------|
| 「婚活を頑張れば結婚できる」 | 市場が拡大しても婚姻数は半減。**努力の問題ではなく到達コストの問題**。 |
| 「子育て支援を増やせば出生率は上がる」 | 保育は効くが、**未婚化8割の時代に子育て支援だけ打っても穴に水**。 |
| 「結婚願望が下がったから少子化」 | 願望は残る。**離脱型増加＋到達不能**が本体。 |
| 「未婚＝不幸」 | 一概には言えないが、**将来不安・孤立・男性中高年リスク**はデータあり。 |
| 「個人のライフスタイル尊重 vs 国の存立」 | 二元論は偽。**出会いと長期的な関係を支える社会の再設計**が両方の利益になりうる。 |

## 歴史的背景（簡略）

| 時代の論点 | 主張 | 限界 |
|------------|------|------|
| 高度成長期 | 皆婚社会・終身雇用・社内恋愛 | 女性の選択肢・多様性を犠牲にした |
| バブル〜失われた30年 | 個人の自由・キャリア優先 | 到達コスト上昇を放置 |
| 婚活産業時代（2000s〜） | 市場が出会いを効率化 | スペック化・課金モデルが長期的関係を蝕む |
| 少子化対策拡大期（2010s〜） | 保育・児童手当 | 未婚化フェーズに手遅れ気味 |
| こども未来戦略期（2020s〜） | 財政投入の最大化 | 出生率はなお低下 |

→ **「個人が悪い」「国が悪い」「婚活が悪い」だけでは説明しきれない。関係性のインフラ全体の設計失敗。**
