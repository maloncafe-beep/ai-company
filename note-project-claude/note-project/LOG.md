# note-project インフラ作業ログ

## 2026-09-30

### やったこと
- サムネ画像（バナー）生成のコスト構造を見直し。従来は毎回Higgsfield（Nano Banana）で文字込み一発生成しており、Freeアカウントのクレジット（残2）を都度消費していた。
- 「文字なし背景を使い回し、タイトル文字はローカル合成」方式に切り替え。
- `scripts/make_note_banner.py`（Python/Pillow）を新規作成。背景画像＋タイトル＋サブタイトルを合成してPNG出力する。背景が無い場合はグラデーションのプレースホルダーで代用。
- `config/banner-style.json` にフォント・色・レイアウト・テーマ別背景の対応表を定義。
- `.claude/skills/phase5-thumbnail/SKILL.md` を改訂。「通常はローカル合成、新しい背景パターンが欲しい時だけHiggsfieldで1枚生成」という運用に変更。
- `assets/banner_bases/`（文字なし背景の置き場）を新設（現時点で0枚）。

### 結果
- プレースホルダー背景での動作確認済み（日本語タイトル・サブタイトルの折り返し・縁取り描画が正常）。テスト出力は確認後に削除。
- 以降、何案バナーを出してもHiggsfieldクレジットを消費しなくなった（背景が揃っている前提）。

### 学び・新ルール
- 画像生成AIのクレジットは「毎回の差分が小さい部分（タイトル文字）」には使わず、「ゼロから作る必要がある部分（背景の絵柄）」にだけ使うとコスト効率が良い。
- Claude Code Pro課金の範囲内で完結させたい作業は、外部生成系をなるべく使わず、ローカルスクリプト（Python/Node等）に寄せるのが良い。
