## 「まともに見える」ための運用ルール

1. 投稿は無理のない範囲でよい。**最低ラインは「固定ポスト＋リリース告知（ハッシュタグ付き）」のみ**。読み物は余力があるときだけ `posts/01-initial-posts.md` から出す。
2. **フォロー数は絞る**。AI・業務効率化・人事系の実務アカウントを数十件フォローし、ホームが空に見えないようにする（相互フォロー目的の大量フォローはしない）。
3. 空のタイムラインが気になる場合のみ、読み物を2〜3本出す（必須ではない）。
4. トーンは note と同じ（一人称「わたし」・丁寧語＋ときどき断言、自虐は軽く）。AI臭い定型句は避ける。
5. **ハッシュタグ必須**。フォロワーがいない間は、タグ検索経由でしか見られない。毎ポスト1〜2個（#AI活用 #業務効率化 #人事評価 #40代転職 など、記事内容に合うもの）。タグも文字数に入るので、本文は少し短めに。
6. 投稿は手動コピペで運用する（リリース案内程度ならx-auto-post/APIは不要）。文案は `posts/` に置く。

## 経営者が行うこと（手動）

2. 固定ポストを投稿 → 「プロフィールに固定」
3. 鍵アカウントになっていないか確認（鍵だと告知が届かない）
