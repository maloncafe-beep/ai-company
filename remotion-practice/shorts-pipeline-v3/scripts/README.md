# scripts/ 台本管理フォルダ

shorts-pipeline-v3でレンダリングする台本のソースを管理する。
`input/temp/Voicebox.txt` に流し込む前の一次情報はここに残す。

## 構成

```
scripts/
  勝海舟の言葉プロンプト.md         ← 台本生成プロンプト（50選から1つ選んで台本化する指示）
  勝海舟語録No.txt                 ← 公開順リスト（公開日時・台本No・タイトル・尺）＋50選対応表
  yyyy-mm-dd_台本No_タイトル.md    ← 生成した台本テキスト（1本＝1ファイル）
```

## 運用ルール

- 台本を新規作成したら `yyyy-mm-dd_台本No_タイトル.md` で保存する（例: `2026-09-24_05急いでも仕方ない寝転んで待つ.md`）
- 尺ルール: 1.5分（毎日）・3分（週1〜隔週1）。作成前に必ず尺を確認する
- 新しい台本を作ったら `勝海舟語録No.txt` の公開順リストと対応表（台本No.列）に追記する
- 台本には【タイトル】を必ず入れる（動画冒頭でWAV化して毎回読み上げる、目を惹くタイトルコール）。【動画タイトル案】とは別物
- 1文30文字程度、1画面（スライド）は4行まで＝60文字が限度。カンマでの細切れ分割は不要で、基本は1文＝1画面。60文字を超える長い文だけ、自然な区切りで2画面に分ける
- 引用「」の閉じ括弧の直前に「。」を置かない（例: 「〇〇〇〇。」ではなく「〇〇〇〇」）。レンダー時に改行されてしまうため
- VOICEBOX用の `キャラ名（スタイル）,テキスト` 形式（`input/temp/Voicebox.txt`）は作らない。台本md（【台本】本文）だけ作れば十分で、VOICEBOX.txtへの流し込みはユーザー側でVOICEBOXのテキスト掃き出し機能を使う
- プロンプトを変更した場合は `勝海舟の言葉プロンプト.md` を上書きし、変更理由をこのREADMEか台本ファイル側に一言残す
- 台本の最後に【動画説明文】を必ずつける（これまでChatGPTで都度作成していたもの）。チャンネル登録・高評価を導く形で、末尾のハッシュタグは `#タグ, #タグ, ` のカンマ区切り。形式は `2026-09-30_11人には余裕が必要.md` の【動画説明文】を参照
