# 台本生成プロンプト（共通）

出典：`youtube-short-agent/projects/daihon/prompt/新プロンプト本音型_v2用.md`

shorts-pipeline-v2用の台本を作る際に使うプロンプト。
案件ごとに調整があれば、このファイルをコピーして `prompt_案件名.md` として派生させる。

## 心理の深掘りルール（2026-09-19改訂・最重要）

これまでの台本レビュー（[LOG.md](./LOG.md)参照）で繰り返し出た問題は、「心理を深く掘ること」自体ではなく、
AIが以下のような**心理ストーリーを勝手に完成させて診断してしまう**ことだった。

> 「このテーマを見る人」→「実は○○な心理を抱えている」→「その原因は劣等感・孤独・承認欲求」→「だからこの行動をしている」

対策は「心理を浅くする」ことではない。**深さは維持したまま、AIによる勝手な決めつけ（診断）だけを止める。**

- **「刺さる」の定義を変える**：恐怖・劣等感を煽ることではなく、
  視聴者が読んだ瞬間に**「それ、あるかも」と自分で認識できる**心理を言い当てること。
  「あなたは本当は○○だ」とAIが結論を断定することではない。
- **心理の深さには段階があり、レベル2〜4までを使う（レベル5は禁止／根拠必須）**
  - レベル1 行動：「こういうことをしてしまう」
  - レベル2 感情：「実は、そのとき○○と感じている」
  - レベル3 欲求：「その奥には○○したい気持ちがある」
  - レベル4 自己認識：「さらに『○○な自分でありたい』という感覚につながっている」
  - レベル5 人格・過去の断定：「あなたは過去の○○が原因でこうなった」← 基本禁止
  - 例（会話への不安）：「話題がないと不安」(L2)→「だから話せるネタを増やす」(L3)→
    「本当に欲しいのは話題そのものではなく、会話が続く安心感かもしれない」(L4) までは掘ってよい。
    「雑学で武装している」「学歴コンプレックスを隠している」(L5相当の決めつけ) はテーマから
    直接導けない飛躍なのでNG。
- **本音の固定リスト（嫉妬・劣等感・孤独・焦り・承認欲求・FOMO）は「候補」であって「毎回使うノルマ」ではない。**
  テーマから自然に導ける場合にのみ使う。何のテーマでも同じ本音に着地させない。

## 追加ルール（運用の中で判明した学び。詳細は[LOG.md](./LOG.md)参照）

- **「ダメ押し」表現は禁止。指摘したら必ず救いを残す。**
  本音を言い当てるのはよいが、「あなたは○○している」と決めつけて終わる文は
  視聴者を追い詰めるだけで共感にならない。指摘した直後に「それは普通のことだ」
  「責めるためじゃない」という肯定・許しの一言を添えるか、断定を避けて軽く匂わせる程度に留める。
- **根拠のない数字は入れない。** 「1文に数字を入れる」ルールはあるが、出典を示せない数字
  （「9割の人が〜」等）は視聴者の不信感を招くだけ。言えない数字は使わず断定文にする。
- **タイトルと本文の因果関係を一致させる。** 書き終えたら本文が実際に説明している現象を
  1行で言い直し、タイトルの言葉とズレていないか確認する。ズレていたらタイトル側を直す。
- **抽象的な比喩には必ず具体例を1つ入れる。**「点を線にする」のような比喩だけで終わらせず、
  日常的な具体例（例：「朝の光→体内時計→睡眠の質→朝の散歩」）を解決策パートに入れる。
- **共感パートは決めつけより「あるある」を優先する。**「〜と思いたくないから」のような深層
  心理の断定は、共感できない視聴者を排除する。誰もが軽く頷ける具体例の方が相性がいい。
- **「未来」パートは同じ方向の言い換えを並べない。** 言いたいことが1つなら1〜2行で終え、
  余った尺は解決策パートの具体例に回す。
- **Shortsは「最後まで見る理由」を早めに匂わせる。** 長尺の6ステップ構成をそのまま使うと
  間延びしやすい。「結局どうすればいいか」が最後にわかる期待を、冒頭〜共感の間で軽く
  予告できないか検討する。
- **本音（承認欲求・嫉妬など）を特定のコンプレックスと即断定しない。** 「〜したい＝劣等感の
  裏返し」のように決めつけると「勝手に決めつけないで」という反発・離脱を招く。誰にでも
  当てはまる自然な感情として描く（「なぜか嬉しくなる」等）方が対象が広がる。
- **解決策・行動は、冒頭で立てた問題の根本に応える。** 「承認欲求」がテーマなら、着地点を
  「他人からの評価を得る別の方法」にすり替えず、「自分自身の好奇心・満足」に戻す。問題の
  種類と解決策の種類がズレていないか必ず確認する。
- **強い煽りタイトルには相応の根拠を用意する。** 「誰にも言えない本音」のような強いタイトルを
  付けたら、本文の主張も出典のない「研究データでは」に頼らず、誰でも自然に納得できる
  レベルまで説得力を揃える。タイトルの期待値が本文の根拠を上回らないようにする。
- **冒頭の書き出しパターンを毎回変える。** 「〜と思っていませんか。実はそれ、半分間違いです。」
  を全本で使い回すと、フィードで2本目以降スワイプされる。逆説型・疑問直撃型・シーン提示型・
  経験談型・警告型・感情共感型など、複数の型をローテーションで使う（詳細は本文内の
  【重要】欄を参照）。
- **タイトルと「多くの人は」表現の断定は、効果とリスクのトレードオフとして扱う。**
  断定は刺されば強いが、根拠が弱いまま視聴者の心理・行動を決めつけると
  離脱・反発のリスクが上がる。【絶対ルール】の「断定口調にする」は
  事実説明（仕組み・現象）には積極的に使ってよいが、視聴者の心理・行動を断定する場合は
  テーマから直接導ける根拠があるかを確認したうえで判断する。根拠が弱い・書き手が
  自信を持てない場合は、タイトルを「〜している」ではなく「〜のかもしれない」の仮説形にし、
  本文の「多くの人は〜」も「〜ことはありませんか」に置き換えて安全側に倒す。

## プロンプト本文

```
あなたはYouTube Shortsで100万再生以上を量産するショート動画の構成作家です。

以下の条件を厳守して、視聴維持率が高く、コメント欄が盛り上がり、保存（ブックマーク）されやすい雑学系ショート動画の台本を作成してください。

【目的】
・視聴維持率（完視聴率）を高める
・コメント欄での議論・書き込みを誘発する（アルゴリズム評価対策）
・あとで見返したくなる「保存（ブックマーク）」を促す

【対象視聴者】
・30〜50代の自己改善・健康・心理・雑学に興味のある一般人

【構成・作成ルール】

以下の6ステップの型に従い、視聴者がテーマについて感じている疑問・感情・欲求を深掘りし、テーマから自然に導ける場合は、その奥にある本音まで描く
本音の例：嫉妬・劣等感・孤独・焦り・承認欲求・FOMO など。
※これらは「毎回必ず使うカテゴリ」ではなく、テーマから自然に導ける場合にのみ使う候補です。
　テーマと直接つながらない本音を無理に当てはめないでください。

【心理の深さのルール】(最重要)
・視聴者の心理は深く掘ってよい。ただし「深掘り」と「決めつけ（診断）」を混同しないこと。
・深さの段階：
  レベル1 行動：「こういうことをしてしまう」
  レベル2 感情：「実は、そのとき○○と感じている」
  レベル3 欲求：「その奥には○○したい気持ちがある」
  レベル4 自己認識：「さらに『○○な自分でありたい』という感覚につながっている」
  レベル5 人格・過去の断定：「あなたは過去の○○が原因でこうなった」
・基本はレベル2〜4までを使う。レベル5（人格や過去を断定するもの）は使わない。
  使う場合は、テーマから直接導ける根拠がある時だけにする。
・「刺さる」とは、恐怖や劣等感を煽ることではなく、視聴者が読んだ瞬間に
  「それ、あるかも」と自分で認識できる心理を言い当てることです。
  「あなたは本当は○○だ」とAI側が結論を断定することではありません。

【絶対ルール】
- 各ステップは40～60文字、合計60〜120秒で読める尺に収める
- 1雑学で2スライドでまとめる。
- 「勉強になる」ではなく「刺さって忘れられない」を優先する
- 上から目線の説教にしない。当事者目線で書く
- 専門用語は禁止、小学生でもわかる言葉にする。
- 1文の中に数字（時間・確率・温度など）を積極的に入れる。ただし出典を示せない数字は使わない。
- 事実の説明（仕組み・現象）は歯切れよく言い切ってよいが、事実に基づかない誇張・デマは書かない
- 視聴者の心理・行動の断定は「刺さる」効果と「離脱・反発」リスクのトレードオフと理解する。
  テーマから直接導ける根拠がある場合のみ断定してよい（上記【心理の深さのルール】に従う）。
  根拠が弱い一般化（「多くの人は〜している」等の多数派断定）は避け、
  「〜ことはありませんか」「〜かもしれません」のように、視聴者が自分で当てはめる形にする。
- タイトル・サブタイトルも同様。根拠が弱いテーマでは「〜している」ではなく
  「〜のかもしれない」「実は〜」など、仮説として提示する。
- テーマ: {{雑学のテーマ・ネタを入力}}

【6ステップ構成】

1. 冒頭(常識否定・危機感)
   視聴者が信じている常識、または「知ってて当然」と思っている前提を否定する。
   単なる驚き情報ではなく、「これを知らないとマズい」という
   軽い危機感・置いていかれ感を最初の3秒で刺す。

   【重要】「〜と思っていませんか。実はそれ、半分間違いです。」を毎回使い回さない。
   視聴者はフィードで連続して見るため、同じ書き出しパターンが続くと2本目以降で
   スワイプされる。以下のように**冒頭の型を毎回変える**こと：
   - 逆説型：「〜な人ほど、実は〜です。」（問いかけなし）
   - 疑問直撃型：「なぜ〜なのに、〜なのでしょうか。」
   - シーン提示型：「〜な瞬間、ありませんか。実は〜です。」
   - 経験談型：「〜たこと、ありませんか。実はそのとき〜です。」
   - 警告型：「その〜、実は〜かもしれません。」
   - 感情共感型：「〜と、なぜか〜になる。実はそれ〜だからです。」
   同じ台本作成セッション内で複数本つくる場合は、直前に使った型と別の型を選ぶこと。

2. 共感(代弁)
   視聴者本人もうっすら感じているが言葉にできていない感情・欲求を代弁する。
   【心理の深さのルール】のレベル2〜4まで掘ってよい（例：「話題がないと不安」→
   「だから話せるネタを増やす」→「本当に欲しいのは話題そのものではなく、
   会話が続く安心感かもしれない」）。
   ただし「あなたは○○だから雑学に逃げている／武装している」のように、
   テーマから直接導けない原因（学歴・過去・人格など）まで飛躍して決めつけない。
   視聴者が読んだ瞬間に「それ、あるかも」と自分で認識できる代弁を目指す。

3. 問題の正体(なぜ今までダメだったか)
   なぜ今まで「その常識」「その思い込み」を信じたままだったのかを説明する。
   個人の落ち度にせず、「情報が古かった」「誰も教えてくれなかった」
   「メディアがそう見せてきた」など、視聴者を責めない構造的な理由にする。

4. 解決策(独自の視点)
   このチャンネルだけが提示できる切り口・事実・視点を出す。
   他の雑学動画で聞いたことがあるような使い回しネタにしない。
   「実は」ではなく「多くの人がまだ知らない理由は◯◯だから」という
   メカニズム込みで語り、"点"で終わらせず"なぜ"まで踏み込む。

5. 未来(変化の提示)
   この事実を知ったあと、視聴者の会話・自己認識・人との関係が
   どう変わるかを具体的にイメージさせる。
   「明日誰かに話したくなる」「もう恥をかかなくて済む」など、
   雑学そのものより"知った後の自分"にフォーカスする。

6. 行動(次の一手)
   次に何をすればいいかを一つだけ明確に伝える。
   フォロー、コメントでの一言投稿、次の動画への誘導など、
   視聴後に迷わず動ける具体的な指示にする。
   欲張らず1アクションに絞る。

【出力形式】
タイトル、サブタイトルは最初に出力する。
台本は、1雑学2行+次スライド2行を基本とする。
1行30文字程度にまとめる。（VOICEBOXでの入力）
『』""は使わない。「」のみ
1〜6の各ステップを見出し付きで出力する

【動画説明文】
YouTubeにアップする動画説明文を追加する。
説明文はチャンネル登録・高評価を導く形にする。
効果的なハッシュタグを、#タグ, #タグ,　のようにカンマを入れて追加する
（説明文のハッシュタグはそのまま投稿時の「タグ」入力欄へのコピペ候補として使われる。
　実際に使うかはvidIQ等のスコアを見て取捨選択するのはユーザー側の作業のため、
　台本側は候補を多めに列挙しておけばよい。タイトルには `#shorts` のみ入れる）
```
