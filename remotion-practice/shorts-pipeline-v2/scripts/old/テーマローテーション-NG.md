# テーマローテーション管理

出典：[プロンプトの背景.md](./プロンプトの背景.md)（10個の本音 + 6つの心理メカニズム）

毎日アップしても内容がかぶらないよう、視聴者の「本音」を大分類（グループ）で台帳化してローテーションする。
同じ大分類を連続で使わない（最低でも1周してから再登場させる）のが基本ルール。

## 習慣・依存構造（6種・応用枠）

本音カテゴリを一周したあとの"次のサイクル"、または切り口のバリエーションが欲しいときに使う枠。
「なぜ見てしまうか」という視聴行動そのものにフォーカスするグループ。

| 大分類 | No | メカニズム | 本音 | 使用済みタイトル |
|--------|----|-----------|------|-----------------|
| **⑥ 習慣・依存構造** | A | 可変報酬（ガチャ） | 次こそ当たりかもという期待でスクロールが止まらない | 未使用 |
| | B | 認知的省エネ | 何も考えたくない、思考のBGMとして見ている | 未使用 |
| | C | 完了欲求 | 中途半端が気持ち悪い、最後まで見ないと落ち着かない | 未使用 |
| | D | 手持ち無沙汰の解消 | 罪悪感なく暇を埋めたい | 未使用 |
| | E | 儀式化 | いつも通りの安心感が欲しい、習慣になっている | 雑学を見ないと落ち着かない人が、本当は怖がっている「取り残される」感覚 |
| | F | FOMO（取り残され不安） | 話題に乗り遅れたくない、一応チェックする | 雑学を見ないと落ち着かない人が、本当は怖がっている「取り残される」感覚 |

## 運用ルール（仮ローテーション）

1. 大分類①〜⑥を順番に回す（同じ大分類を2本連続で使わない）
2. 大分類の中に複数カテゴリがある場合は、その中でも未使用のNoを優先する
3. 全カテゴリ（10＋6）を1周したら、また①から回す（内容は毎回テーマを変えるので被らない）
4. 新しい台本を作るたびに、下の「使用ログ」に日付・大分類・No・タイトルを追記する
5. 直近3本で使った大分類は避ける（連続かぶり防止の最低ライン）
