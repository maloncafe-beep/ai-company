# YouTube Shorts Writing Style Guide

## 1. このチャンネルの目的

本来の目的は、単発の再生数を追うことではなく、ショートフィードに継続的に掲載されるチャンネルを作ること。

基本的な成長イメージは、

ショートフィード掲載 → 視聴継続 → 「自分のことかも」という自己認識 →
コメント・高評価・保存 → 他の動画も視聴 → フォロー →
さらにおすすめされる動画が生まれる

という循環。

最終的な目標は、フォロワー1,000人と、収益化条件である直近90日間1,000万回のShorts視聴を目指すこと。

「1本を無理にバズらせる」のではなく、「おすすめに乗り続けられるチャンネル」を作ることを優先する。

------------------------------------------------------------------------

## 2. コンテンツの方向性

従来の薄い雑学型から、視聴者の「本音・悩み・無意識の感情」を掘り下げる方向へ移行する。

目指す視聴者の反応は、

-   「え、これ自分のことかも」
-   「そういう理由だったのか」
-   「言われてみれば確かに」
-   「自分もこうしてる」
-   「次から少し変えてみよう」

というもの。

「刺さる」とは、不安や羞恥心を煽ることではない。

視聴者自身もはっきり言葉にできていなかった感覚を、自然な言葉で言語化することを「刺さる」と考える。

------------------------------------------------------------------------

## 3. 心理の深さ

心理は深く、決めつけは浅く。

扱ってよい深さは、

行動 → 感情 → 欲求 → 自己認識

まで。

一方で、

-   性格を断定する
-   過去のトラウマを推測する
-   精神状態を診断する
-   「あなたは○○な人」と決めつける
-   根拠のない心理学的断定をする

ことは避ける。

「〜だからです」と断定しすぎず、必要に応じて「〜かもしれません」「〜と感じることがあります」「〜したくなることがあります」など、自然な余白を残す。

------------------------------------------------------------------------

## 4. 1本の中心は一つ

1本の動画で扱う中心テーマは一つ。

複数の心理学用語や原因を詰め込まない。

「不安」「承認欲求」「孤独」「劣等感」「嫌われたくない」などを何でも結びつけるのではなく、そのテーマに本当に必要なものだけを使う。

重要なのは、

「いろいろ知れた動画」

ではなく、

「一つのことを深く理解できた動画」

にすること。

------------------------------------------------------------------------

## 5. 一番重要なのは「刺さる一文」

台本を書く前に、

「この動画を見終わったあと、視聴者の頭に何を残したいか？」

を考える。

その答えとなる「刺さる一文」を一つ作る。

この一文が動画の核。

例：

「沈黙が怖いのではなく、沈黙した自分がどう見られるかを気にしているのかもしれない」

「相手の反応を先回りするほど、自分の言いたいことが分からなくなる」

この一文が刺されば、動画の価値がある。

2分にするために文章を増やすのではなく、一つの意味を深く理解してもらうために必要な時間を使う。

------------------------------------------------------------------------

## 6. 尺の考え方

短すぎる動画では、

共感 → 原因 → 解決策

だけで終わり、内容が浅くなりやすい。

そのため、現在は2分前後を基本的な設計目安とする。

YouTube
Shortsは3分まで拡張されているため、必要なテーマなら2分を超えることも否定しない。

ただし、

「2分にするために情報を足す」

ことはしない。

「一つの意味を深くするために必要なだけ尺を使う」

ことを優先する。

理想は、

「飽きずに見られる」 「少し考えられる」 「見終わったあとに一文が残る」

動画。

------------------------------------------------------------------------

## 7. 2分動画の考え方

基本的には、

日常の場面 → 共感 → 「なぜ？」への掘り下げ → 本当の理由 → 刺さる一文 →
見方の変化 → 今日できる小さな行動

という流れを自然に作る。

ただし、これを機械的なテンプレートとして埋めない。

「共感を1段追加」 「具体例を2個追加」 「解決策を3個追加」

のように、文字数を増やすための駄文を入れない。

構成よりも、話の流れと意味の深さを優先する。

------------------------------------------------------------------------

## 8. 冒頭

最初の1〜2文で、

「自分のことかもしれない」

または

「なぜそうなるのか知りたい」

と思わせる。

使える入口は、

-   逆説
-   直接的な問い
-   日常の場面
-   視聴者の経験への共感
-   意外な気づき
-   注意喚起
-   感情

など。

「実は」「知らないと損」「99％が知らない」などを毎回使わない。

タイトルですべて答えず、本文の最初の部分でタイトルの疑問を自然に回収する。

------------------------------------------------------------------------

## 9. 具体性

心理の話ほど、具体的な日常場面を使う。

例えば、

「意見を言うのが苦手」

だけではなく、

「自分の意見はあるのに、口にする直前で『これ言ったら変に思われるかな』と考えてしまう」

のようにする。

視聴者が自分の経験を思い出せることが重要。

------------------------------------------------------------------------

## 10. 解決策

解決策は大きな人生論にしない。

今日できる、小さく具体的な行動にする。

例：

-   すぐ答えず2秒待つ
-   「どう思われるか」より先に「自分はどう思うか」を考える
-   いつもの行動を一度だけ変えてみる

「前向きになろう」「自信を持とう」のような抽象的な結論だけで終わらせない。

------------------------------------------------------------------------

## 11. 希望の残し方

視聴者を責めない。

「あなたは気にしすぎ」 「あなたは自信がない」 「だからダメ」

という方向にはしない。

その行動には、その人なりの理由があるという視点を持つ。

そして最後は、

「そう考えると少し楽になる」 「次はこうしてみればいい」

という出口を作る。

------------------------------------------------------------------------

## 12. コメント

コメントを増やすために無理やり質問を入れない。

動画のテーマから自然に答えたくなる問いにする。

例：

「あなたは意見を言うとき、相手の反応と自分の気持ち、どちらを気にしますか？」

「沈黙したとき、すぐ話したくなることはありますか？」

視聴者が自分の経験を話せる問いが望ましい。

------------------------------------------------------------------------

## 13. 言葉のスタイル

難しい心理学用語を多用しない。

小学生でも意味が取れるくらい、平易な日本語を使う。

ただし、簡単な言葉＝浅い内容ではない。

むしろ、

「専門用語で説明する」のではなく、 「日常の言葉で本質を言う」

ことを目指す。

短い一文を重ねすぎて、幼い文章や箇条書きのような台本にならないようにする。

VOICEBOXで読み上げることを前提に、自然な話し言葉にする。

------------------------------------------------------------------------

## 14. VOICEBOX用の文章

VOICEBOXではユーザー側で文章をつなぎ、画面分割を調整する。

そのため、台本側では、

-   「青山龍星（ノーマル）」などの話者名を入れない
-   001a、001bなどの画面番号を入れない
-   画面分割を固定しない
-   自然な文章単位で出力する

こと。

日本語の「」は使用してよい。

ただし、VOICEBOXの自動改行に影響するため、引用文の中に「。」を入れる形は避ける。

例：

「これを言ったら、変に思われるかな」と考えてしまいます

は可。

「これを言ったら、変に思われるかな。」と考えてしまいます

は避ける。

------------------------------------------------------------------------

## 15. 画像との関係

2画面＝1イラストという運用は、画像制作・画像検索の負担を減らすためのルール。

台本そのものを画像に合わせて不自然に作らない。

多少の画面とイラストの意味のズレは許容する。

優先順位は、

台本の意味 → 話の流れ → 視聴者への伝わりやすさ → 画像との完全一致

とする。

画像に合わせるために台本の心理や文章を曲げない。

------------------------------------------------------------------------

## 16. 事実・心理の扱い

根拠のない数字、研究、専門家、心理学理論を作らない。

「科学的に証明されている」「○％の人が〜」などの表現は、確かな根拠がある場合だけ使用する。

一般的な人間行動について述べる場合も、必要なら断定を弱める。

「心理学っぽくする」ために専門用語を追加しない。

------------------------------------------------------------------------

## 17. タイトル

タイトルは、

1.  一瞬で意味が分かる
2.  「なぜ？」が発生する
3.  答えを全部言わない
4.  本文の最初でタイトルを回収できる

ことを重視する。

視聴者の内側の言葉をタイトルにすると強い。

例：

「嫌われたくない人ほど、自分の意見を言えなくなる理由」

「会話の沈黙が怖い人ほど、やってしまうこと」

タイトルだけで答えを完結させない。

------------------------------------------------------------------------

## 18. チャンネルとしての一貫性

動画ごとにテーマは変わっても、

「自分でも気づいていなかった気持ちを、言葉にしてくれるチャンネル」

という印象を積み重ねる。

ジャンルを機械的に、

健康 → 人間関係 → 脳 → ライフハック

と回すことを目的にしない。

先に、

「人は人との関わりで、何を怖がるのか」
「日常の行動の裏に、どんな本音があるのか」

を考え、そこからテーマを見つける。

------------------------------------------------------------------------

## 19. 台本作成時の最終チェック

台本完成後は、細かい構成表よりも次を確認する。

-   このテーマは視聴者の実体験につながるか
-   冒頭で「自分のことかも」が生まれるか
-   中心テーマが一つに絞れているか
-   心理を深掘りできているか
-   決めつけになっていないか
-   刺さる一文があるか
-   その一文に向かって話が進んでいるか
-   文字数を埋めるための文章がないか
-   2分前後でも退屈にならないか
-   見終わったあとに少し考えたくなるか
-   今日できる行動が一つあるか
-   視聴者を責めず、希望のある終わり方になっているか
-   コメントしたくなる自然な問いがあるか
-   次の動画も見たくなるチャンネル感があるか

最終基準は、

**「この動画を見た人の頭に、一つの意味が残るか」**

とする。

------------------------------------------------------------------------

## 20. 基本方針

短いから良いのではない。

長いから良いのでもない。

**「伝えたい意味を、視聴者が自分のこととして理解できる長さまで深める」**

ことを優先する。

2分前後という尺は目的ではなく、そのための手段。

最終的に目指すのは、

**「え、これ自分のことかも」** ↓ **「そういう理由だったのか」** ↓
**「次は少し変えてみよう」**

という視聴体験。

そして、その体験を積み重ねることで、

**「このチャンネルの動画なら、また自分が気づいていないことを教えてくれそう」**

と思ってもらえるチャンネルを作る。
