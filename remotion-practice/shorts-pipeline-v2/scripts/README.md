# scripts/ — 台本管理フォルダ

shorts-pipeline-v2でレンダーする台本のソースを管理します。
`input/slides/` に投入する前段階（企画・ネタ出し・台本執筆）をここで一次情報として残します。

## ファイル命名

```
yyyy-mm-dd_タイトル.md
```

例：`2026-09-17_睡眠の質を上げる3つの習慣.md`

## フォルダ構成

```
scripts/
  README.md        ← このファイル
  prompt.md         ← 台本作成の唯一のルール（プロンプト＋ライティングガイド統合版）
  LOG.md            ← 学び・修正履歴
  プロンプトの背景.md ← 視聴者心理の背景分析
  2026-09-17_タイトル.md   ← 個別の台本
  old/              ← ボツにした旧台本・旧プロンプト
  ...
```

## 台本→レンダーまでの流れ

1. `prompt.md` のプロンプトを使って台本を作成し、`yyyy-mm-dd_タイトル.md` として保存
2. 台本をもとにVOICEBOXで音声を書き出し `input/slides/001a.wav` 等に配置
3. テキストを `input/slides/001a.txt` 等に分解（`npm run split` も利用可）
4. イラストを `public/illustrations/` に配置
5. `npm run go` でレンダリング

台本ファイル自体はレンダリングパイプラインには直接使われず、素材作成前の一次情報として保存する。
