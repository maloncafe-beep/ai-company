## カット割りルール

```
1宿 = 2〜3カット（2秒〜3秒／カット）
```

| カット | 内容の法則 |
|---|---|
| カット1 | **フォトジェニックな風呂・プール・絶景**（一番映えるシーン） |
| カット2 | **部屋・外観・別アングル**（宿の雰囲気を補完） |
| カット3（あれば）| **食事・体験・特徴的なコンテンツ**（差別化要素） |

- カット間のトランジション：**ストレートカット**（フェードなし）
- 人物は積極的に入れる（入浴シーン・歩いている・回転など）

## テキスト仕様

### オープニングタイトル

| 項目 | 値 |
|---|---|
| 書字方向 | **縦書き** |
| フォント | 明朝体・セリフ系（細め〜ミディアム） |
| 文字色 | 白（#FFFFFF） |
| 縁取り | グレー系薄め（背景に溶け込む自然な影） |
| 配置 | 画面中央（水平・垂直） |
| サイズ感 | 大きめ（1080px幅換算で約40〜50px） |
| 表示タイミング | 0秒から表示・4秒でフェードアウト |

### 宿名テキスト（各セクション共通）

| 項目 | 値 |
|---|---|
| 行数 | **2行**（1行目：日本語 / 2行目：英語） |
| フォント | **明朝体・セリフ系**（细め）|
| 文字色 | 白（#FFFFFF） |
| 縁取り | 黒または濃いグレー（薄め・自然な影） |
| 垂直位置 | **画面上部30〜45%**（絵の余白部分に配置） |
| 水平位置 | 背景の余白に合わせて調整（左寄り・中央・右寄り混在） |
| 1行目フォントサイズ | 1080px幅換算で約 **34〜38px** |
| 2行目フォントサイズ | 1行目の **65〜70%** 程度（約22〜25px） |
| 表示タイミング | セクション開始から表示・次の宿に変わる直前にフェードアウト |

### テキスト配置の法則

```
映像の「余白・空」がある方向にテキストを置く
→ 空が映っているなら上部
→ 水面・床なら下部に余白があっても上部に置く傾向
→ 顔・主役が中央にあれば上寄り・左右どちらかへ
```

## Remotion テンプレート実装指針

### 構成

```
TravelReelScene
├── OpeningSlide（0〜120f / 4秒）
│   └── 縦書きタイトル（フェードイン→アウト）
└── 各宿セクション（120f〜）
    └── HotelSection × 10
        ├── ClipView × 2〜3（各60〜90f）
        │   ├── KenBurns or OffthreadVideo
        │   └── HotelNameText（日英2行・フェードイン）
        └── ClipCut（ストレートカット）
```

| 1カットあたり | 2〜3秒 | 60〜90f |

## 映像選定ルール（素材の選び方）

> **前提：このサンプルのターゲットは「ちょっとリッチな女子旅」**
> ターゲットが変われば選び方の優先順位も変わる。以下はあくまでこのターゲット向けの傾向。

| カット順 | このサンプルでの選び方 | 理由（ターゲット起因） |
|---|---|---|
| カット1 | 露天風呂・プール・浴槽 | 「ここに浸かりたい」という女性の共感が強い |
| カット2 | 部屋・外観・別アングル | 滞在全体の雰囲気を伝える |
| カット3 | 食事・体験・ユニーク要素 | ロールスロイスなど「非日常」が刺さる |

**ターゲット別の置き換え例：**

| ターゲット | カット1の優先素材 | 全体の雰囲気 |
|---|---|---|
| リッチ女子旅（本サンプル） | 露天風呂・インフィニティプール | 上品・癒し・非日常 |
| カップル・記念日 | 夕景・ベッドルーム・花火 | ロマンティック・2人の距離感 |
| アドベンチャー旅 | アクティビティ・絶景・峠 | 迫力・達成感 |
| 家族・子連れ | 子どもの反応・広い部屋・料理 | 安心感・楽しさ・実用性 |
| グルメ旅 | 料理のアップ・調理シーン | 食欲・こだわり感 |

**共通して効果的な要素（ターゲット問わず）：**
- 人物を入れる → 疑似体験・感情移入を促す
- 夕暮れ〜夜の光 → 高級感・ムードが出やすい
- 動きのあるカット（波・炎・人の動き）→ 視聴を引き止める

## 制作依頼フォーマット

動画制作の指示はこの形式で出す。シナリオ設計に必要な情報が揃う。

```
テーマ：〇〇（例：関西の隠れた宿10選）
場所：〇〇（例：高野山・吉野山）
ターゲット：〇〇（例：初老の夫婦 / 若者向け / 観光ガイド風）
手元の素材：〇〇（例：スマホ写真5枚、動画2クリップ）
尺：〇〇秒
```

この情報から自動的に決まるもの：
- カット数・各カット秒数
- テキストのトーン（詩的 / 情報的 / エンタメ的）
- BGMの方向性
- 不足素材のリスト → AI生成で補完

## シナリオ優先・AI補完フロー

**動画制作の本質：シナリオが先、素材は後から埋める**

```
① 依頼フォーマットで「何が必要か」を定義
         ↓
② シナリオ設計
   ・全カットリスト（シーン × 秒数 × テキスト）を決定
   ・「撮れる素材」と「必要な素材」を照合
         ↓
③ 実撮影・手持ち素材の整理
   ・手元の写真・動画を配置
         ↓
④ 不足素材のリスト化 → AI生成で補完
   ・写真しかない → Higgsfield で動画化
   ・シーン自体がない → Higgsfield でシーン生成
   ・天候・時間帯が違う → AI変換（霧・夕暮れ・桜など）
         ↓
⑤ Remotion（travel-reels）で組み立て
   ・prepare.js でクリップ登録
   ・npm run dev でプレビュー確認
   ・npx remotion render で書き出し
```

### ターゲット別の設計判断

| ターゲット | テキストトーン | カット速度 | 明るさ・色調 | BGM |
|---|---|---|---|---|
| 若者向け | キャッチーな短文・英語混じり | 2〜3秒（速め） | 高彩度・鮮やか | J-POP・テンポ速め |
| 初老の夫婦 | 詩的・縦書き・余白あり | 4〜5秒（ゆっくり） | 自然な明るさ・sepia薄め | 箏・静かなインスト |
| 観光ガイド風 | 情報的・場所名＋説明 | 3〜4秒 | 明るく・彩度標準 | 明るいインスト |
| グルメ旅 | 食欲をそそる言葉・感嘆 | 2〜3秒 | 暖色・食べ物は高彩度 | 軽快なBGM |

### AI補完の具体的な使い分け

| 不足素材の種類 | 補完方法 | ツール |
|---|---|---|
| 写真はあるが動画がない | 写真 → 動画変換 | Higgsfield |
| 天候が違う（晴れ→霧・雪） | スタイル変換 | Higgsfield |
| シーン自体が足りない | テキストからシーン生成 | Higgsfield |
| 音楽がない | フリー素材 or AI生成 | common/bgm/ |
| 人物カットがない | フリー素材で代替 | Unsplash（後ろ姿） |

## 参考：このリールの成功要因

> このリールはターゲット（リッチ女子旅）に最適化された結果であり、
> 汎用ルールではなく「このターゲットで機能した要因」として読む。

### 構造・編集面（ターゲット問わず応用できる）

| 要因 | 内容 |
|---|---|
| タイトルフック | 「死ぬまでに泊まりたい」という強い言葉で即座に関心を引く |
| カットの速さ | 2〜3秒で切り替わるため飽きない（視聴維持率向上） |
| 一貫したテキストフォーマット | 全宿で同じ2行テキスト → ブランド感と信頼感 |
| 10選という数字 | コンテンツ量の明示 → 最後まで見る動機づけ |
| 人物の存在 | 疑似体験・感情移入を生む（どのターゲットでも有効） |

### コンテンツ面（ターゲット依存）

| 要因 | 内容 | 別ターゲットでの代替 |
|---|---|---|
| 露天風呂ファースト | リッチ女子の「泊まりたい」欲求に直結 | グルメ旅なら料理アップが先 |
| 高級宿のみ掲載 | 「ちょっとリッチ」の価値観に合致 | コスパ旅なら格安宿の驚きが刺さる |
| ロールスロイス・蟹などの非日常 | 非日常体験への憧れを刺激 | 家族旅なら子どもの笑顔が代わり |
