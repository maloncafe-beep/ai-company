# 高野山・吉野山 小旅行リール 企画書

---

## コンセプト

**「また来よう、と言える旅」**

豪華さや映えではなく、**静けさ・祈り・2人の時間**が主役。
喧騒を離れて聖地を歩いた夫婦の、言葉にならない充実感を伝える。

---

## ターゲット

| 項目 | 内容 |
|---|---|
| 主ターゲット | 50〜60代の夫婦（子育て一段落・時間に余裕が出てきた） |
| 旅のモード | 「映え」ではなく「心が洗われる」旅 |
| 共感ポイント | 「こういう旅がしたかった」「2人でまたここへ行きたい」 |
| SNSでの行動 | 保存・シェア（「夫に見せよう」「老後の旅リスト」） |

---

## サンプルリールとの違い（設計思想の転換）

| 要素 | リッチ女子旅サンプル | この企画 |
|---|---|---|
| テーマ | 非日常・贅沢 | 日常の延長にある静けさ |
| カット速度 | 2〜3秒（速い） | **3〜4秒（ゆっくり）** |
| テキスト内容 | 宿名・場所名 | **詩的な一文・心情を代弁する言葉** |
| テキストスタイル | 横書き・2行 | **縦書き・1行（俳句的）** |
| 人物 | 浴衣・入浴・華やか | **後ろ姿・手をつなぐ・小さく見える** |
| 色調 | 鮮やか・高彩度 | **低彩度・霧・木漏れ日・朱色** |
| BGM | J-POP系インスト | **尺八・箏・静かなピアノ** |
| 締め方 | 次の宿へ続く | **余韻を残して終わる** |

## 色調・トーン調整（Remotion / 写真選定）

```
フィルター方向：
- 彩度：少し下げる（-15〜-20%）
- コントラスト：わずかに上げる
- 色温度：やや寒色寄り（霧・朝の光の雰囲気）
- 朱色・緑・苔色はそのまま残す（和の色として映える）
```

## 高野山・吉野山 撮影シナリオ（AI補完前提）

実際に旅行したときの撮影リストと、撮れなかった場合のAI補完案。

| カット | 撮影目標 | 撮れない場合のAI補完 |
|---|---|---|
| オープニング | 朝霧の杉並木（奥之院参道） | 晴れた参道写真 → Higgsfield で霧を追加 |
| 高野山①  | 燈籠が並ぶ奥之院（夕方〜夜） | 昼間写真 → 夕暮れ・燈籠点灯にスタイル変換 |
| 高野山②  | 宿坊の縁側・朝の庭 | フリー素材（Unsplash: koyasan shukubo）で代替 |
| 高野山③  | 夫婦の後ろ姿（参道を歩く） | フリー素材（couple back view temple）で代替 |
| 吉野山①  | 千本桜の山並み全景 | 吉野山写真 → Higgsfield で桜を追加 or フリー素材 |
| 吉野山②  | 金峯山寺・蔵王堂（桜と一緒に） | 蔵王堂の写真 + 桜フィルター |
| エンディング | 夕暮れの山稜・静かな光 | 夕方の山写真 → 色調調整で夕焼けを強調 |

**撮影優先度：** 朝霧の参道 ＞ 燈籠の夜景 ＞ 夫婦の後ろ姿
→ この3枚さえ撮れれば、残りはAIと素材で完成できる
