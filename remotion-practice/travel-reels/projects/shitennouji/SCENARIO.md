# 大阪・四天王寺 お彼岸参り リールシナリオ

---

## 制作依頼フォーマット

```
テーマ：大阪・四天王寺 お彼岸参り（賑わい × 祈り × 豆知識）
場所：大阪市天王寺区 和宗総本山 四天王寺
ターゲット：地元の大阪人・大阪観光客・歴史好き・旅行リスト層
手元の素材：スマホ写真10枚（1.jpg〜10.jpg）
尺：約30秒（10枚 × 3秒）
```

| 要素 | autum2026（初老の夫婦） | shitennouji（お彼岸参り） |

| トーン | 詩的・静か・余韻 | 語りかけ・豆知識・驚き |
| テキスト密度 | 10枚中5枚 | 10枚中9枚 |
| 情報量 | 少なめ（感情優先） | やや多め（知識＋感情） |
| ターゲット | 50〜60代夫婦 | 幅広（20〜50代） |

## 次のアクション（パイプライン）

3. 各クリップの .txt 作成（location / comment）
4. node prepare.js shitennouji
5. npx remotion render TravelVideo --output out/shitennouji.mp4
