# LINEスタンプ自動生成ツール 使い方ガイド

**セミナー参加者特典**でお渡ししているツールです。  
このガイドのとおりに進めれば、LINE Creators Market に提出できるスタンプ用の画像を自動で作り、ZIPまで出力できます。

## 1. 必要なもの

- **パソコン**（Mac または Windows）
- **インターネット**（初回セットアップ時のみ。生成自体はオフラインでも可）
- **テキストを編集するアプリ**  
  - Mac: メモ帳・TextEdit・VS Code など  
  - Windows: メモ帳・メモ帳アプリ・VS Code など

## 2. 初回だけ：Python の準備

このツールは **Python** というプログラミング言語で動いています。  
初回だけ、お使いのパソコンに Python を入れます。

### Mac の方

1. **ターミナル**を開く  
   -  Spotlight（⌘ + スペース）で「ターミナル」と入力して起動  
   - または アプリケーション → ユーティリティ → ターミナル  

2. 次のコマンドを **1行ずつ** 入力して Enter を押します。

   ```bash
   # Python が入っているか確認（入っていればバージョンが表示されます）
   python3 --version
   ```

   - 「command not found」と出た場合 → [python.org](https://www.python.org/downloads/) から「Download Python 3.x」をダウンロードしてインストールし、もう一度 `python3 --version` を試してください。  
   - バージョン（例: Python 3.11.0）が表示されれば OK です。

### Windows の方

1. **コマンドプロンプト** または **PowerShell** を開く  
   - スタートメニューで「cmd」または「PowerShell」と検索して起動  

2. 次のコマンドを入力して Enter を押します。

   ```bash
   python --version
   ```

   - 「python は認識されていません」と出た場合 → [python.org](https://www.python.org/downloads/) から「Download Python 3.x」をダウンロードし、インストール時に **「Add Python to PATH」にチェック** を入れてからインストール。その後、もう一度 `python --version` を試してください。  
   - バージョンが表示されれば OK です。

## 3. ツールの準備（フォルダを開く）

1. お渡しした **「LINEスタンプ自動生成」** フォルダを、わかりやすい場所に置いておきます（例：デスクトップ、書類フォルダ）。

2. **ターミナル（Mac）または コマンドプロンプト / PowerShell（Windows）** を開きます。

3. このフォルダの中に移動するために、次のどちらかを実行します。

   **Mac：**
   ```bash
   cd デスクトップ/LINEスタンプ自動生成
   ```
   （フォルダを別の場所に置いた場合は、そのパスに書き換えてください。例：`cd 書類/LINEスタンプ自動生成`）

   **Windows：**
   ```bash
   cd デスクトップ\LINEスタンプ自動生成
   ```
   （フォルダの場所に合わせてパスを変えてください。ドライブが C なら `C:\Users\あなたの名前\デスクトップ\LINEスタンプ自動生成` のような形になります。）

4. **初回だけ**、ツールの部品をインストールします。

   **Mac：**
   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

   **Windows：**
   ```bash
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```

   何か表示されても、最後に「Successfully installed」などと出ていれば成功です。

## 4. 設定を編集する

スタンプの「タイトル」「作者名」「何枚作るか」「各スタンプの文言」を、設定ファイルで指定します。

### 4-1. 設定ファイルを作る

1. **「LINEスタンプ自動生成」** フォルダを開きます。  
2. 中に **`config.example.yaml`** というファイルがあります。  
3. これを **コピー** し、名前を **`config.yaml`** に変更して保存します。  
   - Mac: コピーして「config.yaml」という名前で保存  
   - Windows: コピーして貼り付け → 名前の変更で「config.yaml」  

これで「本番用の設定ファイル」ができました。次に中身を編集します。

### 4-2. config.yaml を開いて編集する

**config.yaml** をテキストエディタ（メモ帳など）で開きます。

| 項目 | 意味 | 例 |
|------|------|-----|
| **stamp.title** | スタンプのタイトル（40文字以内） | 「わたしのスタンプ」 |
| **stamp.description** | スタンプの説明（160文字以内） | 「日常で使えるスタンプです」 |
| **stamp.creator_name** | 作者名（50文字以内） | ご自身の名前やペンネーム |
| **stamp.copyright** | 著作権表記（50文字以内） | 「© 2025 あなたの名前」 |
| **sticker_count** | スタンプの枚数 | **8 / 16 / 24 / 32 / 40** のどれか1つ |
| **expressions** | 各スタンプの文言 | 下の「ありがとう」「おつかれさま」… のリスト |

- **sticker_count** を **16** にしたら、**expressions** の数も **16個** にします（多ければ先頭から16個使われます）。  
- **expressions** は自由に書き換えてOKです。  
  - 例：「ありがとう」「おつかれさま」「了解」「いいね」「泣いている」「笑っている」… など、使いたい言葉を並べます。

編集が終わったら **上書き保存** してください。

### 4-3. 設定例（コピペ用）

```yaml
stamp:
  title: "わたしのスタンプ"
  description: "日常で使えるスタンプです"
  creator_name: "山田太郎"
  copyright: "© 2025 山田太郎"

sticker_count: 16

character:
  name: "くまさん"
  description: "丸くて可愛い茶色いクマのキャラクター"

expressions:
  - "ありがとう"
  - "おつかれさま"
  - "了解"
  - "いいね"
  - "泣いている"
  - "笑っている"
  - "怒っている"
  - "びっくり"
  - "おはよう"
  - "おやすみ"
  - "がんばれ"
  - "かわいい"
  - "やったー"
  - "ごめんね"
  - "おめでとう"
  - "バイバイ"

generator: placeholder
```

※ 最初は **generator: placeholder** のままで大丈夫です（テスト用の画像でスタンプが作られます）。

## 5. スタンプを生成する

設定を保存したら、スタンプを生成します。

1. **ターミナル（Mac）または コマンドプロンプト / PowerShell（Windows）** で、  
   **「LINEスタンプ自動生成」フォルダに移動した状態** にします（[3. ツールの準備](#3-ツールの準備フォルダを開く) の `cd` をもう一度実行すればOK）。

2. 次のいずれかの方法で実行します。

   **方法A：コマンドで実行**

   **Mac：**
   ```bash
   .venv/bin/python run.py --zip
   ```

   **Windows：**
   ```bash
   .venv\Scripts\python run.py --zip
   ```

   **方法B：ダブルクリックで実行（初回セットアップ済みの場合）**

   - **Mac** … フォルダ内の **run_with_zip.command** をダブルクリック  
   - **Windows** … フォルダ内の **run_with_zip.bat** をダブルクリック  

   ※ 初回は「ツールの準備」でターミナルからセットアップを済ませてから使ってください。

3. しばらくすると、  
   - 「生成: sticker_01.png (ありがとう)」  
   - 「メイン画像: output/main.png」  
   - 「サムネイル: output/thumbnail.png」  
   - 「ZIP: output/line_stamp_submit.zip」  
   のような表示が出て、**「完了しました。」** と表示されれば成功です。

4. **「LINEスタンプ自動生成」フォルダの中の `output` フォルダ** を開くと、  
   - **stickers** … 各スタンプ画像  
   - **main.png** … メイン画像  
   - **thumbnail.png** … サムネイル  
   - **line_stamp_submit.zip** … LINEに提出する用のZIP  
   が入っています。

## 6. 出力を確認・LINEに提出する

- **line_stamp_submit.zip** が、LINE Creators Market にそのままアップロードできる形式です。  
- 提出手順は LINE の公式案内に従ってください。  
  - [LINE Creators Market](https://creator.line.me/) にログイン  
  - スタンプの新規作成 → 「画像をZIPでアップロード」などで **line_stamp_submit.zip** を指定  

※ いまのモード（**placeholder**）で作った画像は **テスト用**です。  
本番で販売するスタンプは、ご自身で描いたイラストや写真に差し替えるか、別途イラストを作成してから同じ手順でZIPを作り直してください。

## 7. よくある質問・トラブル

### Q. 「config.yaml がありません」と出る

- **config.example.yaml** をコピーして、名前を **config.yaml** に変更したファイルが、  
  **「LINEスタンプ自動生成」フォルダの直下** にあるか確認してください。  
- 拡張子が `.yaml` になっているかも確認してください（`.txt` になっていると読み込めません）。

### Q. 「sticker_count は (8, 16, 24, 32, 40) のいずれかに」と出る

- **config.yaml** の **sticker_count** を、**8 / 16 / 24 / 32 / 40** のどれか1つに書き換えてください。  
- 半角数字で、余計なスペースや引用符がないか確認してください。

### Q. 「expressions の数が ○ 未満です」と出る

- **expressions** のリストの数が、**sticker_count** で指定した数より少ないと出ます。  
- **expressions** に、スタンプの文言を **sticker_count と同じ数以上** 並べてください。  
  - 例：sticker_count が 16 なら、expressions は 16 個以上。

### Q. python や pip が認識されない（Mac）

- 「python3」で試してください（`python` ではなく `python3`）。  
- まだ出る場合は、[python.org](https://www.python.org/downloads/) から Python をインストールし直し、ターミナルを開き直してから再度試してください。

### Q. python が認識されない（Windows）

- インストール時に **「Add Python to PATH」** にチェックを入れて入れ直し、**パソコンを再起動** してから再度試してください。  
- それでもダメな場合は、  
  `C:\Users\あなたの名前\AppData\Local\Programs\Python\Python3xx\python.exe`  
  のような **フルパス** で `python` の代わりに指定する方法もあります（バージョン番号の xx はお使いの Python のバージョンに合わせます）。

### Q. 2回目以降、同じフォルダでまたスタンプを作りたい

1. **config.yaml** を編集（タイトルや expressions を変えるなど）。  
2. ターミナルで「LINEスタンプ自動生成」フォルダに移動。  
3. もう一度  
   - Mac: `.venv/bin/python run.py --zip`  
   - Windows: `.venv\Scripts\python run.py --zip`  
   を実行すれば、**output** フォルダの中身が上書きされ、新しい **line_stamp_submit.zip** ができます。

### Q. 画像を本物のイラストにしたい

- いまのツールは「テスト用のプレースホルダー画像」を自動生成するモードです。  
- 本物のイラストを使う場合は、  
  - ご自身で **output/stickers** の中の画像（同じファイル名・同じ枚数）を、  
    LINEの仕様（サイズなど）に合うイラストに差し替えるか、  
  - 別のソフトでスタンプ用画像を用意して、**main.png**・**thumbnail.png**・**stickers** を手動でそろえたうえで、ZIPだけ作り直す、  
  といった使い方ができます。  
- 将来的に、AIでイラストを生成するモードを追加する予定です。
