# 勝海舟の言葉 Shorts用BGM 設計書

## 目的

勝海舟の言葉を扱うYouTube Shortsのナレーション下に敷く、30秒の落ち着いたBGMを作る。

狙いは「歴史」「知性」「静かな前向きさ」を出しつつ、ナレーションの言葉を邪魔しないこと。

## BandLab SongStarter設定

| 項目 | 推奨 |
| --- | --- |
| Genre | Ambient / Lo-fi / Cinematic |
| Mood | Calm / Reflective / Hopeful |
| Tempo | 82 BPM |
| Key | D minor または A minor |
| Length | 30秒想定 |

## 入力の優先順位

1. Ambient
2. Lo-fi
3. Cinematic

SongStarterで和風ジャンルが選べない場合は、無理に和風を探さず、落ち着いたAmbientかLo-fiを選ぶ。

## 楽器構成

| 役割 | 音 |
| --- | --- |
| 主旋律 | 柔らかいピアノ、または琴に近いPluck系 |
| 和の気配 | 尺八風の短いフレーズ、または薄いPad |
| 低音 | 丸いサブベース、音数少なめ |
| リズム | 軽いLo-fiビート、ブラシ系ドラム、または控えめな太鼓風キック |
| 空気感 | 低めのストリングスPad、浅いリバーブ |

避ける音は、派手な三味線、強い和太鼓、目立つシンセリード、細かすぎるハイハット。

## 曲の展開

| 秒数 | 展開 | 目的 |
| --- | --- | --- |
| 0-4秒 | 薄いPadかピアノ単音で開始 | ナレーション冒頭を邪魔しない |
| 5-14秒 | ピアノまたはPluckの短い反復を追加 | 知的で落ち着いた印象を作る |
| 15-24秒 | ベースと軽いビートを入れる | 前向きさを少し出す |
| 25-30秒 | 音数を減らし、余韻で終える | 勝海舟の言葉を残す |

## ミックス方針

- BGM全体はナレーションよりかなり小さくする。
- 主旋律は鳴らし続けず、短い間を作る。
- 低音は強くしすぎない。
- 2kHzから5kHzあたりの目立つ音は控えめにする。
- 最後は急に切らず、1秒以上フェードアウトする。

## 判断基準

よいBGMの条件:

- ナレーションなしで聴くと少し物足りない。
- ナレーションを乗せるとちょうどよくなる。
- 歴史ものだが、古臭くなりすぎない。
- 30代から50代が聞いても軽すぎない。

作り直し候補:

- メロディが強すぎる。
- ビートが目立つ。
- 和楽器感が強すぎて観光BGMっぽい。
- 明るすぎて勝海舟の言葉の重みが薄れる。
