YouTubeの動画の台本を作成しようとしています。 上記文章は再生回数がとても多く人気なYouTube動画の台本です この台本の伸びている要素は、台本の構成と、動画のコンセプト、新規性のある内容が伸びている要因だと思います。 この動画が伸びている理由を考察し、今後雑学系の動画を作成する時に使えるプロンプトを作って欲しいです。 プロンプトを使えば参考元の台本の様に、魅力的で再生回数が伸びる動画台本を作れる様にプロンプトを作ってください。

# 【セルフチェック】
最後に以下を自己評価する。

・冒頭3秒で興味を引けるか
・最後まで見たくなる構成か
・新規性は十分か
・数字は適切に使われているか
・すぐ実践できる内容が含まれているか
・情報の種類が偏っていないか

必要であれば改善してから最終版を出力する。

# 追加条件

隣り合う雑学は同じ切り口を禁止（例：NG行動→実践法→意外な事実→数字→メリット…と交互にする）
**10個のうち3〜4個は「思い込みを覆す内容」**にする
**10個のうち2〜3個は「今日から試せる内容」**にする
最後の1個は最も驚きの強い内容を配置する
各雑学は音読で3〜5秒以内で読める長さにする
