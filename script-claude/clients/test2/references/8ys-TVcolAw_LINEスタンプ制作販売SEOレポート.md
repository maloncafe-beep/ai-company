## 全体像

動画内で紹介されているLINEスタンプ制作の流れは、次の順番で進む。

1. 売り場と需要を確認する。
2. 「誰が誰に送るスタンプか」を絞る。
3. AIで8個のスタンプ文言を作る。
4. AIでキャラクター画像を作る。
5. CanvaでLINEスタンプ用サイズに整える。
6. スタンプ画像、メイン画像、トークルームタブ画像を準備する。
7. LINE Creators Marketに登録する。
8. タイトル、説明文、カテゴリーなど表示情報を入力する。
9. スタンプ画像をアップロードする。
10. タグを1枚ずつ設定する。
11. SEOを意識して説明文をブラッシュアップする。
12. リクエスト申請する。
13. リジェクトされたら原因を見て修正し、再申請する。
14. 承認後、販売開始し、分配額が貯まったら送金申請する。

## 1. 最初に売り場を確認する

制作に入る前に、LINE STOREで実際の売り場を確認することが推奨されている。

動画内では、例として次のキーワードで検索している。

```text
安否確認
```

ここで確認するポイントは、次の通り。

1. どんなテーマのスタンプが並んでいるか。
2. どんな説明文が使われているか。
3. 個人クリエイターの商品があるか。
4. 古いスタンプでも今も売り場に残っているか。
5. AI生成スタンプが人気順に入っているか。

動画では、「バーバの安否確認」のように、離れて暮らす家族や友人へ毎日送る用途のスタンプが例として挙げられている。また、AI情報ありのスタンプが人気順に並んでいる例も紹介されており、AIで作ったことを隠さなくても販売自体は可能だという文脈で説明されている。

## 2. テーマは「誰が誰に送るか」で絞る

この動画で最も重要な考え方は、汎用的なスタンプを作らず、「誰が誰に送るのか」を先に決めること。

### 悪い方向性

```text
誰でも使える、便利な日常スタンプ
```

このような広いテーマは競合が多く、個人が見つけてもらいにくい。

### 推奨される方向性

```text
40代、50代の子供が、離れて暮らす70代の親に毎日送る安否確認スタンプ
```

動画内では、売上差の要因として「セット数や期間ではなく、誰に送らせるかで変わる」と説明されている。つまり、使う人の仮想人物と送る相手を明確にして、用途を絞るほど刺さりやすいという考え方。

### テーマ例

1. 離れて暮らす親へ送る安否確認。
2. 夜勤明けのパートナーへ送る気遣い。
3. 単身赴任の夫へ送る連絡。
4. 一人暮らしの母へ送る健康確認。
5. 遠距離恋人へ送る短い気遣い。

## 3. スタンプ文言をAIで作る

まずは、LINEスタンプ用の短い言葉を8個出す。

動画では、8個で実演している。LINE Creators Marketでは8枚、16枚、24枚、32枚、40枚と枚数を選べるため、慣れたら40枚に増やしてもよいという説明。

### 文言作成プロンプト

文字起こし内で紹介されている内容を、使いやすい形に整えると次の通り。

```text
離れて暮らす70代の親に、40代・50代の子供がLINEで毎日送る言葉を、スタンプ用に8個出してください。

条件:
1. 1個12文字以内。
2. 話し言葉にする。
3. 「了解」「ありがとう」「お休み」だけの言葉は禁止。
4. 売り場に多すぎるありきたりな言葉は避ける。
5. 親の体を気遣う言葉を入れる。
6. 返事を催促しない言葉を混ぜる。
7. それぞれ、どんな朝・どんな夜に送るかを一言で説明してください。
```

### AIが出した文言例

動画内では、次のような文言が出たと説明されている。

1. ちゃんと食べた？
2. 無理してない？
3. 今日はゆっくりね
4. 水分取ってね
5. 返事はいらないよ
6. 元気ならそれでOK
7. あったかくしてね
8. また連絡するね

### ポイント

「返事はいらないよ」のように、相手に返信負担をかけない文言は、70代の親へ送る用途に合っていると説明されている。単なる挨拶ではなく、使う場面と相手の負担まで考えるのがポイント。

## 4. AIでキャラクター画像を作る

動画では、「ゆるい茶碗キャラクター」を例にして、先ほどの8個の言葉に対応するスタンプ画像を作っている。

### 画像生成の基本方針

AIで1枚ずつ画像を作ると、キャラクターの顔や雰囲気がぶれやすい。そのため、動画では「一気に8枚作る」または「1枚の画像の中に8個並べる」方法が紹介されている。

### そのまま8枚作る指示例

```text
ゆるい茶碗のキャラクターで、さっきの8個の言葉が入ったLINEスタンプを8枚作ってください。
```

ただし、うまくいかない場合があるため、次の「1枚に8個並べる」方式が紹介されている。

### キャラぶれ防止プロンプト

動画内の指示を整理すると次の通り。

```text
LINEスタンプ用のイラストを1枚の画像に8個並べて作ってください。

横4個 × 縦2個の構図。
それぞれの枠に同じキャラクターを1体ずつ配置してください。

キャラクター:
ゆるい茶碗キャラクター。
顔と短い手足がある。
丸くてゆるい線のキャラ。
白地に青い縞模様。

8個の動き:
1. 手を振る
2. 茶碗と箸を持つ
3. 横になってくつろぐ
4. 両手のひらを前に出す
5. マフラーを巻く
6. コップを差し出す
7. 親指を立てる
8. 布団に入る

背景は真っ白。
文字は一切入れない。
枠線も入れない。
太めの線。
色は少なめ。
小さくしても見えるようにしてください。
```

### 重要ポイント

1. 文字は画像に直接入れない方が安全。
2. 同じキャラクターをまとめて描かせると、顔ぶれが安定しやすい。
3. 小さく表示されても分かるよう、線は太め、色数は少なめにする。
4. 背景は後で透過しやすいよう白にする。
5. 画像に文字を入れた場合、文字崩れや誤字が審査落ちの原因になりやすい。

## 5. Canvaでスタンプ画像を整える

AIで作った画像を、LINEスタンプ用のサイズに整える。

### スタンプ画像サイズ

動画内では、制作ガイドラインのサイズとして次が紹介されている。

```text
スタンプ画像: 370 × 320 px
```

Canvaでカスタムサイズを作り、370 × 320 pxで新規デザインを作成する。

### Canvaでの作業手順

1. Canvaでカスタムサイズ `370 × 320 px` のデザインを作る。
2. AIで生成した画像をアップロードする。
3. 1枚目のスタンプとして、該当するキャラクターを配置する。
4. 背景削除、または背景透過を行う。
5. ページを複製し、8ページ分作る。
6. 各ページに、8個のスタンプ画像を順番に配置する。
7. PNG形式でダウンロードする。
8. ダウンロード時に背景透過を必ず有効にする。

### 背景透過の注意点

動画内で実演者が一度ミスしていた重要ポイント。

Canvaで背景削除をしても、ダウンロード時に背景透過にチェックを入れないと、背景が白く埋まってしまう。その状態だと、LINE Creators Market上で背景がグレー表示にならず、透過できていないことが分かる。

背景透過できていない画像は審査で弾かれる可能性があるため、必ず透過PNGで書き出す。

## 6. メイン画像とトークルームタブ画像を作る

スタンプ画像だけではなく、メイン画像とトークルームタブ画像も必要。

### メイン画像

動画内で紹介されているサイズ。

```text
メイン画像: 240 × 240 px
```

メイン画像は、販売ページなどで見える看板画像。スタンプ内のキャラクターと大きく違うものにすると審査落ちの原因になる。

### トークルームタブ画像

動画内で紹介されているサイズ。

```text
トークルームタブ画像: 96 × 74 px
```

トーク画面のキーボード付近に小さく表示される看板画像。非常に小さく表示されるため、細かい絵より、分かりやすい表情やシルエットの画像を選ぶ。

### 作成時の注意

1. スタンプ画像と同じキャラクターを使う。
2. 別キャラや別テイストの画像にしない。
3. 背景透過を忘れない。
4. 小さくても判別できる画像にする。

## 7. LINE Creators Marketへ登録する

画像の準備が終わったら、LINE Creators Marketで出品作業を行う。

### パソコンで作業する

理由は、リジェクトされた時に、アプリからはスタンプの編集や再申請ができないため。審査に落ちる前提で、最初からパソコンで作業する。

### 基本手順

```text
LINE Creators Marketにログイン
> 新規登録
> スタンプを選択
> 表示情報を入力
> 画像を登録
> タグを設定
> 価格を設定

```

## 11. タグ設定は絶対にサボらない

動画内で最も強調されていたのが、タグ設定。

ここでいうタグは、一般的なブログやECのタグというより、LINEのトーク入力時に候補として出るサジェストに関わるものとして説明されている。

ユーザーがLINEで特定の言葉を打った時に、自分のスタンプが候補として出るかどうかに関係するため、露出と売上に直結する重要作業とされている。

### タグの基本

1. 画像1枚ごとにタグを設定する。
2. 1枚につき最大9個まで設定できる。
3. 入れられるだけ入れる。
4. 8枚すべてに設定する。
5. 40枚で作る場合は40枚すべてに設定する。

### タグ候補をAIに出させる方法

タグ編集画面を開き、`Ctrl + P` でPDF保存する。タグ候補一覧が多いため、そのPDFをAIに渡して選ばせる。

### タグ選定プロンプト

```text
では作成したスタンプ8個それぞれに、9個ずつおすすめのタグをこのPDFファイルから選出して、一覧にまとめて指定してください。
```

### タグを探す方法

AIが出したタグ候補を画面内で探す時は、次を使う。

```text
Ctrl + F
```

検索欄に「元気」「心配」「食事」などを打ち、該当タグを探して設定する。

### タグ例

動画内で出てきたタグ例。

```text
食事
食べる
ご飯
もぐもぐ
パクパク
美味しい
元気
心配
どうしたの
```

### 重要ポイント

タグは「売上に直結する」と説明されている。画像作成より地味だが、ファン0の個人が見つけてもらう入口になるため、最重要作業として扱う。

## 13. 説明文SEO対策

タグ設定と並んで重要なのが、スタンプ説明文。

動画では、ファン0人の個人が見つけてもらうためには、説明文に検索される言葉を入れる必要があると説明されている。

### なぜ説明文が重要か

1. 個人は企業や有名IPに比べて認知がない。
2. 宣伝できるリストやフォロワーがない。
3. ユーザーがLINE STOREで検索した時に拾われる必要がある。
4. その検索語を置く場所が説明文。

### 文字数の注意

説明文は160文字以内とされているが、全角は2文字としてカウントされるため、実質80文字程度で考える必要があると説明されている。

### 説明文ブラッシュアッププロンプト

```text
スタンプ説明文のブラッシュアップを行います。
LINEスタンプのマーケットで検索をかけた時に、少しでも露出がしやすいようにSEOを意識したスタンプ説明文に変えたいです。
160文字以内とは書かれていますが、全角は2文字としてカウントされるので実質80文字です。
その前提で、スタンプ説明文に入れるJapanese欄とEnglish欄をそれぞれ1個ずつ出し直してください。
```

### 入れるべきキーワード例

動画内では、今回の商品検索意図に合わせて次のような語を盛り込むと説明されている。

1. 親。
2. 家族。
3. 食事。
4. 体調。
5. 水分補給。
6. 毎日使える。
7. シニア。
8. 安否確認。
9. 気遣い。

### 説明文作成の考え方

単におしゃれに書くのではなく、「誰が何を検索するか」から逆算する。

たとえば、離れて暮らす親へ送るスタンプなら、検索されそうな言葉は「親」「家族」「安否確認」「体調」「食事」「水分補給」などになる。

## 15. リジェクト対応

LINEスタンプは審査で落ちることがある。動画では、リジェクトされた通知を見て諦めず、30分で直して再申請することが重要だと説明されている。

### リジェクト時の流れ

1. LINE Creators Marketでリジェクト通知を確認する。
2. メッセージ内容を見る。
3. 公式ガイドラインのどの項目に当たりそうか確認する。
4. 該当箇所を直す。
5. 再リクエストする。

### AI制作で特に引っかかりやすい5項目

動画内では、ガイドライン44項目の中から、AIで作ると当たりやすいものとして次が挙げられている。

### 1. 単純なテキストのみの画像

文字だけで、イラストや装飾がない画像は落ちやすい。

対策:

1. キャラクターを必ず入れる。
2. 文字だけのスタンプにしない。
3. 小さくても見えるイラストを添える。

### 2. スタンプ内の文字に誤りがある

AI画像に文字を入れさせると、日本語が崩れたり、漢字が破綻したりすることがある。

対策:

1. AI画像には文字を入れない。
2. 文字を入れる場合は必ず目視チェックする。
3. 特に漢字は念入りに確認する。

### 3. スタンプ画像と著しく異なるメイン画像・タブ画像

メイン画像だけ別キャラクターにしたり、別テイストにしたりすると落ちやすい。

対策:

1. メイン画像はスタンプ内の代表画像を使う。
2. タブ画像も同じキャラクターにする。
3. 売れそうだからと別キャラを描かせない。

### 4. 絵文字・機種依存文字が入っている

説明文やタイトルに、ハートなどの絵文字、機種依存文字を入れると落ちる可能性がある。

対策:

1. タイトル・説明文に絵文字を入れない。
2. 装飾記号を使いすぎない。
3. シンプルなテキストにする。

### 5. 権利の所在が明確でないもの・二次創作

版権キャラ、有名作品風、既存キャラ名、二次創作などは避ける。

動画では、画像内に有名キャラを入れていなくても、タイトルや説明文に「ジブリ風」「〇〇風」のような表現を書くと危険だと説明されている。

対策:

1. 有名作品名、キャラ名を使わない。
2. 「〇〇風」と書かない。
3. 版権キャラに似せない。
4. AIプロンプトでも有名作品名を使わない。

## 16. 承認後の反映と販売開始

承認されても、検索にすぐ出てこない場合がある。動画内では、反映に数時間かかることを知らず、落ちたのかと思って再リクエストしそうになった事例が紹介されている。

### 注意点

1. 承認直後に検索して出なくても慌てない。
2. 反映まで数時間かかる場合がある。
3. 自動販売にしていれば、承認後に販売開始される。
4. 手動販売にした場合は、自分で販売開始操作をする。

## 17. 売上金と送金申請

動画内では、売上には販売数と送信数の表示があり、分配額が1000円を超えると送金申請ボタンが押せるようになると説明されている。

### 送金申請の条件

```text
分配額が1000円を超えると送金申請可能
```

### 振込先

```text
銀行または信用金庫
```

### 手数料

```text
495円
```

### 注意点

1000円を少し超えた段階で引き出すと、手数料でかなり減る。そのため、こまめに引き出すより、ある程度貯めてから送金申請した方がよいと説明されている。

## 18. 制作・販売の実践チェックリスト

### 制作前

1. LINE STOREで売り場を検索した。
2. 人気順や個人スタンプを確認した。
3. 「誰が誰に送るか」を決めた。
4. 汎用テーマではなく狭い用途に絞った。

### 文言作成

1. 8個または40個の文言を作った。
2. 1文12文字以内にした。
3. 返事を催促しない文言を入れた。
4. 体調、食事、水分補給など用途に合う言葉を入れた。

### 画像作成

1. 同じキャラクターでまとめて生成した。
2. 文字を画像に直接入れすぎていない。
3. 小さくても見える太線・少色にした。
4. 背景は白または透過しやすい状態にした。

### Canva整形

1. スタンプ画像を370 × 320 pxで作った。
2. メイン画像を240 × 240 pxで作った。
3. タブ画像を96 × 74 pxで作った。
4. 背景透過PNGで書き出した。
5. 透過漏れがないか確認した。

### Creators Market登録

1. パソコンで作業している。
2. 日本語と英語のタイトル・説明文を入れた。
3. AI使用を申告した。
4. カテゴリーを内容に合わせて選んだ。
5. 販売エリア、企画参加、販売開始設定を確認した。

### タグ・SEO

1. タグ編集画面をPDF保存した。
2. AIに各画像9個ずつタグを選ばせた。
3. 全画像にタグを設定した。
4. 説明文に検索語を入れた。
5. 全角80文字程度を意識した。
6. 説明文に絵文字を入れていない。

### 審査前

1. メイン画像・タブ画像がスタンプ本体と一致している。
2. 文字の誤りがない。
3. 版権・有名キャラ・〇〇風表現がない。
4. 単純な文字だけ画像になっていない。
5. リクエスト前に全項目を見直した。

## 19. 最短実践フロー

初めて作る場合は、次の順番で進めると迷いにくい。

```text
1. LINE STOREで「安否確認」などを検索
2. 送る相手を決める
3. AIで8個の文言を作る
4. AIで同一キャラの8枚画像を作る
5. Canvaで370×320の透過PNGにする
6. メイン画像240×240を作る
7. タブ画像96×74を作る
8. LINE Creators Marketにパソコンでログイン
9. 新規登録 > スタンプ
10. 表示情報を入力
11. 画像をアップロード
12. タグを全画像に設定
13. 説明文SEOを整える
14. リクエスト申請
15. リジェクトされたら通知を見て修正
16. 承認後に販売開始
17. 分配額が貯まったら送金申請
```

## まとめ

この動画のLINEスタンプノウハウの核は、絵の上手さではなく、設計と出品作業にある。

特に重要なのは、汎用スタンプを作らず、「誰が誰に送るのか」を絞ること。次に、AIで文言と画像を作り、CanvaでLINE規格に整え、LINE Creators Marketでタグと説明文SEOを丁寧に設定すること。

審査落ちは前提として考え、リジェクト通知を見て修正すればよい。諦めずに直して再申請することまで含めて、LINEスタンプ販売の作業工程として捉えるのが重要。
