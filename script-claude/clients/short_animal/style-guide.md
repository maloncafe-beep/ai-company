# style-guide（参考動画: vKKaD56PNkk「知らないと損する睡眠の雑学」17:40）

## 動画フォーマット
- **ジャンル**: 雑学ファクト列挙型（100個前後のトリビアを高速で紹介）
- **動画尺**: 約17〜18分
- **推定文字数**: 5,500〜7,000字（ナレーション速度：速め）
- **ナレーションスタイル**: ナレーター1名、視聴者への語りかけなし、純粋な情報読み上げ

## 文体・語調
- **文末**: 常体（〜になる、〜がある、〜している、〜できる）
  - 「です・ます」は使わない
  - 体言止めあり（「〜のサイン」「〜の証拠」など）
- **文の長さ**: 1ファクトあたり1〜2文。30〜60字程度でコンパクトに完結
- **数字の使い方**: 積極的に使う（「15分程度」「20%以上」「90分サイクル」「1.5L以上」）
- **逆張り表現**: 「実は〜」「〜は逆効果」「〜というのは実は嘘」で意外性を出す
- **サイン表現**: 「〜のサイン」で夢や行動の意味を解説するパターンが多い

## 構成パターン（冒頭フック型）
```
【冒頭フック】（0:00〜0:30）
  → 「え、それ知らなかった！」という意外ネタを2〜3個先出し
  → 視聴者を引き込む「実は〜」「知らないと損する〜」系の言葉

【本論：ファクト列挙】（0:30〜16:30）
  → トピック別にまとめず、バラバラに並べるランダム列挙型
  → 「寝姿勢」「夢」「入眠法」「睡眠環境」「食べ物・飲み物」「体の仕組み」を横断
  → 各ファクトの長さは均一。単調にならないよう「逆張り」「数字」「体験想起」を交互に

【再フック】（5〜6分前後）
  → 「まだまだあります」「次は〜に関する雑学」など継続視聴を促す一言

【エンディング】（16:30〜17:40）
  → 「いかがでしたか」系のまとめ
  → チャンネル登録・高評価の呼びかけ
```

## よく使われるトピックカテゴリ
1. 寝姿勢（仰向け・横向き・うつ伏せ）の特徴と影響
2. 夢の意味・仕組み（夢のサイン系）
3. 入眠テクニック（478呼吸法・カウントダウンなど）
4. 睡眠環境（室温・湿度・照明・音）
5. 食べ物・飲み物と睡眠の関係
6. 睡眠時間・睡眠負債・病気リスク
7. 動物・偉人の睡眠エピソード
8. 「実は嘘」「実は逆効果」系の意外ネタ

## 禁則
- 「です・ます」調は使わない
- 視聴者に直接話しかけるセリフ口調（「皆さんは〜ですか？」）は不使用
- 長い説明文でひとつのファクトを掘り下げない（簡潔に完結させる）
