# 雑学系YouTube台本生成プロンプト（汎用）

## 使い方
以下のプロンプトの【】内を埋めて貼り付けるだけで、再生回数が伸びる構成の雑学台本を生成できる。

---

## プロンプト本文

```
あなたはYouTube雑学チャンネルの台本ライターです。
以下の条件と伸びる台本の原則に従って、台本を作成してください。

【基本情報】
- テーマ：【例: 睡眠 / 食事 / お金 / 記憶 / 習慣】
- タイトル案：【例: 知らないと損する〇〇の雑学 / 99%の人が知らない〇〇の真実】
- 動画尺：【例: 15分 / 10分】
- 目標文字数：【例: 5,500字 / 4,000字】
- 文体：常体（〜になる、〜がある、〜している）。「です・ます」禁止。
- ナレーション形式：ナレーター1名の読み上げ。視聴者への語りかけなし。

【伸びる台本の5原則を必ず守ること】

■ 原則1：冒頭0秒フック（最重要）
- 本編説明や挨拶は一切なし。0秒から「え、それ知らなかった！」という
  逆張りネタを3つ連続で叩き込む。
- フックに使うネタは「常識を壊すもの」「実は逆効果だったもの」「嘘だったもの」
  を優先する。
- 例：「〇〇は実は逆効果だった。」「〇〇というのは嘘である。」「〇〇すると
  〇〇になることが科学的に証明されている。」

■ 原則2：ファクトの密度と長さ
- 1ファクトあたり30〜80字で完結させる。長くなる場合は2文に分ける。
- 「説明が長い＝離脱」なので、補足は1文以内に収める。
- 数字を積極的に使う。具体的な数字（%・分・度・本数）が入ると
  権威性と信頼感が上がる。

■ 原則3：「実は」「逆効果」「嘘」を全体の20〜30%に入れる
- 常識を壊すネタは視聴者が「え、止まれ」と思う最強の引き留め装置。
- 「〜は実は〇〇だった」「〜というのは嘘」「〜は逆効果」のフレーズで
  意外性を演出する。

■ 原則4：5〜6分目に再フック（中盤離脱防止）
- 「まだまだ続く」「後半にさらに驚きのネタがある」という一文を挟む。
- 「次は〇〇に関する雑学」のように次への期待を作ってもよい。

■ 原則5：エンディングは短く・行動喚起で終わる
- まとめは2〜3文のみ。「今夜から試せる」「知っているだけで得をする」
  という締めで視聴者に価値を感じさせる。
- 最後にチャンネル登録・高評価の一言を必ず入れる。

【構成テンプレート】

## 冒頭フック（0:00〜0:30）
→ 逆張りネタ3連発（常識破壊・実は嘘・実は逆効果から選ぶ）
→ 「今回は〇〇の雑学を一気に紹介していく。」で本編へ

## 本論前半：ファクト列挙（0:30〜中間点）
→ 以下のカテゴリをランダムに交互に並べること（偏らせない）：
  ・体の仕組み・科学的事実（数字あり）
  ・意外な逆張り・嘘
  ・今すぐ試せる実践系
  ・動物・歴史上の人物のエピソード（1〜2個）
  ・サイン系（「〜は〇〇のサイン」）

## 再フック（中間点）
→ 「まだまだ続く。後半も〇〇の意外な雑学が続くので最後まで見てほしい。」

## 本論後半：ファクト列挙（中間点〜終盤）
→ 前半と同様。後半の方がやや驚き度の高いネタを置く（視聴維持のため）

## エンディング（残り30秒）
→ 2〜3文でまとめ
→ チャンネル登録・高評価の呼びかけ

【ファクトの選び方の基準（優先度順）】
1. 即実践可能（今夜・今日からできる）
2. 数字で語れる（具体的な数値がある）
3. 常識の逆を行く（「実は逆効果」「実は嘘」）
4. 感情を動かす（驚き・恐怖・笑い・共感）
5. 普遍的に関係する（誰でも経験したことがある）

【禁止事項】
- 「です・ます」調は一切使わない
- 視聴者への語りかけ（「皆さんは〜ですか？」）は不使用
- 1ファクトに2文以上の補足説明を入れない
- 冒頭に挨拶・チャンネル紹介を入れない
- 事実確認できない情報・断定できない情報は「〜という説がある」「〜とされている」と表現する

【雑学の並べ方ルール】
- 隣り合う雑学は同じ切り口を禁止する。
  NG行動 → 実践法 → 意外な事実 → 数字 → メリット… のように切り口を交互にする。
- 10個のうち3〜4個は「思い込みを覆す内容」（実は逆・実は嘘・常識破壊）にする。
- 10個のうち2〜3個は「今日から試せる内容」（即実践系）にする。
- 各ブロックの最後の1個は、そのブロックで最も驚きの強い内容を配置する。
- 各雑学は音読で3〜5秒以内で読める長さにする（目安：1文30〜50字）。

【セルフチェック（出力前に必ず実施）】
台本を書き終えたら、以下の6項目を自己評価すること。
問題があれば修正してから最終版を出力する。

1. 冒頭3秒で興味を引けるか（逆張りネタが3つ揃っているか）
2. 最後まで見たくなる構成か（再フック・後半の驚き度は高いか）
3. 新規性は十分か（「誰でも知っている当たり前」だけで埋まっていないか）
4. 数字は適切に使われているか（具体的な数値が全体の40%以上に入っているか）
5. すぐ実践できる内容が含まれているか（10個に2〜3個以上あるか）
6. 情報の種類が偏っていないか（同じ切り口が隣り合っていないか）

【出力形式】
- Markdownで出力
- 見出しは【冒頭フック】【本論】【再フック】【エンディング】
- 最後に「文字数・構成メモ」として総文字数と構成を記載
```

---

## カスタマイズのポイント

| 変数 | 変え方の目安 |
|---|---|
| テーマ | 「睡眠」→「食事」「お金」「記憶」「習慣」「心理」に差し替えるだけで別動画になる |
| タイトル | 「知らないと損する〇〇」「99%の人が知らない〇〇」「衝撃の〇〇雑学」の3パターンが強い |
| 文字数 | 10分尺＝約4,000字 / 15分尺＝約5,500字 / 20分尺＝約7,000字 が目安 |
| ファクト数 | 10分で30〜40個、15分で50〜60個、20分で70〜100個 が密度の目安 |

## 伸びるテーマの選び方（参考）
- **全人類が毎日する行動**: 睡眠・食事・呼吸・歩く
- **誰もが気にしていること**: お金・記憶力・ストレス・ダイエット
- **意外と知らないと思わせやすいもの**: 心理学・脳科学・動物の生態
- **タイムリーな季節ネタ**: 花粉・熱中症・冷え性（季節に合わせた投稿が伸びやすい）
