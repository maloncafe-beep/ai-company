# Suno Piano BGM Design Memo

作成日: 2026-10-01

目的: YouTubeショート/VLOG系動画の映像を邪魔せず、短時間でも耳に残る静かなピアノBGMを量産し、将来的な収益化・権利管理につなげるための設計メモ。

## 基本方針

狙う音楽は「寺院専用BGM」や「睡眠用アンビエント」ではなく、「音数は少ないが、旋律は明確で、VLOG全般に使えるピアノBGM」。

重要な軸:

- 静けさ
- 余白
- 覚えられる短い旋律
- 映像を邪魔しない音量感と展開
- 1分〜2:50程度の動画に自然に乗る構成
- 最後をフェードアウトしても不自然にならない流れ

避ける方向:

- 何も記憶に残らない環境音寄り
- 劇伴として大きく盛り上がる曲
- ドラムや強いリズムで映像を引っ張りすぎる曲
- 高速アルペジオや技巧的なピアノ
- タイトルやプロンプトが特定ジャンルに寄りすぎ、カバーアートや曲調が狭くなること

## 用途の優先順位

主目的は、自作BGMをYouTubeショート/VLOG系動画で使い、将来的な収益・権利管理につなげること。

寺院・仏像・静かな風景は用途例の一つであり、メインテーマとして固定しすぎない。

優先用途:

- VLOG
- 日常風景
- 旅行
- 散歩
- カフェ
- 街歩き
- 自然
- 寺院・神社・仏像
- 静かな室内
- 余韻のあるショート動画

ここから見ると、BGMは「寺院専用」ではなく、次のような幅を持たせる。

- 静かな旅VLOGに合う
- 地域紹介に合う
- 神社仏閣にも合うが、そこに限定されない
- 花・自然・街歩きにも違和感がない
- 主張しすぎず、映像の雰囲気を底上げする
- 印象に残る短い旋律はあるが、映像より前に出ない

タイトルでは `Temple` のような用途限定語を避け、抽象的で汎用性のある名前にする。

## Suno設定メモ

2026-10-01時点で公式ヘルプ上は、v6系がCurrent Modelsとして案内されています。v6 / v6-wildはPro・Premier向け、v6-miniは全プラン向けです。

SunoのCustom ModeではInstrumentalをオンにし、Style欄に曲調を記述します。不要要素はAdvanced OptionsのExcludeに入れます。

本番のYouTube利用・収益化を想定する場合は、無料プラン生成曲の扱いに注意。公式ヘルプでは、Basic/free planの曲は非商用用途、Pro/Premier加入中に作成・ダウンロードした曲は商用利用権が付く趣旨で説明されています。過去の無料プラン曲に後から自動で商用権が付くわけではありません。

## 固定する6項目

| 項目 | 指定 |
|---|---|
| 主楽器 | soft piano / solo piano |
| テンポ | slow, around 60-75 BPM |
| 雰囲気 | peaceful / nostalgic / warm / dreamy / relaxing |
| メロディ | simple but memorable melody |
| 展開 | minimal arrangement / gentle development |
| 除外 | no drums / no vocals / no dramatic climax / no orchestral swell |

## 長さ指定と動画編集方針

動画BGMとして使う場合は、Suno上では3分前後の素材として作り、動画編集側で必要尺に合わせて末尾をフェードアウトする。

理由:

- ショート動画でも実尺は1分〜2:50程度になることがある
- 途中で曲が切れて冒頭に戻るループは不自然に聞こえやすい
- 3分程度の素材なら、動画尺に合わせて自然に切り出せる
- 最後をフェードアウトすれば、映像の終わりに合わせやすい

| 用途 | 推奨長さ | メモ |
|---|---:|---|
| 本番BGM素材 | 約3分 | 1分〜2:50程度の動画に対応しやすい |
| テスト生成 | 60〜90秒 | 雰囲気確認だけなら短尺でも可 |
| 特定の短尺用途 | 60〜90秒 | 冒頭から終わりまで曲構成を固定したい時だけ |

基本方針:

- 本番用途は3分前後で生成する
- 動画尺に合わせて編集側でカットする
- 末尾はフェードアウトで処理する
- ループ前提にはしない

今回の初回本番候補は、短尺版とフル尺版を別IDで管理する。

- 短尺版: `SUNO-001`
- フル尺版: `SUNO-002`
- 今後の本番採用候補は、基本的に `SUNO-002` のような3分前後の素材を優先する

## 生成の進め方

1. 基本プロンプトを固定する
2. 1項目だけ変えたバリエーションを作る
3. まず10曲生成する
4. 20〜40秒で使える箇所があるか聴く
5. 評価表に○△×を付ける
6. ○の曲だけ共通点を抜き出す
7. Yasuさん専用BGMプロンプトとして固定する

## 評価軸

| 評価軸 | 見るポイント |
|---|---|
| メロディが立っている | 3〜5秒で主旋律の印象が出るか |
| 静かさ | 映像より前に出すぎないか |
| 映像を邪魔しない | ナレーションや字幕の邪魔にならないか |
| 切り出し適性 | 20〜40秒で自然に使えるか |
| 寺院・仏像適性 | 和風に寄せすぎず、静謐さがあるか |
