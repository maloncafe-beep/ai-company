# コピペ用サンプル文テンプレート集

このファイルは、新しいチャットでそのまま貼って使える依頼文のサンプル集です。
`SKILL.md` と `images/` を前提に、短く指示できる形にしています。

---

## 1. 基本形

```text
.\lp-packs\starter-mobile-first を見てください。
SKILL.md と images フォルダ内の参考画像をもとに、スマホ最適化LPを作成してください。
index.html と style.css を更新してください。
```

## 使い分けの目安

- まず試すなら `1. 基本形`
- そのまま実案件に近い形で投げるなら `2. 野菜カフェ向け`
