# LP Starter Skill

## このファイルの使い方

この `SKILL.md` は、LPを量産するときに毎回長い指示を書かなくていいようにするための設定ファイルです。

使い方はシンプルです。

1. 下の `簡単な質問` に答える
2. `images/reference/` に参考画像を入れる
3. 必要なら `images/generated/` に生成AIで作った本番候補画像を入れる
4. 使用許可のある本番素材は `images/assets/` に入れる
5. Codex / ChatGPT にこのフォルダを読ませてLP作成を依頼する

このファイルに書かれている共通ルールは、毎回の案件で基本的に共通で使います。

## このパックの役割

- スマホ最適化されたLPを短時間で作る
- 参考画像の雰囲気を見た目に反映する
- `HTML + CSS + 画像 + SKILL.md` だけで軽く運用する
- 参考画像と本番利用画像を分けて安全に管理する

## 制作の前提

- 1ページ完結のLPを作る
- まずスマホ表示を優先して整える
- PCはあとから横幅に応じて整える
- 参考画像は `images/reference/` を使う
- 本番利用する画像は `images/generated/` または `images/assets/` から選ぶ

## 画像フォルダの使い分け

### `images/reference/`

- Pinterestなどから集めた参考画像を置く
- 色味、余白感、写真のトーン、世界観の参考に使う
- 本番LPにそのまま掲載しない前提で扱う

### `images/generated/`

- 生成AIで作った本番候補画像を置く
- ヒーロー画像、背景画像、装飾ビジュアルなどに使う
- 本番で使う第一候補にしやすい

### `images/assets/`

- 使用許可が明確なロゴ、商品写真、店舗写真などを置く
- 実際にLPへ掲載してよい素材だけを入れる

### `images/` 直下にある既存ファイル

- 既存の仮画像や過去素材として残してよい
- 今後の新規案件では、できるだけ `reference / generated / assets` に分けて置く

## 参考画像ルール

- `images/reference/` の画像を優先して世界観の参考にする
- Pinterestから入れたJPGは、色味、余白感、写真の見せ方、文字量の参考に使う
- 画像に書かれている文字やレイアウトをそのまま使わず、雰囲気だけを参照する
- 本番LPに使う画像は `images/generated/` または `images/assets/` を優先する
- 本番素材が未確定の場合は、抽象ビジュアルや仮画像で置き換えてよい

## デザイン共通ルール

### デバイス優先順位

1. スマホ最優先
2. タブレット対応
3. PC対応

### 基本サイズ方針

- ベース幅: 390px前後を最優先
- コンテンツ最大幅: 1120px
- 左右余白:
  - スマホ: 20px
  - タブレット: 28px
  - PC: 32px

### デザインテーマ初期値

- テーマ名: Dark Cosmic
- 印象: 未来感、没入感、ワクワク感、テック感
- 世界観: 宇宙、星、発光、ガラス、深いネイビーとパープル

※案件によって、ナチュラル、カフェ、和風、ヘルシーなどへ変更してよいです。

### レイアウトルール

- ファーストビューで価値提案とCTAを見せる
- 重要セクションの末尾にCTAを置く
- スマホでは縦積みを基本にする
- PCで必要に応じて2カラム化する
- カードは見やすい余白を確保する

### コピーのトーン

- 前向き
- わかりやすい
- ベネフィットが先に伝わる
- 断定しすぎない
- 日本語改行は文節単位で自然に切る

## 推奨セクション

案件に応じて増減してよいです。

1. ヒーロー
2. 悩み
3. 選ばれる理由
4. 提供内容またはメニュー
5. 価格または利用案内
6. FAQ
7. 最終CTA

## 野菜カフェ向けの読み替え例

- ヒーロー: 新鮮さ、安心感、来店したくなる写真
- 悩み: 外食で野菜不足になりがち、安心できる店が少ない
- 選ばれる理由: 無農薬、地元野菜、彩り、居心地
- 提供内容: ランチ、ドリンク、テイクアウト、季節限定メニュー
- CTA: 予約、メニュー確認、Instagram確認

## 禁止事項

- 助詞の手前で不自然に改行しない
- 数字と単位を分けない
- 架空の実績や比較を勝手に追加しない
- 未入力の事実情報を断定しない
- 参考画像の見た目を丸写しせず、方向性の参考として使う
- `images/reference/` の素材をそのまま本番掲載画像として扱わない

## Codex / ChatGPT への依頼文の短縮例

以下のような短い依頼で使えます。

`このフォルダの SKILL.md と images を見て、野菜カフェ向けLPを作成して。`

`SKILL.md の回答欄をもとに、スマホ優先で index.html と style.css を更新して。`

`images/reference の参考JPGの雰囲気を使って、やさしく自然派のLPにして。トップ画像は generated または assets の画像を使って。`
