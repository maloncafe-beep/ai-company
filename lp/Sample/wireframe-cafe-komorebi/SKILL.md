# Wireframe LP Skill

## このテンプレートの役割

このフォルダは、LPの完成デザインを作る前に、セクション構成と情報配置を先に固めるためのワイヤーフレーム用セットです。

見本の構成は以下を想定しています。

- 上部ナビゲーション
- ヒーロー
- カード一覧
- 記事一覧
- 特集または強み紹介
- CTA
- フッター

## 使い方

1. `index.html` と `style.css` をベースにする
2. 業種に合わせて見出しと文言を差し替える
3. 画像枠はプレースホルダーのままでもよい
4. 構成が固まったら、完成版LP用に色や画像を追加する

## 画像の役割

本番に近づける段階では、画像を用途ごとに分けて考える。

- `hero`: 最初に見せる主役画像。LP全体の印象を決める
- `section`: 各セクションの説明画像。内容理解を助ける
- `card`: メニュー・商品・サービスカード用画像。比較しやすく見せる
- `background`: 背景・質感用画像。雰囲気づくりに使う
- `icon`: 小さな補助ビジュアル。特徴や導線を軽く補足する

AI生成画像を使う場合は、まず全体の構成に仮配置し、違和感がある画像から順に生成・修正・差し替えを行う。

案件受注前に「見た目」で判断してもらう必要がある場合は、最小限のラフ画像だけでは弱く見えることがある。
その場合は、以下の追加画像まで用意すると、完成イメージがかなり伝わりやすくなる。

- `card`: ホットラテ
- `card`: アイスラテ
- `card`: カプチーノ
- `card`: 焼き菓子セット
- `section`: クリーム系ドリンク
- `section`: テイクアウトカップ
- `section`: クロワッサンまたは焼き菓子

この段階では、全画像を完璧に仕上げるより、LP全体がプロっぽく見えるだけの密度を先に作る。
受注後に、採用画像だけを本番用に修正・高解像度化・差し替えする。

## 注意

- これは完成デザインではなく骨組みテンプレートです
- 参考画像の構図は参考にしても、そのまま模写しすぎないようにします
- ワイヤーフレーム段階では、まず情報設計を優先します

## 依頼文の短縮例

`このフォルダの wireframe を使って、野菜カフェ向けLPの骨組みを作って。`

`index.html と style.css をベースに、スマホでも見やすいワイヤーフレームLPへ調整して。`

必要に応じて、確認用に以下も作成する。

- preview.png: ブラウザ表示をキャプチャした確認用画像
- wireframe.svg: 静的な1枚絵として共有したい場合のみ作成

LP実装に進める場合は HTML/CSS を正本とし、PNG/SVG は確認・共有用として扱う。
