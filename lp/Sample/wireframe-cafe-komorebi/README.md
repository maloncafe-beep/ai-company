# Wireframe Template Set

このフォルダは、LPの骨組みを素早く作るためのワイヤーフレーム用テンプレートです。

## 入っているもの

- `index.html`
  ワイヤーフレームの基本レイアウト
- `style.css`
  デスクトップとスマホの見た目を整えるスタイル
- `SKILL.md`
  このテンプレートの使い方と、ChatGPT / Codex への依頼方法

## 想定用途

- まずは構成だけ決めたいとき
- 見出し、画像位置、CTA位置を先に固めたいとき
- 参考デザインを見ながら、自分の業種向けLPに置き換えたいとき

## 使い方

1. `index.html` を開いてワイヤーフレーム全体を見る
2. `SKILL.md` を見ながら業種、ターゲット、CTAを決める
3. 各見出しやテキストを案件用に差し替える
4. 必要なら画像プレースホルダーを本番画像に置き換える
5. 骨組みが固まったら、色や世界観をのせて完成版へ進める

## images の役割
- reference/
  Pinterestなどの参考画像
- assets/
  実際にLPで使ってよい画像
- generated/
  生成AIで作ったヒーロー画像や背景
