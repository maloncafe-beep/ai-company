LP-GPT for Codex
インストール・使い方


このフォルダは、商品情報や参考画像から
スマホ向けLPを制作するCodexプラグインです。


────────────────────
必要なもの
────────────────────
・Codexを利用できる環境
・LPを作るための作業フォルダ
・画像を生成する場合は、Codexで画像生成機能が利用できること


────────────────────
インストール方法（確実な方法）
────────────────────
1. 受け取った「lp-gpt-public.zip」をダブルクリックして展開します。

https://lstep.app/pPtPH5q 

2. Macの「ターミナル」アプリを開きます。

3. ターミナルへ次の文字を入力します。
codex plugin marketplace add 

4. Enterはまだ押さず、展開した「lp-gpt-public」フォルダをFinderからターミナルへドラッグします。

5. フォルダのパスが入力されたらEnterを押します。

6. 続けて、次のコマンドをコピーして実行します。
codex plugin add lp-gpt@lp-gpt-public

7. Codexアプリを終了して、もう一度起動します。

8. Codexで新しいタスクを開始します。


────────────────────
使い方
────────────────────
新しいタスクで、次のように依頼します。
$lp-gpt を使って、この商品のスマホLPを作ってください。
商品資料と参考画像を添付します。
申込みURLがまだ決まっていない場合は、次のように書けます。
$lp-gpt を使って、このオンライン講座のスマホLPを作ってください。
申込みURLはまだないので、仮モーダルにしてください。
参考画像がある場合は、画像をタスクへ添付してから依頼してください。


────────────────────
ターミナルを使わない場合
────────────────────
1. 展開した「lp-gpt-public」フォルダをCodexで開きます。
2. Codexの「Plugins」を開きます。
3. 「LP-GPT Public」から「LP-GPT」を選びます。
4. Installを押します。
5. Codexを再起動し、新しいタスクで使用します。
プラグインが表示されない場合は、上に記載したターミナル方式を使用してください。
