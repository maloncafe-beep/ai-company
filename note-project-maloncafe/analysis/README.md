# note公開後分析

このフォルダは、公開後のnote記事を分析するための置き場。

`research/` は書く前の調査、`analysis/` は書いた後の検証に使う。

## 役割

- 記事ごとの数字と改善仮説を残す
- アカウント全体の月次PDCAを残す
- 次に書くテーマ、横展開、有料化候補の根拠にする

## フォルダ

| フォルダ | 役割 |
|----------|------|
| `articles/` | 公開済み記事ごとの個別分析 |
| `account/` | 月次・週次のアカウント全体分析 |

## 運用

公開後は、記事本文を直接直す前にここへ数字と仮説を残す。

基本の順番:

1. 公開24時間後の初動を見る
2. 公開7日後にスキ率・PV・フォロー導線を見る
3. 月1回、アカウント全体の傾向を見る
4. 次に書くテーマと改善候補を決める
