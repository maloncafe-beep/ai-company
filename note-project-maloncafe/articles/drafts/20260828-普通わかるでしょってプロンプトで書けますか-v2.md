# 「普通わかるでしょ？」って、プロンプトで書けますか？

こんにちは！ご機嫌はいかがですか。

「普通にやっておいて」「普通わかるでしょ？」「普通はそうしないよね」

こういう言葉って、日常ではわりと自然に出てきます。職場でも、家庭でも、学校でも、たぶん一度くらいは言われたことがある。言ったことがある人もいるかもしれません。

でも、これをそのままAIへのプロンプトとして書いたらどうなるでしょうか。「普通にいい感じでお願いします」「普通ならわかる感じで出してください」「あとは普通に整えてください」。たぶん、思ったものは出てこない。なんなら、こっちが想像していたものと全然違うものが返ってきて、「いや、そういうことじゃないんだよ」と言いたくなる。

でもね、そこで一度立ち止まりたいんです。

**AIが悪いのでしょうか。**

それとも、こちらが「普通」という言葉の中に、あまりにも多くの条件を詰め込みすぎていたのでしょうか。今日は、「普通」という言葉について考えてみます。これは単なる同調圧力の話ではありません。AI時代になって、いままで人間同士でなんとなく処理されてきた雑なコミュニケーションが、急に可視化され始めているのではないか、という話です。

# 「普通にやって」が通じるように見える理由

AIに「普通にやって」と言っても通じません。もちろん、AIはそれっぽく何かを返してくれます。でも、それがこちらの期待と合っているとは限らない。

なぜか？

**AIには、こちらの人生の文脈が共有されていないからです。**

どんな人に向けた文章なのか。どのくらい丁寧にするのか。どんな言葉を避けるのか。何を成功とするのか。どこまで踏み込んで、どこから先は抑えるのか。そういう条件を書かないまま「普通に」と言っても、AIは困るわけです。

でも、人間同士ではどうでしょう。「普通にやって」と言われると、わたしたちはなんとなく動いてしまう。よく分からないまま、相手の顔色を見て、過去の会話を思い出して、その場の空気を読んで、「たぶんこういうことだろう」と穴埋めする。

つまり、人間同士では「普通」が通じているのではありません。

**言われた側が、見えない条件を必死に補完しているだけです。**

「普通わかるでしょ？」と言われたとき、こちらはただ内容を理解しようとしているわけではない。相手の期待値、機嫌、過去の成功パターン、その場の力関係、聞き返したときに怒られそうかどうかまで、一瞬で計算している。これ、かなり高度な処理です。

でも、やっている側は自分が高度な処理をしているとは思わない。むしろ「そんなことも分からない自分が悪いのかな」と感じてしまう。ここに、「普通」という言葉の厄介さがあります。

# 「普通」は、説明ではない

「普通にして」と言われる。でも、その普通が何を指しているのかは説明されない。「普通わかるよね」と言われる。でも、どの基準で判断すればいいのかは示されない。「普通はそうしない」と言われる。でも、なぜそうしない方がいいのかは語られない。

これ、よく考えると不思議です。本当に論理的に正しいなら、説明できるはずなんですよね。理由があるなら、理由を言えばいい。条件があるなら、条件を共有すればいい。目的があるなら、目的を渡せばいい。

それなのに「普通」という言葉が出てくるとき、多くの場合、その説明が省略されます。なぜ省略されるのか。たぶん、言っている側にも明確に言語化できていないからです。

「昔からこうしてきた」「自分はそう教わった」「この職場ではそれが当たり前だった」「親からそう言われて育った」「なんとなく、その方がちゃんとして見える」。こういうものが、ひとつの袋に雑に詰め込まれて、「普通」というラベルで渡される。そして受け取った側は、その袋の中身を自力で開けなければならない。

**「普通」とは、説明ではなく、説明の省略です。**

ここを間違えると、受け手は自分を責めます。「普通が分からない自分はおかしいのかな」「みんなできているのに、自分だけできていないのかな」「聞き返すと迷惑かな」。でも、本当にそうでしょうか。

もしかすると、問題はあなたの理解力ではない。相手が渡してきた指示の方に、必要な条件が入っていなかっただけかもしれない。

# 「普通」の正体

では、「普通」とは何なのでしょうか。ここで少し分解してみます。

「普通」という言葉の中には、たいていこういうものが入っています。過去にうまくいったやり方。その職場だけで通じるローカルルール。家庭や世代の中で当たり前とされてきた空気。言語化されていない評価基準。立場が上だから通ってしまう要求。

もちろん、すべての「普通」が悪いわけではありません。信号を守る。約束の時間を守る。人を傷つけない。こういう社会生活のための共通前提はあります。これまで積み上げられてきた慣習にも、意味があるものはたくさんある。

でも、人を苦しくさせる「普通」は少し違います。それは、みんなで共有しているルールではなく、誰かの中だけにある前提が、説明されないまま相手に渡されるときに起きます。

たとえば、上司が部下に「普通これくらい察するでしょ」と言う。でも、その「普通」は、その上司が過去に怒られながら覚えた会社の空気かもしれない。親が子どもに「普通はこうする」と言う。でも、その「普通」は、その親が生きてきた時代の安全策かもしれない。

つまり、「普通」は客観的な正解の顔をしているけれど、中身はかなりローカルです。

**「普通」とは、誰かの成功体験が、説明されないまま他人に渡されたものだ。**

わたしは、これがかなり近いと思っています。もっと言えば、

**「普通」とは、共有された常識ではなく、説明されなかったプロンプトである。**

ここで、AIの話に戻ります。

# AIには「普通」が通じない

AIに何かを頼むとき、こちらの「普通」は通じません。「普通に読みやすくして」「普通に売れそうな感じで」「普通の社会人っぽく」。こういう指示でも、ある程度の出力は返ってきます。でも、こちらが本当にほしいものに近づけるには、もっと条件が必要になる。

誰に向けるのか。何を目的にするのか。どの言葉は使わないのか。どのくらい踏み込むのか。何を読み終わったあとに感じてほしいのか。AIは、こちらが言葉にした条件をもとに動きます。

だから、AIを使っていると気づくことがあります。

**自分は、自分の中の前提を思ったより言語化できていない。**

これ、けっこう痛い発見です。「いい感じにして」と言っている自分の中には、たしかに「いい感じ」のイメージがある。でも、それを相手が再現できる形で渡せているかというと、かなり怪しい。AIはそこを容赦なく見せてきます。

人間同士なら、相手が察してくれた。気を遣ってくれた。曖昧な部分を埋めてくれた。多少ズレても、関係性で丸めてくれた。でもAIは、そういう人間的な配慮で穴埋めしてくれません。

ここで、ようやく見えてくるんです。人間関係で起きていた「普通わかるでしょ？」問題と、AIに対する「なんで思った通りに出してくれないの？」問題は、かなり似ている。

どちらも、前提条件が足りていない。どちらも、指示する側が自分の期待を言語化できていない。どちらも、相手がうまく動かないときに、相手の能力不足に見えてしまう。

でも、本当はそうではないかもしれない。

**足りないのは、相手の能力ではなく、こちらが渡した条件かもしれない。**

# 「普通」で人を動かせた時代

これまでの社会では、「普通」で人を動かせる場面がたくさんありました。会社には会社の空気があり、学校には学校の空気があり、家庭には家庭の空気がある。そこに長くいる人ほど、その空気を知っている。

だから、年上や先輩や上司は「普通」と言える。一方で、年下や新人や立場の弱い人は、それを聞き返しにくい。「普通って何ですか？」と聞くと、反抗しているように見える。理解力がないように見える。面倒な人だと思われる。

だから黙って察する。

ここで生まれているのは、かなり不均衡な関係です。言う側は、説明するコストを払わない。言われた側は、察するコストを払う。しかも、外したら怒られる。

でも、それが「普通」という言葉で包まれると、なぜか受け手の問題にされる。「普通が分からない」「空気が読めない」「常識がない」。こう言われると、人は黙ります。なぜなら、「普通」や「常識」は、反論しにくい言葉だからです。

でも、AI時代になると、この構造が少し変わります。AIには、権力勾配が通じません。AIに「普通わかるでしょ」と言っても、こちらの意図を勝手に完全再現してはくれない。怒っても、圧をかけても、昔話をしても、条件が足りなければズレる。

つまり、AIはとても冷たいようでいて、ある意味ではとても公平です。

**言語化したものしか、相手には渡らない。**

この当たり前を、かなりはっきり見せてくる。

# 「普通が分からない」は、悪いことなのか

ここまで考えると、「普通が分からない」という状態の見え方が少し変わります。もちろん、社会で生きる以上、共有されているルールを知ることは大事です。毎回すべてをゼロから説明してもらわないと動けない、という話ではありません。

でも、「普通が分からない」と感じたとき、すぐに自分を責めなくてもいい。その「普通」は、本当に共有されたルールなのか。それとも、誰かの過去の成功体験なのか。その場だけのローカルルールなのか。相手の感情を、正しさに見せているだけなのか。

ここを分けて考えるだけで、少し楽になります。「普通わかるでしょ？」と言われたとき、心の中でこう考えてもいい。

**これは、条件不足のプロンプトかもしれない。**

そう思えるだけで、自分の人格まで差し出さなくて済みます。「わたしがダメなんだ」ではなく、「いま渡されている条件が足りないのかもしれない」と見られる。この差は大きいです。

もちろん、現実の人間関係では、毎回そんなに理想的に聞き返せるわけではありません。相手が怖いこともある。立場が弱いこともある。聞き返しただけで面倒な空気になる場面もある。だから、「こう返せば全部解決します」みたいな簡単な話にはしたくありません。

ただ、少なくとも自分の内側では、切り分けられる。

**普通が分からないことと、あなたに価値がないことは、まったく別の話です。**

# ちゃんと関係を続けるために

わたしは、「普通」という言葉を全部なくせばいいとは思っていません。人間は、すべてを毎回説明していたら生きていけない。長く続く関係には、言葉にしなくても分かる瞬間もあります。

でも、それは相手に説明を押し付けていい、という意味ではない。

「普通わかるでしょ？」と言いたくなるとき、わたしたちはだいたい、自分の中の前提を説明するのが面倒になっています。その面倒を相手に押し付けると、関係は少しずつ削れていく。逆に、自分の普通を言葉にできたとき、相手はようやくこちらの世界に入ってこられる。

普通を疑うことは、ひねくれることではありません。相手に条件を突きつけることでもない。

**「普通」を疑うことは、相手とちゃんと関係を続けるための第一歩なのかもしれない。**

「普通わかるでしょ？」って、プロンプトで書けますか？

もし書けないなら、それは相手が分からず屋なのではなく、まだ言葉になっていない前提があるということです。そして、その前提を言葉にすることから、少しだけやさしいコミュニケーションが始まるのだと思います。
