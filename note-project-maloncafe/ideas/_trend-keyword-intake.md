# 流行キーワード起点のネタ出し

ネタ切れを防ぐため、記事化の前に「起点候補」を集める。

ここでは記事を作らない。まず、まろさんが「ピッと感じる」キーワードを見つける。

## 目的

- 自動化の最初でネタ切れを防ぐ
- 流行っている言葉をそのまま記事にせず、違和感や思想につながるものだけ選ぶ
- 選んだキーワードをGemini等で深掘りし、MD化してから記事にする

## 流れ

1. 流行キーワード・注目用語・SNS上の違和感語を10〜20個出す
2. それぞれに「なぜ今出ているか」を1行で添える
3. Maloncafeに合いそうな接続仮説を添える
4. まろさんが気になるものを選ぶ
5. 選ばれたものだけ、Gemini等で深掘りする
6. `research/YYYYMMDD-テーマ名.md` に落とす
7. 構成案を作る
8. 記事にする

## 候補の種類

| 種類 | 例 | source_route |
|------|----|--------------|
| Xで反応している言葉 | 普通、正論、自分は正しい | `x_research` |
| 心理・認知バイアス用語 | 追認バイアス、ツイニングバイアス | `concept_research` |
| AI時代の違和感語 | なんか違う、プロンプト、AI文章 | `concept_research` or `x_research` |
| 人間関係の違和感語 | 距離感、わかってくれない、察して | `x_research` |

## 候補リストの出力形式

| # | キーワード | 種類 | なぜ今気になるか | Maloncafe接続仮説 | source_route | 優先度 |
|---|------------|------|------------------|--------------------|--------------|--------|
| 1 | | | | | | ★ |

## 選定基準

まろさんが選ぶときの基準:

- なんとなく引っかかる
- 説明できないけれど気になる
- 自分の経験や思想とつながりそう
- 読者の痛みがありそう
- ただの流行語ではなく、奥に構造がありそう

## 注意

キーワード候補を出した段階では、記事化しない。

選ばれたキーワードだけ深掘りに進める。

自動化では、この人間の選定を飛ばさない。ここを飛ばすと、検索で拾っただけの記事になりやすい。
