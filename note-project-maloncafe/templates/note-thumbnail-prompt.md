# noteサムネ生成プロンプト

以下の方針で、note記事用サムネを作ってください。

## アカウント

`malon | 違和感収集家`

## 目的

note一覧で読める、違和感が伝わる、ブランド感のあるサムネを作る。

## 基本方針

- 線画のおじさんキャラを使う。
- 落ち着いた世界観にする。
- 文字は大きく、老眼でも一覧で読めるサイズにする。
- 主文言は2行以内。
- 補助文言は小さくしすぎない。読めないなら削る。
- 色は3色程度に絞る。
- 通常記事は、短い強い言葉型を基本にする。
- 有料記事だけ、必要なら情報詰め込み型も検討する。
- 記事内容やアカウントの雰囲気とズレないようにする。

## サムネで表現したいもの

- 感情: しんどさ、引っかかり、違和感、静かな疲れ。
- 場面: デスク、会議、PC、スマホ、職場、家庭。
- 関係: 評価される人/されない人、見える仕事/見えない仕事。
- 対立: 普通/説明、正論/苦しさ、成果/前提、AIっぽさ/自分の言葉。
- 読む理由: この記事を開くと何が整理されるのか。

## 文字設計

- 主文言は2行以内。
- 主要文言は一覧表示で読める大きさにする。
- スマホ一覧でも読める大きさにする。
- タイトル全文を無理に入れない。
- 全部を載せたい場合は、主文言・補助文言・小ラベルに分ける。
- 補助文言が読めないなら削る。

## チェック

- タイトルを読まなくても、だいたい何の話かわかるか。
- タイトルとサムネを合わせると、開く理由が強くなるか。
- 文字が小さすぎないか。
- 一覧表示で文字が読めるか。
- 色が多すぎて散らかっていないか。
- 同じキャラ/同じ世界観でアカウントの連続性があるか。

## 入力欄

```text
記事タイトル:
サムネに入れたい主文言:
補助文言:
記事の違和感:
読者の場面:
入れたい小物:
色の方向:
通常記事 / 有料記事:
```
