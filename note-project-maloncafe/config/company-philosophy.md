## コア概念

### 1. 幸福の概念（5つの軸）

幸福は「欲求の解消」だけではない。

| 軸 | 意味 |
|---|------|
| 欲求の解消 | 欲求を満たすこと |
| 意義性 | 自分の今この瞬間が「目的」にプラスに寄与すること |
| 没頭 | 自分の今この瞬間に集中すること |
| 成長実感 | 過去を振り返り「目的」に対して前進していると感じられること |
| 関係性 | 欲求の源である関係性がきちんと存在していること |

### 2. 継続する関係（Lifetime Relation）

- 継続する関係こそが最大の資産
- 一度つながった関係を命に代えても守る
- 相手にかけてもらったコストを命に代えても返す
- 長く続く関係は新たな欲求を生み、代替不可能な関係へ育ち、**愛**になる


### 3. まず与えよ

- **Give**: 価値を与えようとする人。相手をwinさせることを第一優先とする
- **Take**: 価値を得ようとする人。自分をwinさせることを第一優先とする（相手のloseを厭わない）
- Giveが構造的に報われる世界を作ることが会社の存在意義

### 4. 愛 = 代替不可能性

- 愛とは希少性が極大化した時に感じる対象の価値の爆発的な増加
- 「コレは唯一だ！」と信じられた時、そのモノがかけがえのない大切なものになる
- 代替不可能性をもたらすのはLTR（時間の共有）
- 愛の敵は代替可能性（スワイプ文化、転職カルチャー、SNS比較）

### 5. 価値提供

- ビジネスは最も純粋な価値提供の形
- 価値の非対称性を利用してWin-Winを作る
- 自分のGiveが相手に与える価値 > 相手がかけるコスト を常に成り立たせる
- 価値提供 → 継続する関係 → 幸福の概念 → さらなる価値提供 の無限ループ

### 6. Ai+Action

- 目標を持った瞬間に、実行に移すまでの正しい思考プロセスをAIと共に最高効率で実現する行動
- 「知ってる」と「できる」の間の谷を埋める
- 生成AIの思考リソースを「実行」に変換する装置

## 5つのルール

1. **今、よく生きる** — 未来のために今を犠牲にしない
2. **命に代えても継続関係を紡ぐ** — 一度つながった関係は命に代えても守る
3. **完璧にこだわる** — 永遠に到達できない「完璧」を追い求め続ける
4. **相手の視点を取得する** — 相手の目で見て、相手の心で感じる
5. **まず与えよ** — 価値提供ゲームのガチ勢で在り続ける
