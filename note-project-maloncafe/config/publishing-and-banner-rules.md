# 投稿頻度・レビュー・バナー運用

Maloncafeの記事運用は、投稿頻度に合わせてレビューと分析の重さを変える。

現状は月1本程度。今後は倍程度、つまり月2本前後を目安にする。

## 投稿頻度の目安

| 記事モード | 目安頻度 | 役割 |
|------------|----------|------|
| `light_note` | 月1本前後 | キーワードで引っかかる軽い記事、コメント・接点づくり |
| `deep_article` | 月1本前後 | 信頼形成、保存、フォローにつながる主力記事 |
| `guide_or_offer` | 必要時 | 有料記事・商品・導線があるときだけ |

まずは月2本を目標にする。

理想形:

- 軽い記事: 月1本
- しっかり記事: 月1本

無理に本数を増やすより、軽い記事で接点を増やし、深い記事で信頼を作る。

## レビュー頻度

| 記事モード | レビュー |
|------------|----------|
| `light_note` | 誤字・タイトル・CTA中心の軽い確認 |
| `guide_or_offer` | CTA、価格、リンク、案内先を確認 |
| `deep_article` | 構成、深掘りMD、タイトル、冒頭、CTAを確認 |

`deep_article` は、まろさんの判断を必ず通す。

`light_note` は、自動化で下書きまで進めてよい。

## 分析頻度

| 頻度 | 内容 |
|------|------|
| 公開24時間後 | インプレッション、PV、スキ、コメントを見る |
| 月1回 | `analysis/account/YYYYMMDD-account-pdca.md` を更新 |
| 3本たまったら | `light_note` と `deep_article` の反応差を見る |

今は投稿数が少ないため、記事ごとに細かく分析しすぎない。

月1回、まとめて見る。

## バナー運用

読み手に「この記事の重さ」が伝わるように、制作モードごとにバナーの方向を変える。

現状、公開済み記事はほぼ `deep_article` として作っている。

いつものおじさん系バナーは、現時点では `deep_article` 用のバナー表現として扱う。

`light_note` と `guide_or_offer` のバナー表現はまだ未定。今後、軽い記事や案内記事を実際に作りながらテストする。

| 記事モード | バナーの役割 | 色・見え方の方向 |
|------------|--------------|------------------|
| `light_note` | 軽く読める入口 | 未定。明るめ・軽めの方向でテスト |
| `guide_or_offer` | 案内・行動導線 | 未定。すっきり・CTAが見える方向でテスト |
| `deep_article` | 保存・信頼の入口 | いつものおじさん系バナー。落ち着いた色、考える雰囲気 |

## 注意

バナーで記事の中身を説明しすぎない。

色や雰囲気で「軽い記事」「案内記事」「しっかり記事」の違いが伝わればよい。

タイトル・バナー・本文の重さがズレないようにする。

例:

- 軽い記事なのに、重すぎるバナーにしない
- 深い記事なのに、ポップすぎるバナーにしない
- 案内記事なのに、思想記事のように見せない
