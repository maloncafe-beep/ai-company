# 記事制作モード

Maloncafeの記事は、すべて同じ重さで作らない。

自動化する場合は、最初に制作モードを判定する。

## Mode 1: light_note

さらっと流す記事。

向いているもの:

- 日々の気づき
- 短い違和感メモ
- 過去記事への軽い補足
- X投稿から広げた短めのnote
- 読者との接点を保つための記事

自動化:

- 自動化してよい
- 深掘りリサーチは必須ではない
- ただし、Maloncafeらしい違和感の一文は必ず入れる

読者反応の役割:

- コメントしやすい
- 読者との接点を増やす
- 「この人、よく見ているな」と思ってもらう
- 深い記事へ進む前の入口になる

目安:

- 800〜1800字
- 構成確認なしでも下書き作成可
- 公開前チェックは軽め

## Mode 2: guide_or_offer

案内記事・商品説明・有料記事への導線記事。

向いているもの:

- 有料記事の案内
- 商品・サービス説明
- 無料記事から有料記事へつなぐ導線
- まとめ記事
- 読者に次の行動を促す記事

自動化:

- 自動化してよい
- 目的、読者、CTAが明確なら作成可能
- 事実関係、価格、リンク、公開状態は確認する

読者反応の役割:

- 次に何を読めばいいか分かる
- 有料記事やサービスへの迷いを減らす
- 読者の関心を、具体的な行動へつなげる

目安:

- 1000〜2500字
- CTA重視
- 哲学よりも読者の次アクションを優先

## Mode 3: deep_article

しっかり調べて作る主力記事。

向いているもの:

- 用語・概念から作る記事
- 反応が大きく出そうなテーマ
- Maloncafeの思想を代表する記事
- 今後の有料化・シリーズ化の核になりそうな記事
- 「普通」「正論」「自分は正しい」のような中心テーマ

自動化:

- 完全自動化しない
- まろさんの選定・判断を必ず挟む
- 検索結果から直接書かない
- Gemini等で深掘りし、MD化してから構成する

読者反応の役割:

- 「この人やるな」と思ってもらう
- 「この人の考え方はいいな」と信頼につながる
- フォローや保存の理由になる
- Maloncafeの思想を覚えてもらう記事になる

目安:

- 2500〜5000字以上
- 構成案の確認必須
- `research/_deep-research-method.md` に沿った深掘り必須

## 判定基準

| 観点 | light_note | guide_or_offer | deep_article |
|------|------------|----------------|--------------|
| 目的 | 接点維持・軽い気づき | CTA・案内・販売導線 | 思想・保存・反応の核 |
| 読者反応 | コメント・共感 | 行動・遷移 | 信頼・フォロー・保存 |
| リサーチ | 軽め | 必要情報の確認 | 深掘り必須 |
| まろさん判断 | 任意 | CTAや価格は確認 | 必須 |
| 自動化 | 可 | 可 | 半自動 |
| 失敗リスク | 低 | 中 | 高 |

## 自動化ルール

自動化してよいもの:

- `light_note`
- `guide_or_offer`

まろさん判断を必ず挟むもの:

- `deep_article`

`deep_article` は、候補選定・深掘りMD・構成案のどこかで必ず人間の判断を入れる。

ここを飛ばすと、検索で拾っただけの浅い記事になりやすい。

## 保存時メタデータ

```yaml
production_mode: light_note / guide_or_offer / deep_article
automation_level: auto / semi_auto / manual_review_required
```
