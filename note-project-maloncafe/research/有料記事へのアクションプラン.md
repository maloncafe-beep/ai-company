# 有料記事へのアクションプラン

いきなり有料記事にするのではなく、まず **無料記事を「有料記事と同等の満足度」まで引き上げる**。そこで新規読者、フォロー、専門家反応を取りにいく。そのうえで、後から有料化できる型を見つける。これが今のMaloncafeには合っています。

**基本プラン**
1本ごとに、次の順番で作るのがよさそうです。

1. **Xリサーチから強い違和感語を選ぶ**
   例: 普通、正論、察して、言語化できない、なんか違う、わかってくれない

2. **Note向けに分解する**
   Xの短い反応語を、そのまま記事にしない。
   「職場では？」「家族では？」「AI時代では？」「人間関係では？」に分解する。

3. **入口3点を先に作る**
   本文より先に、
   - タイトル
   - バナー
   - 最初の2行
   を作る。

   ここで「見れば一発で何の話かわかる」状態にする。

4. **無料なのに持ち帰りがある記事にする**
   読者が読み終わったあとに、
   - 自分の違和感に名前がつく
   - 明日から見方が変わる
   - 誰かに説明できる
   - 保存したくなる
   くらいまで持っていく。

5. **記事末尾でフォロー理由を作る**
   「スキ・フォローお願いします」だけでなく、
   「こういう違和感をこれからも分解します」
   という形で、次も読む理由を出す。

**記事の方向性**
当面はこの3系統が強いです。

| 系統 | 狙い | 例 |
|---|---|---|
| 普通・正論・察して系 | 人文・思想/言語学カテゴリ狙い | 「普通にやって」が通じない理由 |
| AIと自分の言葉系 | コンピュータ・IT/AIカテゴリでも読者の違和感に寄せる | AIで文章が薄くなる人、深くなる人 |
| 人生後半・関係性系 | PVを取りやすい広めの入口 | 人間関係を減らしても孤独が軽くならない理由 |

**有料記事化への布石**
無料記事の中に、毎回少しだけ「有料化できる種」を残します。

たとえば、

- 診断シートにできそうな問い
- チェックリスト化できそうな分類
- プロンプト集にできそうな使い方
- ケース別の対処法
- 読者が自分で使えるワーク

でも今は売らない。まず無料記事で反応を見る。

**判断基準**
次の記事からは、公開後にこれを見ます。

- PVが伸びたか
- スキ率が高いか
- フォローが増えたか
- 専門家の反応があったか
- 掲載カテゴリが合っていたか
- 関連記事に同系統の記事が出たか

つまり、今の戦略はこうです。

**無料記事で有料級の価値を出す。  
ただし商品化は急がず、反応が取れたテーマだけを後で有料設計する。**

この順番なら、読者獲得と将来の有料化がちゃんとつながります。
