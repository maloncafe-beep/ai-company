# noteリサーチ チェックリスト

市場リサーチ → トピックリサーチ → 執筆 → PDCA の実務用。スキル発動時もこのリストを参照する。

## 書く前（テーマ探索 A + B）

- [ ] 候補キーワード3〜5個を note 内検索（記事数・有料割合・タイトルパターン）
- [ ] ラッコキーワード等でサジェスト・関連語10個取得（Google流入狙いの場合）
- [ ] 上位5記事のタイトル・価格・切り口をメモ
- [ ] `research/YYYYMMDD-テーマ名.md` に「キーワード需要」「競合サンプル」を追加  
  → スキル: **research-note-market**
- [ ] 続けてテーマの中身・哲学接続  
  → スキル: **research-topic**

## 書いた後（自アカウント C）

- [ ] 公開24時間後に初動を確認する（インプレッション・PV・スキ・フォロー増）
- [ ] 公開24時間後のインプレッションが低い場合は、タイトル・冒頭・タグのどこで止まっているか仮説を立てる
- [ ] ダッシュボードを週1回（PV順・スキ順）
- [ ] インプレッションが低い記事は、本文より先にタイトル・冒頭・タグを見直す
- [ ] PVはあるがスキが弱い記事は、冒頭の自分ごと化・読後の持ち帰りを見直す
- [ ] スキはあるがフォローにつながらない記事は、次も読みたいと思えるテーマ軸・プロフィール接続を見直す
- [ ] スキ率10%超の記事構成をテンプレ化
- [ ] 月1回: CSV or スクショ → **analyze-note-account** で「次の5テーマ」
- [ ] 有料化候補をスキ率×コメントでリスト化

## ツール優先順位（コスパ）

**無料で始める**
1. note内検索 + ダッシュボード
2. ラッコキーワード
3. CSV拡張 or スクショ→AI分析
4. 競合10記事の手動メモ

**有料化を本格化する場合**
5. noteInsight（価格・構成）
6. maa-note-analysis（CVR・売上ファネル）

## 指標の目安

| 指標 | 計算 | 目安 |
|------|------|------|
| スキ率 | スキ ÷ PV × 100 | 10%超＝構成優秀 |
| 1日PV | PV ÷ 公開日数 | 安定＝ストック型 |
| コメント率 | コメント ÷ PV | 議論テーマの判定 |

競合のスキ数は切り口参考のみ。伸び判断は**自アカウント内比較**。
