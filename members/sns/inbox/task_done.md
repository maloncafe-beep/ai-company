# タスク：スプシ備考ルール刷新（NN統一対応）

依頼日: 2026-05-09
依頼元: Leader

## 背景

NN統一ルール（新規はNN=60〜、スレッド/リメイク/画像プロンプトを同じNNで揃える）の運用に合わせ、
スプシ「備考」列の表記を簡素化します。

旧ルール下では備考に **スプシID2つ** を併記していましたが（例：`リメイク版（47-48）`）、
新ルールではファイル名のNNだけで対応関係が自明になるため、ID併記が冗長です。

## 修正内容

### 1. SNS CLAUDE.md の「スプシ登録ルール」を以下のように更新してください

**現状（90〜91行目あたり）：**
```
- リメイク版の場合、備考列に `リメイク版（元スレッドID-登録ID）` 形式で記入する
  - 例：`リメイク版（32-46）`
```

**修正後：**
```
- 備考列の表記（NN=60〜の新規コンテンツから適用）：
  - スレッド：`スレッド（NN）` ※NN=ファイル名のコンテンツ番号
  - リメイク：`リメイク（NN）` ※NN=ファイル名のコンテンツ番号（スレッドと同じ）
  - 例：x-thread-60-xxx → 備考「スレッド（60）」 / x-remix-60-xxx → 備考「リメイク（60）」
- 旧ルール（NN=01〜28のlegacy）で登録済みの備考（例：`リメイク版（47-48）`）はそのまま残す（書き換えない）
```

### 2. 既登録分（スプシID 47〜52）の備考は **触らない**（旧形式のまま残す）

経営者判断：legacyは過去ログとして保全。新規NN=60〜から新形式を適用。
