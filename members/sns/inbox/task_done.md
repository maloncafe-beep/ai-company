   ヒアリング→テンプレート選定→スライド構成案→文字数チェック済みのテキスト一式を出力

2. **テンプレート管理**  
   `templates/` フォルダ内のテンプレごとにスライド別文字数制限表を保持し、デザイン崩れを防止

3. **カラーパレット設計**

4. **リサーチ連携**  
   構成案に必要な数値・データのリサーチを行い、具体的な数字を含めたコンテンツに仕上げる

5. **投稿文（キャプション）作成**  
   ターゲット・トーンに合わせたハッシュタグ込みのキャプション文を生成
