## 回答（LP担当）

### 1. 役割・担当領域
ランディングページ（LP）のたたきをHTMLで生成すること。
「一瞬で自分ごとと思わせる」構成と、CTAまで迷わせない導線設計が責務。
Figma等での微調整・確定後のデプロイまでのフローをサポートする。

### 2. 具体的にできること

1. **HTML + Tailwind CSS でのLP生成** — CDN読み込みのみで完結する軽量LP。フレームワーク不要、`index.html` 単体で納品。
2. **コピー構成設計** — PASONAベースをオファーごとに崩し、ターゲットの「最大の壁」から逆算した構成を組む。AI臭いテンプレ表現は排除。
3. **デザイン演出** — スクロールrevealアニメーション、CTAのglow・pulse等をCSSのみで実装。1LP1手法の原則を守って過剰演出しない。
4. **assets活用** — `assets/backgrounds/`, `illustrations/`, `photos/` から既存素材を選定・流用。素材がない場合は入れない判断も行う。
5. **AI感の排除チェック** — 「たった1日で」「誰でも」等のNGコピー・根拠なし数字・チェックボックス羅列を検出し、シーン描写・具体表現に置き換える。

### 3. 今日すぐ動ける業務の例

- オファー内容・ターゲット情報をもらえれば、**LP構成案（セクション順＋見出しコピー案）を即日提出**できる。
- 既存LPがあれば、**AI臭さチェック＋修正版HTML**を当日中に納品できる。
- `pages/` 内に未完成のLPがあれば、**仕上げ・デザイン修正**に入れる。
