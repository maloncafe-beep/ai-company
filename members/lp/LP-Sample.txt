━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【デザインの方向性】
以下の5つから1つを選び、選んだもの以外の行を削除してください:

→ A: ダークコズミック — 深い紫の宇宙空間にネオングロー。未来的でワクワク感がある。テック系・AI系・ゲーム系向け。
→ B: クリーンネイビー — 紺×白×オレンジ。信頼感と温かみのバランス。ビジネス系・教育系向け。
→ C: ソフトグラデーション — パステル系のグラデーション。柔らかく親しみやすい。女性向け・ヘルスケア・ライフスタイル系向け。
→ D: モノクロプレミアム — 黒×白×ゴールドアクセント。高級感と洗練。高単価サービス・コンサル向け。
→ E: カスタム — 以下にカラーコードを記入してください。
  背景色: ここに背景色を入力
  メインアクセント色: ここにメインアクセント色を入力
  サブアクセント色: ここにサブアクセント色を入力
  テキスト色: ここにテキスト色を入力

上記の方向性に基づいて、以下のデザイン要素を一貫して適用してください:

1. カラーパレット: 方向性に合った5〜7色をOKLCH形式で定義し、
   index.css の @theme inline ブロックと :root にカスタムプロパティとして設定する。
   背景・カード・アクセント・テキスト・ボーダーの各用途に色を割り当てる。

2. グラスモーフィズム: 半透明背景 + backdrop-filter: blur(16px) + 細いボーダーの
   .glass-card クラスを定義する。カードやバッジに使用する。

3. グロー効果: メインアクセント色を使った .neon-glow（box-shadow 3層）と
   .neon-text-glow（text-shadow 2層）を定義する。見出しやCTAに使用する。

4. グラデーションテキスト: アクセント色2〜3色を使った .gradient-text を定義する。
   強調したい見出しに使用する。

5. アニメーション:
   - float: 4秒周期で上下12pxの浮遊（キャラクター/装飾画像用）
   - float-slow: 6秒周期で上下8px + 微回転（サブ装飾用）
   - pulse-glow: 3秒周期でCTAボタンのbox-shadowが脈動
   - ページ読み込み時: opacity 0→1 + translateY 8px→0, duration-1000
   - Canvas星空/パーティクル: 背景に60〜80個の光の粒がtwinkle

【タイポグラフィ】
- フォント: Noto Sans JP（Google Fonts）
- ウェイト: 400（本文）, 500（ナビ）, 700（見出し）, 900（ヒーロー見出し）
- ヒーロー見出し: text-4xl → sm:text-5xl → lg:text-6xl, font-black
- サブコピー: text-lg → sm:text-xl

■ 日本語改行ルール（必ず遵守）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【NG】助詞の直前で切る（「私/は」「りんご/を」「りんご/など」）
【NG】単語の途中で切る（「コンピュー/ター」「アプリケー/ション」）
【NG】数字と単位を分ける（「100/円」「500/円」「2024/年」）
【NG】固有名詞の途中で切る（「田中/太郎」）
【NG】助詞だけを次の行に残す（改行後に「は」「が」「を」だけがポツンとある）
【OK】句読点（、。）の直後で改行
【OK】文節の切れ目（意味のまとまりの後）で改行
【OK】接続詞の前で改行（「〜です。/しかし」）

■ 技術要件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- Tailwind CSS 4（@theme inline で OKLCH カスタムカラー定義）

- lucide-react アイコン
- Canvas API でパーティクルアニメーション（requestAnimationFrame）
- レスポンシブ: モバイルファースト（sm: / lg: ブレークポイント）
- Google Fonts: Noto Sans JP (400, 500, 700, 900)
- html lang="ja"
- ThemeProvider: defaultTheme に合ったテーマを設定
- 画像は定数ファイル（lib/images.ts）で一元管理する
