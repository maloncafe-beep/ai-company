# 長文コンテンツ掲載プラットフォーム調査レポート

**調査日：** 2026-04-30  
**担当：** researcher  
**依頼：** Leader（X流入×長文読み物×将来課金 用途のプラットフォーム選定）

---

## 概要

X（旧Twitter）のスレッドをフックに長文読み物へ誘導するコンテンツ戦略に最適なプラットフォームを選定するため、note・Substack・Medium の3媒体を主軸に比較調査した。

---

## 結論（3行）

- **日本語市場でX流入×課金を今すぐ始めるなら note 一択**。単品・サブスク・PDF販売すべて対応し、日本語ユーザー基盤が圧倒的。
- **独自ドメインや将来の英語展開を視野に入れるなら Substack が第2候補**。ただしX上でのリッチプレビュー問題あり（独自ドメインで緩和可）。
- **Medium は日本語運用での課金モデルとして機能しない**。パートナープログラムが間接分配型で、単品販売・PDF販売不可。

## 2. 各プラットフォーム詳細

### note.com

- **強み：** 日本語ユーザー基盤が最大。記事単品・有料マガジン・メンバーシップ（月額）・ファイル添付（PDF）販売すべて対応。X連携設定で記事シェア時に自アカウントが表示される。
- **弱み：** 独自ドメインは note pro（法人向け）のみ。個人では不可。月N本→有料の厳密なメータリングはなく、メンバーシップ内での限定設定で代替する形。
- **手数料詳細：**
  - 有料記事：決済手数料（約5%）+ プラットフォーム利用料10%
  - 定期購読マガジン：決済手数料（約5%）+ プラットフォーム利用料20%
  - メンバーシップ：上記と同様の構成
- **X流入との相性：** ◎。日本のX（旧Twitter）クリエイター界隈でnoteへの誘導は一般的な動線として定着済み。

### Substack

- **強み：** 月額サブスクのプロダクト完成度が高い。独自ドメイン設定可（$50一回払い）。海外読者へのリーチ可能。Stripeを通じた安定した決済インフラ。
- **弱み：** 2023年のX-Substack対立の影響で、SubstackのダイレクトURLはX上でリッチカードプレビューが表示されず、アルゴリズム上も降格リスク。独自ドメインを設定することで部分的に解消可能。日本語読者基盤は薄い。UIが英語。PDF販売ネイティブ機能なし（外部リンクで代替は可）。
- **日本語運用：** コンテンツは日本語で書けるが、Substackのデイスカバリー機能（検索・レコメンド）は英語圏向けが中心。

### Medium

- **強み：** 英語圏では読者基盤が大きく、SEOも強い。
- **弱み：** 収益モデルが「読者のMedium月額会員費を分配する」間接型で、記事単品販売・PDF販売不可。日本語記事は書けるが日本人有料読者が極めて少なく、実質的に日本語での収益化は困難。日本人向けにはモデルとして機能しない。

## 4. Xリサーチ結果（一次情報）

X上での実体験・本音ポストより抽出：

1. **「noteは単体でのマネタイズに最も向いていて『noteだけひたすらやる』でも伸びていく」**  
   → 単品収益化に最も直結するプラットフォームとして評価が高い  
   出典：[@hayashiwithcats](https://x.com/hayashiwithcats/status/1873936396702147049)

2. **Substackを試した日本人クリエイターの声：「日本人には早すぎるプラットフォーム」**  
   → 日本語読者層が薄く、コンテンツを作っても読まれにくいとの実体験  
   出典：[note.com/yuyaman1986](https://note.com/yuyaman1986/n/n4015bdc318fa)（正直レビュー記事）

3. **「SubstackをやっているがnoteにもXからの流入を狙って記事を掲載」**  
   → 両プラットフォームを併用してリーチ拡大を図るクリエイターも存在  
   出典：[@gamayauber01](https://x.com/gamayauber01/status/1923137603366207584)

4. **「Xのフォロワー増加→その才能を活かせるポジションを探す→noteでマネタイズ」という動線が定番化**  
   → X起点→note誘導→課金の王道パターンが確立している  
   出典：[@seto_note_labo](https://x.com/seto_note_labo/status/1895501897601347711)

5. **SubstackのダイレクトリンクはX上でカードプレビュー表示なし・アルゴリズム降格リスクあり**  
   → X連携という観点で Substack は明確な弱点を持つ  
   出典：[beehiiv blog](https://www.beehiiv.com/blog/how-much-does-substack-cost)（2026年調査）

## 5. 推奨プラットフォーム

### 第1推奨：**note**

**理由：**
- X流入→長文読み物の動線が日本市場で最も確立されている
- 記事単品・月額サブスク・PDF販売のすべてに対応し、将来の課金モデルをすべて実現できる
- 日本語UI・日本円決済・日本語サポートで運用コストが低い
- X連携機能により、記事シェア時の導線最適化が可能

**懸念点：** 独自ドメインは個人では使えない（note proは法人向け・高額）。SEO的にはnote.comドメイン配下になる。

---

### 第2推奨（将来的な独立性・英語展開視野）：**Substack**

**理由：**
- 独自ドメインを$50で設定でき、長期的にコンテンツのSEO資産を自社ドメインに積める
- 月額サブスクのプロダクト完成度が高く、ニュースレター型の固定読者獲得に強い
- 将来的に英語コンテンツも視野に入れる場合、海外読者へのリーチが可能

**懸念点：** X上でのリッチプレビュー問題（独自ドメインで緩和可）。日本語読者層が薄い。UIが英語。
