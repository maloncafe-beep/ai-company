## 調査内容

### 1. 候補プラットフォームの比較
note・Substack・Medium・その他も含めて比較する。
以下の軸で整理すること：

| 軸 | 確認事項 |
|----|---------|
| 掲載機能 | 長文記事・シリーズ管理・カテゴリ分け |
| 課金機能 | 単品販売・月額サブスク・記事ごと有料設定 |
| アクセス制御 | 月N本まで無料・それ以降有料、会員限定記事 |
| PDF販売 | まとめPDFのアップロード・販売が可能か |
| X連携 | X（旧Twitter）からの流入・埋め込みのしやすさ |
| 手数料 | 販売手数料・プラットフォーム利用料 |
| 日本語対応 | UI・決済・サポートの日本語対応度 |
| 独自ドメイン | 使えるか |

### 2. 将来の課金モデル候補
以下の課金パターンが技術的に実現可能かプラットフォームごとに確認：
- ① 記事単品販売（1記事 ¥○○）
- ② 月額サブスク（月¥○○で読み放題 or 月N本）
- ③ PDFまとめ販売（複数記事をPDF化して販売）
- ④ 無料n本→それ以降有料のメータリング制御

### 3. 推奨プラットフォーム
上記を踏まえ、今回の用途（X流入×長文読み物×将来課金）に最も適した1〜2案を理由付きで推薦する。
