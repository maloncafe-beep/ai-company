# 中級者の壁！どこで使う？「使い分け」のライティング

## セールスライティングとコンテンツ系のライティング

**セールス**
- 好奇心と恐怖と欲望をコントロールする
- **売るために行う** → 緊急性と希少性を与える → 行動に促す
- 煽り重視 → ただひたすらに、次を読ませる事を意識

**コンテンツ系**
- 動機や価値観を伝える
- **信頼をとるために行う** → 情報価値を与える → 賢くする、成果をだしてもらう
- 育成重視 → 読みやすさ、わかりやすさ、楽しさを重視
- 信頼があるうちは話を聞いてくれる

**サイクル — 信頼残高という考え方**
- セールスなしの記事で相手の役に立つ事をかければ、信頼はあがる
- 成果をだささせるのが一番はやい
- 機能的、感情的に
- 買ったお客の満足が上がれば → そのお客のみ信頼がある
- セールスをすると、した段階で、信頼は減る
- 高い成果が出ればそのお客が口コミしてくれる
- そのロコミで、買ってないお客でも信頼は増幅する
- それらのシェアがない場合
- 買わないお客はさがったまま

## 低額と高額のライティング

**無料**
- 好奇心優位
- オファーはライトに、ノーリスクを提示、文章は短く → 数千文字以内
- 手に入るものを手早く提示し、すく誘導

**低額**
- 好奇心、恐怖優位
- オファーはライトに、高い利益を提示、文章は短く → 数千文字以内
- ストーリーよりは数字やベネフィットの羅列で攻める
- 成果物をイメージさせる
- 欲望、恐怖優位

**高額**
- オファーは丁寧に、文章は長く → 数万文字単位
- ストーリーを使い、変身願望や成長意欲をかきたてる
- 成長の確実性を伝える

## 初心者集客と中級者集客

**初心者（情報弱者）**

- 響く感情 → 欲望、恐怖、好奇心を刺激
- 伝えるべきもの → ベネフィット、プレゼント → どうなるか？何を得れるか？が中心
- 今ある問題の解決を求める
- 即効性 → 表面的な利益を求める
- 求めるもの → 最速、簡単
- 流行性 → 皆やってることに乗っかりたい
- 誰でもウェルカム → イージー性
- 響く言葉 → 初心者でも大丈夫

**中級者（情報強者）**

- 響く感情 → 欲望、向上心、好奇心を刺激
- 伝えるべきもの → 理念、最高品質、最先端、最高環境
- 誰がやるか？誰とやるか？どのようにやるか？
- 二度と問題が起きない状態を求める
- 本質性 → 根本的な解決を求める
- 求めるもの → ブランド性 → 情弱、一般として扱われたくない
- ○○な人のみ歓迎。それ以外はお断り → 選民性
- 響く言葉 → 質の高い人と繋がれます。荒らす人はいません → 環境

## オラオラ系とまったり系

数は少なめだが目立つ

**オラオラ系**
- 最高でどこまでいけるかを気にする
- 手がるさや最速最大を伝える → コストやリスクはあまり気にしない（赤字はダメだが） → リターンの速さと大きさを気にする
- ただ、ビッグマウスなときも多い
- 行動力、投資意欲は非常に高い → 口約束、言葉は半分にきく → 攻撃的アンチやクレーマーにもなりやすい
- アプローチ → 具体論が響く
- 数は多めだが印象薄い

**まったり系**
- 低リスク低コスト、コスパを伝える → 速度や最大値はあまり気にしない → 万一を考える、リスクやコストを気にする
- 平均値がどこまでいけるかを気にする
- ただ、行動速度が遅く、コレクター化しやすい
- 真面目で誠実 → 発言は大体そのまうけとっていい
- アプローチ → 抽象論、マインド論が響く。
