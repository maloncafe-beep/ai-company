# 初見で欲情させよ！「勝てるネーミング」の技術

## ネーミング＝肩書や商品名（サービス名）の名付け

## ネーミングは売上に直結！

- 強いタイトルができると、それだけで「売ってくれ」の直前までくる。「もっと聞かせて」ぐらいはたやすい
- 本文は雑に流れでかいても、タイトルは死ぬほど時間かけるという億プレイヤーもいるぐらい
- 素晴らしいネーミングが決まれば、本文もつよく芯が通る
- ネーミング替えただけで売上30倍とか変わった例は世の中に多数
- ターゲットやコンセプトが明確になった場合が多い
- 欲情もしやすい
- モイスチャーティッシュ→鼻セレブ 10倍以上
- 三陰交をあたためる→まるでこたつソックス 17倍以上

## セールスレターにおけるネーミングの価値とは？

- **本文に興味をもたせること**
- 欲情させれそうか？ → 「タイトルを聞いただけで、欲しくなる」が基本
- **タイトルをみただけでその気になり、続きをよみたくなる**
- ワードにパワーがあるか？

## 商品名の作り方

- 基本は、2単語で組み合わせる
- 多くても3単語
- 4単語以上は大体多すぎ
- 例：熱狂の文章術、コンテンツ・キングダム、仕組み化帝国、扇動マーケティング、悪魔の情弱狩り講座

- 長文言いたいときは、サブタイトルで補完する
- 悪魔の情弱狩り講座 〜悪用厳禁！二度と狩られる側には回らない！狩る側のスキルを身につけてしまう販売講座〜

- 作るタイミング → レターの書き始めと同時。ステップメールとか作るより先なことも非常に多い
- 理由：強いタイトル思い浮かんだら間違いなく勝てるから先に考えとくと非常に労力的に楽

## 基本は3つ！パワーのあるタイトルのつけかた

**1：ストレート法** → そのまんまにつける → 例：スーパービギナーズライティング

**2：ギャップ法** → 逆のワードをつなげる、意外性のあるワードをだす
- 例：初心者無双ライティング
- 例：悪魔のステップメール

**3：過剰法** → 同じ属性のワードを重ねる、パワーのあるワードを連打する
- 例：実績ゼロ知識ゼロスキルゼロからのスリーゼロスタートライティング
- 例:ネコソギ〜極限の仕入れ術〜

## 上級者向けネーミング！3つの技法！

**4：比喩法** → 例えを用いてイメージさせる
- 例：「脱獄」 強制労働からの解放という意味をこめて
- 「泡雪」 泡となって溶けるようなお菓子
- メリット：強いパワーワードを、幅広く選べる。ハマれば非常に強い印象を与えれるし、短く表現できる
- 注意：商品名の解説がほぼ必要。また、外したときは、逆にイメージがしづらい

**5：流行ワード法** → 流行に乗っかったワードを使う
- 例：集客の教典（悪の教典）、爆売れ先生（しくじり先生）
- 注意：相手が知らないと滑る。時期がたつと響かない

**6：語呂合わせ法** → 口ずさみやすいワードを使う
- 例：武器楽倶楽部
- 覚えやすい。口コミしやすい

- 無理して使わなくていい。なくてもいける

## 超よくある！けどやるな！良くないネーミングのワナ！

**オシャンティのワナ**
- なんかシャレた感じにしたがる
- 一般的に使われない英語や横文字を使いたがる
- しかも英表記する（これはマジでやめろ）
- 例：Shangri-La Curriculum
- 日常的に使わない言葉はやめよ

**平凡すぎるのワナ**
- 100万人ぐらい言ってそうなタイトルにする
- 検索したらライバルがすぐでてくるワードにする → 例：初心者ライティング

**無推敲のワナ**
- タイトル1発通しで決めようとする
- 大体ヤバイ。最低でも10ぐらいは出したほうがいい

**無難オブ無難のワナ**
- いろんな意見を聞いたりして
- 多人数でアイディア出すときにありがち
- 全員が納得するところを目指した結果
- ウルトラ無難な名前に落ち着く
- **必要なのは綺麗さではなく、欲望を刺激するかどうか**

## 良いタイトルのチェックリスト！

**1：欲情しそう？** → 優先。タイトルで感情を動かせられないと続きは読まれない
2：直感的でわかりやすそう？ → 中身がピンとこないのは大体だめ
3：ライバルはいなそう？ → 検索してメジャーなライバルか、検索ワードを奪う存在がいたらやめたほうがいい → みんなが使ってると、ワードにパワーがなくなる → 無視できるようなマイナーさなら無視してよい
4：一息で言えそう？ → 略語でもよい。一息でいえないと覚えづらく伝えづらい → 2単語あたりが無難
5：口コミしやすそう？ → 品がなさすぎると他人に紹介しづらいし → 自分でも口にだしづらい

## 応用！より売れるために「造語」を作ろう！

**造語を作ろう！**
- 学収 → 収益を得ながら学ぶ
- ゼロ時間収入 → 普通の自動化だがこっちのほうが響く
- 狂育、恐育、狭育 → 仮想敵を叩くために作った、やってはいけない教育

**造語のメリット・デメリット**

メリット
- ライバルがいない
- 学ぶなら自分しか無いと思わせる
- 覚えやすい（良い造語なら）
- **いい造語つくれたら、それだけで勝てる**

デメリット
- ピンときづらいことも
- 説明が必要すぎると単語の意味が弱くなる
- 検索で探されたりはしない
- 初期に目立ちづらい

共通注意
- 造語の説明はあったほうがいい
- （というか、造語だからないとわからない）

**造語の4つのパターン**

**1：同音異義語の漢字を探す**
- 仕事をしよう！→志事をしよう！
- 頑張ろう！→顔晴ろう！
- 競争→共創
- マイナスにも使う → 自己紹介→事故紹介、教育→恐育
- 注意：普段使わない、目にしない漢字はなるべくやめておくこと（常用漢字から探すこと）
- 使うツール → **類語辞典**、**連想言葉辞典**

**2：英語などを混ぜる**
- 人間心理の解析術 →ヒューマナライズ（ヒューマン＋アナライズ）
- 注意：混ぜすぎて意味がわからなくならないように
- 使うツール → Google翻訳

**3：頭文字を取ってつなげる**
- 例：潜在能力に目覚めるセルフ・カウンセリングの教材売りたい。しかしセルフカウセリングプログラムは芸がない。エマンシペイションは解放という意味で使いたいが一般的でない。しかも組み込むと長い……
- →セルフ・エナジー・エマンペイション・プログラム → **S.E.E.P**

**4：カタカナにしてみる**
- 例：根こそぎ→ネコソギ

## タイトルはひたすらブレインストーミングでだそう！

- 人と案を出し合うと効果的

**ネットの辞典を使うとより最強！**
- **Google翻訳辞典** → 超使う！死ぬほど使う！迷ったら類語！
- **類語辞典**
- 連想単語辞典
- 同音異義語辞典

- 最初は安直なタイトルを10も20もだす
- その後に、ひねったタイトルを少しずつ考える
- 絶対に却下しない。否定しない。とりあえず書きだす
- 思いつかないなら、最後はストレートで → 誰がどうなる？などでもいい → 例：**初心者月収1万円絶対達成企画**

## 最後に

例：せどりの教材を売りたい → 初期案：せどりで売れる方法
- アレンジ：せどりでたくさん売れる方法 → せどりでバク売れする方法 → せどり爆売れ塾 → せどり爆仕入れ塾 → 爆入れのせどり塾
- 仕上げ：バクイレのせどり術 → バクイレ〜爆発的に仕入れできて、お金も入る〜 → 根こそぎの仕入れ術 → ネコソギ 〜お宝を、全部仕入れて全部売る〜 → ネコソギの目利き術

例：ライティング教材を売りたい → コンセプトはなに？→ファン化 → 初期案＆叩き台：ファン化ライティング
- アレンジ：ファンづくりライティング → ファンクリエイトライティング → 言葉の錬金術師 → 文章の錬金術師 → 錬金の文章術 → 錬金 → 言葉の魔術師←仮決定
- 最終：ファン→ファナティック（語源） → 狂乱の文章術 → 信者化の文章術 → **"熱狂"の文章術**
