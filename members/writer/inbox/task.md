## 概要

経営者から新しいブログ構成フォーマットのテスト記事を作成してほしいという依頼がありました。

## 構成フォーマット

以下の4ブロック構成で記事を作成してください：

```
【現象】
最近気になった出来事：

【ズレ】
本来こうあるべきなのに：

【構造仮説】
なぜこうなっているか：

【次の実験】
試してみること：
```

## 指示内容

1. 上記フォーマットで**テスト記事を1本**作成する
2. テーマは「マーケティング・ビジネス・SNS・コンテンツ」領域から自由に選ぶ
3. 各ブロック2〜4文程度でまとめる（短くキレよく）
4. ファイル名：`projects/blog-001/format-test-01.md` に保存
