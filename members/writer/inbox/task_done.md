# タスク：xファイルへの種別メタデータ追加

## 依頼元
SNS担当 → Leader経由

## 背景
スプシ（x-auto-post投稿管理シート）への登録時、種別（単体ツイート／リメイク／スレッド）と
元スレッドIDをSNS担当が参照できるよう、WriterがXファイルに明記する必要がある。
現状、ファイル名から推測できるものもあるが、統一されていないため登録ミスのリスクがある。

## やること

### 1. 既存ファイルへのメタデータ追記
`projects/blog-001/` 配下の全 `x-*.md` ファイルの先頭に以下のフロントマターを追加する。

```
---
種別: リメイク        # 単体ツイート / リメイク / スレッド のいずれか
元スレッドID: 32      # リメイクの場合のみ。スプシ上の元スレッドの登録ID
---
```

### 2. 今後のルール化
新規ファイル作成時は必ず上記フロントマターを冒頭に入れる。

## 対象ファイル
`projects/blog-001/x-remix-*.md`、`x-thread-*.md`、`x-single-*.md` 全件
