# 特典ページ構成

## コンセプト
- 「今何をすればいいか迷わない」設計
- 1画面1アクション
- 「読む」と「やる」を視覚的に分離
- ゴール達成（確信を与える）が最重要

## 確定デザイン
- ベース: パターンA（ポップ・カラフル / インスタグラデーション）
- テンプレートファイル: `insta-pattern-a.html`
- 新規特典作成時はこのファイルを複製して使う

## ページ構成

### 1. FV（ファーストビュー）
- 背景: 「Instagram × AI Automation」がスライドで流れるアニメーション（CSS @keyframes、偶数行は逆方向）
- バッジ（BONUS TUTORIAL等）
- メインタイトル
- サブテキスト

### 2. Goal カード
- サムネイル（16:9）
- 「このマニュアルで達成できること」リスト
- **「チュートリアルを始める」ボタン** → 押すとSTEP群が開く

### 3. STEP群（ボタン押下後に出現）
- プログレスバー（上部fixed）表示
- 各STEPカードが順に表示

### 4. 各STEPカード（繰り返し）
- **インスタ風ヘッダー**（ストーリーズリング付きアバター + 「STEP X」 + ···メニュー）
- ステップタイトル（STEP番号なし、タイトルのみ）
- **解説動画**（プレースホルダー / 埋め込み）
- **アクションブロック**（ピンク枠「YOUR TURN」）
  - プロンプトコピー or タスクチェックリスト
- **完了ボタン**

### 5. アクションブロック内のタスク
- **チェックボックス** → タップで完了（取り消し線）
- **トグル（▼）** → タップで解説テキストがタスクの下に出現
- チェックとトグルは独立動作
- 解説はグレー背景の角丸ボックスで表示
- **最初のタスクにHTMLで直接 `current` クラスを付与する**（UTAGE上ではJS初期化が効かないため）

### 6. 完成セクション
- 全STEP完了後に出現（アニメーション付き）
- おめでとうメッセージ
- 次のステップCTA（メイン商品への導線）

## UI仕様
- プログレスバー: position fixed（UTAGE埋め込み時はiframe方式で対応）
- チェックリストナビ: SP版はfixedバーで対応、本体HTMLからは削除済み
- FVスクロールテキスト速度: 12s / 15s
- スタートボタン押下 → ボタン非表示 + プログレスバー表示 + STEP群スライドオープン
- STEP完了ごとにプログレス更新
- 全STEP完了で完成セクション表示

## カードデザイン仕様（確定）
- border-radius: 12px（インスタ寄り）
- border: 1px solid #dbdbdb
- box-shadow: 0 1px 3px rgba(0,0,0,.06)（薄い影）
- インスタ風ヘッダー: ストーリーズリング付きアバター + タイトル + ···
- ステップ番号バッジ（丸グラデ）は使わない → ヘッダーの「STEP X」で代替
- Goalカードにもインスタ風ヘッダーあり
- サムネイル画像: カード横幅いっぱい（ネガティブマージンでパディング相殺、border-radius なし）
- SP版: wrap padding 8px、card/step-card padding 20px 12px、action-block padding 14px 12px

## UTAGE対応
- position sticky/fixed はUTAGE HTMLブロック内で効かない
- **解決策: iframe方式** — Netlify等に外部ホスティングし、UTAGEからiframeで埋め込む
- CSSアニメーション、JS（onclick、clipboard API）はUTAGE HTMLブロックで動作確認済み
