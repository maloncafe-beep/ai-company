# 提案書・企画書 AI 自動作成プロンプト集 100+

**毎日 60 分かかる提案書が 10 分で完成するプロンプト集**

対応AI：ChatGPT / Claude / Gemini 全対応  
出力形式：PDF / PPTX / DOCX / PNG / HTML

---

## これは何？

営業資料・提案書・診断レポートを **AI に 1 回コピペするだけで、自動生成** するプロンプト集です。

### 具体例

| 仕事 | かかる時間 | このプロンプト集だと |
|---|---|---|
| 提案書 1 件（11ページ） | 60～90 分 | **10～15 分** |
| 診断レポート 1 件（10ページ） | 45～60 分 | **8～12 分** |
| 業務改善企画書 | 120 分 | **20～30 分** |

毎日これを繰り返すと……**月 40～50 時間が浮きます**。

## 使い始めるには？

### 方法 A：プロンプト経由（推奨・環境構築不要・10分）

**最も簡単。初心者向け。**

#### フロー図

```
│ ステップ 3：AI に貼り付け                               │

│ ✅ ブラウザで PDF / HTML として保存可能                  │
└─────────────────────────────────────────────────────────┘
```

#### 具体的な使い方（3パターン）

**パターン 1：テキストエディタ + コピペ（最も確実）**

1. **プロンプトファイルを開く**
   - `prompts/prompt_proposal_11p.md` をテキストエディタで開く
     - Windows: メモ帳 / Visual Studio Code
     - Mac: TextEdit / Visual Studio Code
   - ⚠️ **Mac ユーザーへの注意**：TextEdit で開く場合は**必ず「フォーマット」→「標準テキスト」に設定してから開いてください**。UTF-8エンコーディングが正しく適用されないと文字化けします。

2. **すべてのテキストをコピー**
   ```
   Ctrl+A（すべて選択）→ Ctrl+C（コピー）
   ```

3. **ChatGPT / Claude / Gemini のチャット画面に貼り付け**
   ```
   Ctrl+V（貼り付け）
   ```

4. **【インプット】の部分を埋める**
   ```
   【企業名】テック・ブリッジ株式会社（仮）
   【現状の課題】営業資料作成に時間がかかっている
   【提案する解決策】AI導入によるコスト削減
   ```

5. **送信 → 提案書が自動生成される**
   ✅ HTML 形式で出力 → ブラウザで PDF として保存可能

**パターン 2：ドラッグドロップ（Claude 推奨・最も簡単）**

Claude のチャット画面に `prompts/prompt_proposal_11p.md` をそのままドラッグドロップすれば、ファイル内容が自動的に貼り付けられます。その後 ステップ 4 に進んでください。

**パターン 3：Google Docs 経由（複数人での共有が必要な場合）**

1. Google Docs を開く：https://docs.google.com/document/u/0/
2. プロンプトの内容を貼り付ける
3. 共有リンクを生成し、チーム全員で編集可能に
4. 完成後、各自が ChatGPT / Claude / Gemini のチャット画面に内容をコピペ

## よくある質問

### Q1: 「何も表示されない」「エラーが出た」

**A:** 以下を試してください（順番に）

1. **check-environment を実行**
   - Windows: `check-environment.bat`
   - Mac: `./check-environment.sh`
   - 何が足りないか、自動で表示されます

2. **ChatGPT / Claude のバージョン確認**
   - 古いバージョンだと、プロンプトが認識されないことがあります
   - ブラウザを再読み込み（F5）してください

3. **まだ動かない場合**
   - 方法 A（Google Docs 経由）から始めてください
   - こちらなら環境構築が不要です

---

### Q2: 「結果を別の形式で保存したい」

**A:** 以下の手順で変換できます

| 形式 | 方法 |
|---|---|
| PDF | ブラウザで「Ctrl+P」→「PDF として保存」 |
| Word（.docx） | HTML 出力 → Google Docs にコピー → Word 形式でダウンロード |
| Excel（.xlsx） | HTML の表 → Google スプレッドシートに貼付 → Excel でダウンロード |
| PowerPoint（.pptx） | プロンプト実行時に「PowerPoint 形式で生成してください」と指示 |
| 画像（PNG/JPG） | ブラウザで「Print Screen」→ 画像編集ソフトに貼付 / スクリーンショットツール利用 |

---

### Q3: 「複数パターンを一度に作りたい」

**A:** プロンプト内の【インプット】を以下のように渡してください

```
企業名：テック・ブリッジ / 課題：資料作成 / 費用：300万円 / 期間：6ヶ月

企業名：ヤマト製作所 / 課題：業務改善 / 費用：150万円 / 期間：3ヶ月

...（複数行）
```

AI が自動で複数ファイルを生成します。

---

### Q4: 「カスタマイズしたい」

**A:** 各プロンプント MD ファイルの冒頭に**カスタマイズガイド**があります

例：`prompts/prompt_proposal_11p.md` の上部

```markdown
【カスタマイズポイント】
- 企業規模を「大手企業向け」に変更する場合 → 【企業規模】行を編集
- 業種を「不動産」に限定する場合 → 【業種】行を編集
- 出力言語を「英語」にする場合 → 【言語】行を編集
```

---

### Q5: 「営業マンが複数いるが、共有できる？」

**A:** はい、できます

方法 1：**このフォルダを共有フォルダにコピー**
- Google Drive / Dropbox / OneDrive に入れる
- チーム全員でアクセス可能にする

方法 2：**社内サーバーに置く**
- NAS / Git リポジトリ に配置
- チーム全員でクローン
