## 【道筋B】スクリプト使用で自動化（上級・時短重視）

### 前提条件

このルートを使うには、以下をインストール済みにしてください。

**必須：**
- Node.js 16 以上

**オプション（一部スクリプト使用時）：**
- Google API キー（Google Drive にアップロードしたい場合のみ）

### セットアップ手順

**ステップ 1：Node.js をインストール**

**Windows:**
```
1. https://nodejs.org/ を開く
2. 左側「LTS」をダウンロード
3. インストーラーを実行
4. デフォルト設定で OK
5. PC を再起動
6. コマンドプロンプトで確認：
   node -v
```

**Mac:**
```
1. https://nodejs.org/ を開く
2. 左側「LTS」をダウンロード
3. .pkg ファイルをダブルクリック
4. インストーラーに従う
5. ターミナルで確認：
   node -v
```

**ステップ 2：必要なモジュールをインストール**

```bash
# プロンプム集のフォルダに移動
cd ~/ai-prompts

# npm モジュール をインストール
npm install
```

**注意：** 初回のみ 1～2 分かかります。以降は不要。

**ステップ 3：HTML → PDF 変換スクリプトを実行**

```bash
# 例：proposal.html を PDF に変換
node server/scripts/html_to_pdf.mjs proposal.html

# 複数ファイルも可
node server/scripts/html_to_pdf.mjs proposal.html summary.html
```

**出力：** `proposal.pdf` が自動生成されます。

**ステップ 4：HTML → PPTX 変換（Google Slides にアップロード）**

**前提：** Google API キーを設定している場合のみ

```bash
node server/scripts/html_to_slides.mjs proposal.html "提案資料フォルダ"
```

**出力：** Google Drive に `proposal.pptx` と `proposal.pdf` がアップロードされます

```

## 📋 セクション 1：基本概念を 60 秒で理解

### 「プロンプト」とは？

**プロンプト** = AI に対する「指示書」

例：
```
「以下の条件で、SIer 向けの AI 導入提案書を Markdown で作成してください：
・対象：システムインテグレーション企業
・課題：手作業の自動化による生産性向上

```

↓ AI が読んで実行

↓

完成品（Markdown 文書）が返ってくる

### 「出力形式」とは？

**AI の出力** = 基本「テキスト」

でも私たちは「PDF」「PPTX」「HTML」で提出したい

**出力形式の変換作業が必要**

Markdown（テキスト）

```

Claude・ChatGPT・Gemini で、同じプロンプトでも結果が微妙に異なります

```
Claude：精度・正確性◎（高単価案件向け）
ChatGPT：速度・使いやすさ◎（量産向け）
Gemini：リアルタイムデータ◎（グラフ・統計必要な案件向け）

```

## ⚠️ セクション 5：失敗パターン＆対応

### 「AI の出力がイマイチ」の対処法

| パターン | 原因 | 対応 |
|---|---|---|
| 「文字が詰まってわかりにくい」 | 簡潔さが指示されていない | プロンプトの最後に「改行・空白行を増やして読みやすくしてください」を追加 |
| 「専門用語が間違っている」 | AI が推測で書いた | プロンプトに「以下の用語を正確に使い分けてください：[用語の定義]」と明記 or Claude に「これ本当？」と聞き直す |
| 「数字・統計データが古い」 | AI の学習データが古い | Gemini を使う（リアルタイム検索） or プロンプトに「2024～2025年の最新データを使用」と明記 |
| 「トーンが合わない」 | トーン指定がない | プロンプトに「トーンは【経営層向け・丁寧・フォーマル】」と明記 |
| 「出力が長すぎる/短すぎる」 | ボリュームが指定されていない | 「500単語に要約」or「1,000単語に拡張」と指示 |

### Claude vs ChatGPT：どちらを使う？

| 場面 | 推奨 | 理由 |
|---|---|---|
| 複雑な論理・業界専門用語が要る | Claude | 精度が高い |
| 高単価案件（5万円以上） | Claude | 正確性が命 |
| スピード重視・量産（毎日10件以上） | ChatGPT | 速い |
| 最新データが要る | Gemini | リアルタイム検索 |

   もし「スクリプトで自動化したい」となったら、
