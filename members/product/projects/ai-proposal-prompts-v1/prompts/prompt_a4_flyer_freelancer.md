# A4 両面チラシ作成プロンプト：提案書自動作成プロンプト集（フリーランス向け）

## 使い方

このプロンプトを **Claude / ChatGPT / Gemini** にそのまま貼り付け、ユーザー名や業種の部分を置き換えて実行すると、
営業用チラシの HTML が生成されます。ブラウザで表示 → PDF/PNG で保存が可能です。

---

## プロンプト本体

```
# あなたの任務：提案書自動作成プロンプト集の営業用 A4 チラシを作成する

## チラシの型

表面：ヒーロー・価値・訴求（何ができるか、誰にどう効く）
裏面：比較・実例・CTA（なぜ選ぶべきか、導入フロー、行動喚起）

## チラシ情報（置き換えてください）

- **商品名**：提案書自動作成プロンプト集
- **ターゲット**：フリーランス・副業起業家・個人事業主
- **キャッチ**：「60分の提案書作成から、解放される。」
- **サブヘッド**：「毎日の提案書づくり → 10 分で完成。営業スキルに時間を使おう」
- **色コード**：
  - メイン：#FF9500（オレンジ）
  - セカンダリ：#FFD700（ゴールド）
  - テキスト：#1C2B3A（ネイビーグレー）
  - 背景：#FFFFFF（ホワイト）

## チラシの構成

### 表面（ユーザーの課題 → 解決策）

1. **ヒーロー**
   - ロゴ・商品名：「提案書自動作成プロンプト集」
   - キャッチコピー：「60分の提案書作成から、解放される。」（大きく・太く）
   - サブヘッド：「毎日の提案書づくり → 10 分で完成。営業スキルに時間を使おう」
   - 背景カラー：#FF9500（オレンジ）

2. **課題ストリップ**
   - タイトル：「こんな悩み、ありませんか？」
   - 課題チップ（複数）：
     * 「提案書作成に毎日 1 〜 2 時間かかっている」
     * 「案件ごとに 1 からテンプレートを作り直している」
     * 「複数の AI を使い分ける方法がわからない」
     * 「デザイン・文言を整えるのに時間がかかる」
     * 「複数 AI で同じ工数がかかってしまう」

3. **訴求ポイント（3 つ）**
   - 「60分 → 10分」：時間短縮ビジュアル（大きな数字）
   - 「複数 AI 対応」：Claude・ChatGPT・Gemini のロゴと対応表
   - 「出力形式自由」：PDF・PPTX・DOCX・PNG 対応アイコン

4. **主な機能（グリッド表示）**
   - 「セットアップ不要」：コピペで即開始
   - 「複数出力形式」：HTML → PDF/PPTX 対応
   - 「AI 別対応」：ChatGPT・Claude・Gemini 全対応
   - 「実例同梱」：テック企業向け 11P 提案書テンプレート

### 裏面（導入フロー → CTA）

1. **比較表**（4 列 × 5 行）
   - 列：「このプロンプト集」「手書き作成」「汎用テンプレート」「AI 相談型サービス」
   - 行：「作成時間」「複数 AI 対応」「出力形式」「初心者向け」「費用」
   - チェック：✅ このプロンプト集が最も有利

2. **実装例**
   - 「📄 テック・ブリッジ向け提案書（11P）も同梱」
   - 「 顧客評価」：⭐⭐⭐⭐⭐ 5/5
   - 「 感想コメント」：「10 分で完成して、単価交渉に集中できた」「テンプレートから 5 分で自分仕様に変更」

3. **導入フロー（3 ステップ）**
   - ① ダウンロード・解凍
   - ② Claude / ChatGPT にコピペ
   - ③ HTML 出力 → PDF/PPTX で保存・送信

4. **CTA**
   - 「今すぐ使い始める」ボタン（#FF9500）
   - 価格表示：「5,500円（買切り）」
   - 下部バッジ：「30日返金保証」

5. **フッター**
   - 商品名・URL
   - 「よくある質問」へのリンク

## デザイン指定

- **サイズ**：A4 210×297mm（2 ページ = 表面・裏面を 1 ページずつ）
- **配色**：
  - ヒーロー・CTA：#FF9500（オレンジ）
  - アクセント：#FFD700（ゴールド）
  - テキスト：#1C2B3A（濃いグレー）
  - 背景：#FFFFFF
  - ハイライト背景：#FFF3E0（薄いオレンジ）
- **フォント**：
  - 見出し：太く・大きく（sans-serif）
  - 本文：読みやすく・18px 以下（sans-serif）
  - 行間：1.5 〜 1.6
- **ビジュアル**：
  - 時間短縮の「60分 → 10分」を目立たせる（大きな矢印＋色強調）
  - アイコン：簡潔・単色（#FF9500）
  - スペーシング：余白を多く（詰まった印象を避ける）
- **受け手層**：フリーランス・副業初心者（迷わないシンプル設計）

## 出力形式

- **形式**：HTML5（セルフコンテイン = CSS・SVG・画像すべて埋め込み）
- **仕様**：
  - ブラウザで開くと A4 2 ページが PDF として印刷可能
  - `@media print { }` で用紙サイズ最適化
  - レスポンシブ：デスクトップ・タブレット対応
- **互換性**：Chrome・Safari・Firefox で確認可能

---

## 出力の品質基準

✅ **必ず満たすこと**：

1. **ロジック**：表面で「何ができるか」→ 裏面で「なぜ選ぶべきか」の流れが明確
2. **ビジュアル**：#FF9500（オレンジ）が印象的で、ユーザーの目を引く
3. **字の大きさ**：見出し 24px 以上、本文 12px 以上（A4 印刷時に読める）
4. **実在する要素**：架空のデータ（存在しない案件、URL のない実装例）を入れない
5. **CTA が明確**：ボタン or リンクの場所・色・文字が目立つ
6. **2 ページ構成**：表面・裏面が 1 ページずつ（A4 サイズで自然な分割）

出力は、ブラウザで開いて即座に PDF/PNG で保存できる形式で。
```

## 使用上の注意

1. **置き換え可能な部分**：
   - `{ユーザー名の業種}`：フリーランス / 副業家 / 個人事業主
   - `{削減時間}`：60 分 → 10 分（カスタマイズ可能）
   - `{実装例}`：別の案件例に置き換え可能
   - `{価格}`：5,500 円（変更可能）

2. **出力形式**：
   - HTML を Claude / ChatGPT に貼り付けて実行
   - 生成された HTML をブラウザで開く
   - PDF / PNG で保存

3. **品質チェック**：
   - チラシのビジュアルが FieldSync デザインのレベルと同等か確認
   - 時間短縮の数字（60分→10分）が視覚的に目立つか確認
   - CTA ボタンの色・テキストが目立つか確認
