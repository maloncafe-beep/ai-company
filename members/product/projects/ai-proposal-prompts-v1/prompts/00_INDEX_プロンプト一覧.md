## 📖 使い方（30秒で理解）

1. 下から番号で探す（#1～#14）
2. 「ファイル場所」の URL をクリック（またはコピー）

## 🔧 変換スクリプトの使用方法

### HTML → PDF 自動化
```bash
node server/scripts/html_to_pdf.mjs logs/PrezenAutomake/output/ファイル名.html
```
前提：Node.js + Puppeteer インストール

### HTML → PPTX 自動化
```bash
node server/scripts/html_to_slides.mjs logs/PrezenAutomake/output/ファイル名.html
```

前提：Node.js + python-pptx インストール

### PPTX → Googleスライド化 + PDF 生成
```bash
node server/scripts/upload_to_drive.mjs ファイル.pptx
```
前提：Google Drive API 設定済み

## 📞 FAQ（よくある質問）

### Q. どのプロンプトから始めればいい？
**A.** 以下の順番をおすすめします：
1. **#1 提案書11P**（一番基本・実績多い）
2. **#2 診断レポート10P**（量産向け）
3. **#7 スライド自動生成**（ChatGPT の最大活用）

### Q. 複数業種を一気に生成したい
**A.** プロンプト #2（診断レポート10P）を使い、【インプット】を業種ごとに変えて **並列実行**。15～20分で 5～10 業種分できます。

### Q. PDF 化の品質が悪い場合は？
**A.** ブラウザ印刷（Ctrl+P）ではなく、**Gemini + WeasyPrint** で直接 PDF 生成をお試しください。品質・速度共に最高です。

### Q. PPTX にしたいけど複雑そう
**A.** **ChatGPT + プロンプト #7** が最短です。python-pptx コードを ChatGPT が生成して、Code Interpreter で実行すれば完成。手間は5分。

### Q. 営業マンが各プロンプトを簡単に使えるようにしたい
**A.** このファイルの「プロンプト一覧」を営業マンに共有。番号で指示（「#1 を Claude に送ってね」）だけで OK。ファイルを開かせる手間は省く。
