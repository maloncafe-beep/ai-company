# タスク：クラウドワークス案件管理スプレッドシート作成

## 依頼元
leader（マーケリーダー）

## 依頼日
2026-04-27

## タスク概要
クラウドワークスで受ける案件を管理するためのスプレッドシート（HTMLベース or CSVテンプレート）を作成する。

## 要件
- 案件ごとに以下の情報を管理できること：
  - 案件名
  - クライアント名
  - 受注日
  - 納期
  - 報酬金額
  - ステータス（応募中 / 進行中 / 納品済 / 支払済）
  - 備考
- 一覧で進捗が一目でわかること
- シンプルで使いやすいこと（余計な項目は不要）

## 成果物
- `projects/crowdworks-tracker/` 配下に配置
- HTMLファイル（ブラウザで開いて使えるもの）を推奨
- 完成後は `inbox/task.md` を `inbox/task_done.md` にリネームして報告

## 優先度
高（経営者からの直接依頼）
